# 관절 비율 편집 계산 준비

이 디렉터리는 아직 생성기 서비스가 아니다. GUI·공용 게이트웨이·참조 이미지 검출·입력 선택·작업 이력과 저장은 연결되지 않았다. `humanml3d.adjust_humanml3d_proportions`는 입력 `[T,22,3]` HumanML3D 관절과 Kimodo의 `body18-reference-ratios-v4` 결과를 받아 어깨와 골반 너비 및 위팔·아래팔·허벅지·종아리 길이를 조정한다. 원본 관절 배열은 바꾸지 않고 골반, 몸통 및 발목 상대 발 벡터를 유지한다. 코 기준 몸통 축·얼굴·손가락·무기는 대응 관절이 없어 수정하지 않는다. 발 접지와 신체·무기 충돌은 검증하지 않는다.

2026-11-22 기존 AnimationGPT 160프레임 모션과 기본 캐릭터 8방향 시트에서 Kimodo가 실제로 검출한 6개 인물 관측으로 계산한 비율을 이용해 임시 보정했다. 입출력 좌표 유한성과 골반 보존을 확인했으며 애니메이션의 체형 정확도, 관절 연속성, 발 접지와 캐릭터 비율을 시각 승인한 것은 아니다. 기존 비율 기록을 재사용한 것으로, 이 기능이 이미지를 독립적으로 검출한 것은 아니다.

`vace_pose_export.export_vace_pose`는 HumanML3D 22관절을 BODY18에 대응시키고 Y축 기준 정사영한 뒤 VideoX-Fun DWPose 색상·선 규칙으로 832×480, 16fps MP4를 만든다. 원본 FPS로부터 선형 보간하며 카메라는 전체 클립에 고정한다. 변환된 전체 프레임 수가 5~129의 4n+1이 아니면 오류를 표시한다. 자동 절단·분할·프레임 복제는 하지 않는다. `pose-export.json`에는 원본 파일·해시, 원본 프레임 위치, 영상 해시·구간·카메라·누락 관절과 전달된 출처를 기록한다. 0도는 세계 좌표의 X축 화면 투영이며 캐릭터의 정면이나 우측 보장은 아니다.

2026-11-22 과거 시험에서는 160프레임 모션을 변환한 뒤 여러 MP4로 분할했다. 이 자동 분할 기능은 폐기했으므로 같은 출력을 현행 동작으로 보지 않는다. 전체 동작의 시각 품질·VACE 추론·무기 유지 여부는 검증하지 않았다. 직접 투영을 DWPose 검출로 표현하지 않으며 코·눈·귀·손가락·무기와 가림 판정을 생성하지 않는다. 이 출력 기능 또한 관리 화면과 게이트웨이에 연결되지 않았다.

얼굴 처리에는 Kimodo의 참조 얼굴 앵커 계산을 검토한다. 폐기된 ANNY 리그와 MoMask 생성 경로는 사용하지 않는다.

`face_anchors.estimate_face_anchors`는 등록된 Kimodo 8방향 시트 중 정면·측면 얼굴 좌표를 사용해 코·양쪽 눈·양쪽 귀를 근사한다. 첫 프레임 몸통을 참조에 정렬하고 몸통 길이로 크기를 고정한 뒤 목→머리 방향과 어깨 축으로 방향을 추정한다. 첫 프레임의 머리 자세가 참조 정면에 대응한다는 **미검증 가정**이 있으며 몸통과 독립된 머리 좌우 회전, 가림과 얼굴의 실제 표면은 알 수 없다. 3D 참조 형상은 정사영·동일 배율·깊이 대칭을 가정한다.

`export_vace_pose(..., include_face=True)`로 얼굴점을 포함할 수 있다. 기본값은 꺼져 있고 16fps 재표본 관절에서 추정한다. 출력 JSON에 참조 이미지·설정 해시, 추정 방법·크기·한계를 남긴다. confidence 1은 추정 좌표 존재 표시이지 검출 신뢰도나 가시성 판정이 아니다. 뒤통수에서도 얼굴점이 그려질 수 있다. 2026-11-22 한손검 예시로 125·5프레임 출력과 수학적 변환 검사를 수행했으며 얼굴의 배치·시선 정확도 및 VACE 생성 품질은 미검증이다. UI·게이트웨이에는 연결되지 않았다.

`estimate_face_anchors(..., local_offset=(x,y,z))`와 `export_vace_pose(..., include_face=True, face_local_offset=(x,y,z))`는 얼굴점 전체를 머리 기준 로컬 좌표로 평행 이동한다. 축은 오른쪽 어깨→왼쪽 어깨를 목 축에 직교화한 방향, 목→머리 방향, 두 축의 외적 순서이며 단위는 첫 프레임 몸통 길이이고 각 값은 -1~1이다. 원본 관절과 얼굴 내 점 간 3D 거리는 유지한다. 기본값은 `(0,0,0)`이고 출력 기록에 오프셋과 참조 해시를 저장한다. 오프셋 후보는 수동 검수를 위한 가정으로 자동 채택하지 않는다. 이 계산은 UI·게이트웨이에 연결되지 않았다.
