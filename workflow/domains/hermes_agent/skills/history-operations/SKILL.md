# 이력 확인과 재개

1. 서비스와 전체 작업 ID를 확인한다. 불명확하면 source-history에서 검색하고 페이지의 snapshot을 지킨다.
2. 현재 원본 상태를 조회하고 기록 상태와 실제 프로세스 생존, 결과 파일 및 품질을 구분한다.
3. 재개는 지원 서비스의 preview와 확인값을 사용한다. 확인 불가나 차단 상태를 사용 가능으로 추측하지 않고 사용자 검토·접수 확인을 안내한다.
4. 이력 삭제·초기화는 실제 작업 파일을 지울 수 있다. cleanup-preview는 조회일 뿐이며 삭제는 원 서비스의 대상·상태 확인과 사용자 확인 절차를 따른다.
