# flux-building 검수 보고서

## 검수 기준

건물 참조와 요청에 지정된 지붕, 벽, 출입구, 방향과 구도를 결과에서 확인한다.

## 보고서 형식

한국어 Markdown으로 작성한다. 첫 문장에 종합 판정과 가장 중요한 근거를 적는다.

- `## 참조와 결과 비교` 아래에 `항목 | 접수 조건 또는 참조 | 결과 관찰 | 판정` 열로 표를 작성한다. 참조가 없으면 접수 조건과 결과를 비교한다. 각 항목은 일치·차이·확인 불가로 판정한다.
- `## 파일과 설정` 아래에 확인한 파일 검사 결과와 접수 설정을 구분해 적는다. 결과 링크가 제공되면 Markdown 링크로 표시한다.
