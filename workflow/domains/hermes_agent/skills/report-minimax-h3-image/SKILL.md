# minimax-h3-image 검수 보고서

## 검수 기준

접수된 이미지 폼을 기준으로 result_image 관찰과 결과 PNG를 비교한다. 사과처럼 지정된 피사체의 종류·개수·색·위치, 배경, 문자·워터마크 조건을 요청된 항목만 평가한다. 원 요청에서 폼으로 수정한 조건은 변경 사항으로 기록한다. 결과가 수정된 폼을 충족하면 최초 요청과의 차이를 생성 실패로 판정하지 않는다. 크기와 해시는 파일 검사 근거로, 시각 조건은 관찰 근거로 설명한다. 관찰에 없는 세부 사항은 확인 불가로 표시한다. 정지 이미지 보고서는 이미지 조건에 집중한다.

참조가 있으면 reference_comparison의 두 이미지 관찰을 사용한다. 검이 있는 장면에서는 각 이미지에서 손잡이에 닿은 손의 수와 다른 손의 위치를 구분한다. 검 방향은 화면 기준 손잡이에서 칼끝으로 읽는다. 손의 접촉 또는 칼끝이 가려지거나 관찰이 서로 모순되면 해당 항목은 확인 불가로 표시한다. 프롬프트와 해시만으로 자세를 추정하지 않는다.

화풍·캐릭터 일관성 검수 요청에서는 참조와 결과의 얼굴·머리·체형·의상, 윤곽선·음영·질감·색을 각각 눈으로 비교한다. 포즈·카메라 변경으로 비교할 수 없는 부분은 확인 불가로 표시한다. 프롬프트·참조 역할·공용 화풍·시드·크기·모델 정밀도와 관찰 표본 수를 구분한다. 한 장의 성공이나 실패를 반복 재현성 또는 모델 전체 능력으로 일반화하지 않는다. 조건이 함께 바뀌었다면 원인을 단정하지 않는다.

샘플러를 비교할 때 저장 요청·결과·로그에서 Euler 또는 LCM, 6스텝, 시드와 생성·최종 크기를 확인한다. 이전 기록에 샘플러 필드가 없으면 Euler로 설명한다. LCM은 별도 시드 난수로 매 단계 노이즈를 추가하므로 같은 시드가 Euler와 같은 전체 난수열을 의미하지 않는다. 생성기 LCM은 실험 기능이고 ComfyUI 난수열 동등성과 반복 품질은 미검증이다. 참조·프롬프트·시드·크기 등이 다르면 그 차이를 밝히고 샘플러만의 효과로 판정하지 않는다.

- `## 참조와 결과 비교` 아래에 `항목 | 접수 조건 또는 참조 이미지 | 생성 결과 | 판정` 열로 표를 작성한다. 참조가 없으면 접수 조건과 결과를 비교한다. 각 항목은 일치·차이·확인 불가로 판정한다.
