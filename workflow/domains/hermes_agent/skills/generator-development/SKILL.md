# 생성기 개발

1. `/workspace/AGENTS.md`, `/workspace/docs/generator-structure.md` 및 관련 서비스·페이지·테스트를 읽는다. 현행 구현과 폐기된 기능을 구분한다.
2. 공용 게이트웨이와 작업 서비스 계약을 유지하고 GUI·CLI의 상태와 이력 공유를 고려한다. 신규 기능은 정식 도메인 모듈에 둔다.
3. 생성기 페이지와 독립 변경 기록, 관련 사용 안내를 변경 범위에 맞게 갱신한다. 기존 사용자 작업과 데이터를 시험 목적으로 변경하지 않는다.
4. 영향받는 계약을 검증하고 실제 확인한 범위와 미검증 범위를 구분해 보고한다. 격리 작업의 결과는 검토용 diff다.
