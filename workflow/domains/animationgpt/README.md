# AnimationGPT 추론 준비

이 디렉터리는 생성기 서비스가 아니라 데이터셋 없이 모델을 불러오는 실험용 추론 구성이다. 관리 게이트웨이, GPU 대기열, GUI, 생성 이력, 영상 또는 무기 트랙 출력은 연결되지 않았다. 현행 Kimodo 서비스를 변경하지 않는다.

`pipeline.run_pipeline`은 격리 작업 프로세스에서 프롬프트로 관절을 생성하고 VACE 포즈 영상과 출처를 같은 새 출력 디렉터리에 기록하도록 준비한 내부 함수다. 입력을 검증하고 원본 소스 리비전·추적 파일 변경 여부 및 모델 관리의 준비 표식을 확인한다. 별도 모션 생성기 서비스·도구 카탈로그·GUI·생성 이력에는 아직 등록되지 않았으며 전체 실행도 검증하지 않았다. 포즈는 직접 투영이며 무기 궤적은 제공하지 않는다.

공식 MotionGPT 소스 `001aaca8d0ee218fc17f8265d11ac124044fe42f`를 `.local/animationgpt/upstream`에 준비하고 모델 관리의 AnimationGPT 파일을 사용한다. 모델은 제3자 FP16 변환본이다. 입력과 출력 임베딩은 다른 가중치이므로 Transformers 5에서 원본 FLAN-T5의 `tie_word_embeddings=false`를 명시적으로 복원한다. 모델이 모션 경계를 누락하면 공식 코드의 `[0]` 대체 출력을 받아들이지 않고 실패한다.

2026-11-22 CPU 시험: 전체 CombatMotion 데이터셋 없이 `a man holding a katana and swinging his sword diagonally downward.`와 시드 42에서 26개 모션 토큰, 20fps 104프레임, 프레임당 22개 관절의 유한 좌표를 반환했다. 원본 웹 UI의 정규화 통계를 사용했으며 CMP 학습 분포에 적합한지 검증하지 않았다. 재생·시각 품질·검술 정확도·ROCm·GPU 대기열은 검증하지 않았다. 결과에는 무기 형상과 무기 궤적이 없으므로 영상 생성의 무기 유지 문제를 해결했다고 볼 수 없다.

모델 파일의 출처·라이선스와 다운로드는 모델 관리 설명을 따른다. 실행 전 모델 해시, 공식 소스 리비전·변경 여부 검증과 격리된 작업 프로세스가 필요하다.

2026-11-22 짧은 한손검 지시문에서 모델이 모션 토큰 대신 자연어 동작 설명을 생성해 경계 검증에 실패하는 현상을 확인했다. 추론은 모션 시작 토큰을 제공하고 유효한 모션 코드와 종료 토큰만 허용하도록 변경했다. 최소 한 개의 코드가 필요하며 길이 상한에 도달해 종료 토큰이 없으면 계속 실패로 처리한다. 이 제약은 샘플링 분포를 바꾸므로 정식 체크포인트의 재학습이나 동작 정확성을 뜻하지 않는다. 같은 지시문·시드의 CPU 재실행에서 유효한 코드와 136프레임 좌표를 확인했으며 신체 동작·검술 품질은 별도 검수한다.

2026-11-22 제작자 방식 적용: 파이프라인은 격리된 `.local/animationgpt-legacy/venv`의 Python 3.10.22, PyTorch 2.0.1 CPU, Transformers 4.38.2에서 제작자 원본 FP32 텐서와 FLAN-T5 기본 가중치를 사용한다. 원본 문장으로 제약 없는 샘플링을 수행하되, 공식 파서의 0번 대체와 손상된 모션 토큰은 오류로 처리한다. 가중치 해시, 환경·입력·시드·어텐션 경로를 결과에 기록한다. 체크포인트의 정규화 통계와 모델 관리 통계는 일치한다. 파일명 `AnimationGPT_fp16.safetensors`는 기존 호환 이름이며 제작자 디렉터리 안의 텐서는 FP32다. 원본 CKPT 및 Python 환경은 모델 관리 준비와 별도다. FLAN-T5의 현재 준비·복구 동작은 아래 설명을 참고한다.

이 경로의 Transformers 4.38.2 T5는 행렬곱·softmax를 직접 사용하며 PyTorch SDPA를 호출하지 않는다. 검증되지 않은 SDPA 우회를 전역 적용하지 않았다. CPU 실험이며 GPU 대기열·ROCm·NVIDIA CUDA 및 중간 어텐션 수치는 미검증이다. 원본 Ubuntu 22.04·RTX 4090 환경이나 전체 공식 데모 실행의 완전 복제는 아니다. 120프레임 모션은 VACE 16fps 변환 시 96프레임으로 VACE의 4n+1 조건에 맞지 않으므로 관절 결과를 보존하고 포즈 변환 불가 사유를 기록한다. 자동 절단은 하지 않는다.

2026-11-22 ROCm 이전 준비: `rocm_inference.generate_rocm`은 ROCm GPU와 공용 GPU 대기열 환경을 요구하고 CPU 대체를 거절한다. 모델·관절을 GPU에서 실행하고 T5 어텐션 출력, 생성 점수, 모션 특징과 최종 관절의 비유한 값을 거부하도록 준비했다. 이 경로는 아직 실제 GPU에서 실행·수치 검증되지 않았고 GPU 대기열 작업 서비스, 생성 요청·상태·이력 및 화면에 연결되지 않았다. 제작자 CPU 환경과 달리 현재 ROCm 환경의 Transformers를 사용하므로 동일한 결과를 보장하지 않는다. 모델 파일 준비 여부를 ROCm 생성 준비 완료로 해석하지 않는다.

제작자 방식 FLAN-T5 Base는 `.model/flan-t5-base`를 우선 사용한다. 가중치와 토크나이저의 독립 설치이며 기존 `.local/animationgpt-legacy/flan-t5-base`는 새 경로가 없는 경우 호환 경로로 남긴다. 실행 환경은 여전히 `.local/animationgpt-legacy/venv`에 별도 설치되어야 한다. 가중치의 고정 SHA-256은 실행 전에 검사한다.

모델 관리의 AnimationGPT 준비는 FP16, FLAN-T5 Base, 제작자 방식 가중치를 고정 SHA-256으로 확인한다. FLAN-T5는 Samba를 먼저 확인하고 사용할 백업이 없으면 공급처에서 내려받는다. 제작자 가중치는 Samba에서만 자동 복원하며 사용할 백업이 없으면 준비가 실패한다. Python 실행 환경은 별도다.
