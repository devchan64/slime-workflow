# MiniMax H3 영상 편집 사용설명

원본 MP4와 편집 프롬프트를 사용해 새로운 영상과 소리를 생성합니다. 원본의 동작이 조건으로 사용되며 결과는 재생성되므로 원본과 정확히 같거나 편집 지시가 반드시 반영된다는 보장은 없습니다.

832×480, 24fps, 124프레임 MP4 한 개를 선택합니다. 파일은 27MiB 이하여야 합니다. 출력은 같은 해상도와 프레임 수, Turbo 8스텝을 사용합니다. 프롬프트에 유지할 인물·배경·동작과 바꿀 내용을 구체적으로 씁니다. 원본 오디오는 참조하지 않으며, 프롬프트에 따라 새 오디오를 생성합니다. 입력 파일의 사본과 해시가 작업 기록에 보관됩니다.

Diffusers Ref2VA, FP8 저장·BF16 GPU 계산, INT8 텍스트 인코더와 8스텝 Turbo LoRA를 사용합니다. 어텐션은 연속 배치 경로를 사용합니다. 입력 조건이 지원 범위를 벗어나거나 GPU 여유 메모리가 부족하면 작업을 중단합니다. 480p는 실험 설정입니다. 생성 완료와 출력 품질은 별도로 확인해야 합니다.

MiniMax H3와 가중치의 라이선스 및 해당 사용자의 개별 허가 조건이 적용됩니다.
