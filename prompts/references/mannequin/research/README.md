# 마네킨 연구 자료

기존 v1~v4를 버전별로 통합 보관한다. 이미지와 생성 프롬프트·출처 기록을 함께 유지한다.

- `v1/`: 신체 유형과 피부·기본복, 중성형 초기안
- `v2/`: 중성형 골반 확장
- `v3/`: 중성형 어깨 축소
- `v4/`: 중성형 허리 축소

현재 지정한 중성형 신체는 [latest](../latest/neutral-body-four-directions.png)를 사용한다. 전체 자료의 용도와 채택 상태는 [상위 색인](../README.md)을 따른다.
