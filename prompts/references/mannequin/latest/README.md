# 현재 마네킨 참조

캐릭터 생성에 사용하는 현재 중성형 신체 마네킨 기준을 관리한다. 파일별 채택 상태를 구분하며, 이 경로에 있다는 이유만으로 모든 이미지를 승인된 기준으로 취급하지 않는다.

## 기본형 얼굴

- [중성형 기본 얼굴 4방향](neutral-head-basic-four-directions.png)
- [생성·등록 기록](neutral-head-basic-four-directions.yaml)

사용자가 채택한 연구 v10의 복사본이다. 눈·코·입의 크기와 간격, 턱선의 기준으로 사용한다.

## 배치와 비율

- 이미지는 2×2 구성이다. 좌상 정면, 우상 앞쪽 쿼터, 좌하 측면, 우하 후면이다.
- 성인 평균 5등신을 출발 기준으로 한다. 정확한 등신 수치나 이미지 간 비율 일치를 실측으로 보증한 자료는 아니다.
- 현재 신체는 좁은 어깨, 가는 허리와 넓힌 골반을 적용한 중성형이다. 생성 시 머리 크기·키·팔다리 길이를 함께 유지한다.
- 방향별 좌우와 시점을 확인하고 사용한다. 4방향 시트를 연속 회전 프레임으로 간주하지 않는다.

## 사용 방법

1. 신체 비율을 지정할 때는 관절 분리형 마네킨을 참조한다. 회색 표면과 기계식 관절은 캐릭터 외형에 복제하지 않는다.
2. 피부와 기본복을 생성할 때 기존 신체 비율과 자세를 보존한다. 피부·기본복 적용 이미지는 아래 사용자 지정 명칭의 등록 자료를 참고한다.
3. 얼굴과 머리카락은 별도 단계에서 추가한다. 얼굴을 추가하면서 머리 외곽이나 전신 비율까지 재설계하지 않도록 참조 역할을 명시한다.
4. 결과는 같은 전신 높이로 정렬해 턱·어깨·가랑이·무릎 위치와 몸통 폭을 비교한다. 머리카락 부피는 등신 계산에서 제외한다.

참조 등록은 생성기의 기본 입력을 자동 변경하지 않는다. 화풍은 [공통 화풍](../../../common/art-style.md), 외관은 [캐릭터 외관 기준](../../../common/character-appearance.md)을 함께 따른다.

## 저장·갱신 규칙

- PNG와 같은 이름의 YAML을 함께 관리한다. YAML에 출처·참조 이미지·채택 상태·이미지 해시를 기록하고, 생성 자료에는 실제 프롬프트·단어 수·프롬프트 해시를 보존한다.
- `neutral-body-four-directions.png`는 사용자 첨부 원본이다. 연구 v4와 파일 해시가 다르므로 동일 파일이라고 취급하지 않는다.
- 실험 버전은 [research](../research/README.md)에 보존한다. 현재 기준의 교체는 사용자 지시에 따라 수행하고 색인과 참조 경로를 함께 갱신한다.
- 전체 신체 유형과 얼굴 기준은 [마네킨 전체 색인](../README.md)에서 확인한다.

## 생성 결과 저장 위치

새 이미지 생성·수정 결과는 `latest/`에 직접 저장하지 않는다. `research/<버전>/`에 이미지와 생성 기록을 보존하고, 사용자가 반영을 지시한 경우에만 `latest/`를 갱신한다.

제작·검수·등록 절차: [마네킨 기반 기본형 관리](../../../../workflows/character-baseline-mannequin.md)
