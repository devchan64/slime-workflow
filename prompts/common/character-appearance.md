# 캐릭터 외관을 그리는 기준 공통 프롬프트

관리 원문: [character-appearance-v1.yaml](character-appearance-v1.yaml), 버전 1.0.0. 기본 캐릭터의 기존 `base-prompt`를 역할별로 정리했으며 기존 원문을 교체하지 않는다.

## 공통 외관 기준

표현력 있는 눈, 간결한 코·입, 부드러운 턱선과 묶음 형태의 머리카락을 사용한다. 여러 방향·포즈에서도 지정한 얼굴 특징·눈색·머리·체형·복장을 유지한다. 특정 성별·갈색 머리·회색 복장을 모든 캐릭터에 강제하지 않는다. 현재 원문은 성인 캐릭터용이다.

## 캐릭터별 필수 입력

| 항목 | 지정 내용 |
| --- | --- |
| 정체성 | 성별 표현·나이 인상·고유 얼굴 특징 |
| 외형 | 머리 형태와 색·눈색·피부색 |
| 체형 | 목표 등신·체격·팔다리 비율 |
| 기본복 | 상의·하의 길이, 맞음새, 소재·색, 신발 여부 |
| 출력 | 방향 수·배치·자세·카메라·배경·해상도 |

## 5등신 기준과 주의점

프로젝트 종합 기준의 목표는 머리 1·몸통과 골반 2·다리 2이다. 머리는 두개골 정수리~턱으로 정의하고 머리카락 부피와 구분한다. 정수리를 0으로 잡으면 턱 20%, 가랑이 60%, 발바닥 100%가 목표이다.

성인이라는 나이 표현은 긴 성인 실사 비율을 요구하는 지시가 아니다. 반대로 큰 머리·짧은 팔다리를 과도하게 강조하면 목표보다 짧아질 수 있다. v7~v9 실험에서는 양쪽 현상이 나타났으며 단일 단어가 원인이라고 확정하지 않는다.

공통 원문에는 등신 숫자를 반복하지 않고 과제별 비율 블록으로 앞에 배치한다. 지정 숫자는 생성 보장이 아니다. 정면에서 머리·전신 길이를 확인하고, 회전·머리카락·신발로 인한 측정 오차를 기록한다. 8방향은 동일 체형과 배율인지 따로 검수한다.

짧은 기본복은 착장 교체를 위한 과제별 선택이다. 현재 여성 A의 크롭 상의·숏팬츠를 모든 캐릭터의 필수 복장으로 승격하지 않는다.
