# 공통 프롬프트 변경 이력

## 2026-11-09 · 구버전 공통 프롬프트 폐기

- 사용자 지시에 따라 화풍 1.0.0~1.4.0과 캐릭터 외관 1.0.0~1.1.0 원본을 폐기했다. 현재 화풍 1.5.0과 외관 1.2.0을 유지하며 생성 기록의 과거 출처는 보존한다.

## 2026-11-09 · 화풍 v1.5.0 및 캐릭터 외관 v1.2.0

- 선택한 부드러운 셀 음영, 절제된 디테일과 은은한 회화 질감을 반영했다.
- 지정한 눈 색을 방향 간 유지하도록 명시했다. 이번 캐릭터는 호박색 눈을 사용한다. 새 원문의 별도 생성 검증은 전이다.

## 2026-11-09 · 화풍 v1.4.0 및 캐릭터 외관 v1.1.0

- 최근 얼굴 실험의 회화적 2D 질감과 부드러운 음영을 공통 화풍으로 정리했다.
- 얼굴 비율 참조가 제공된 경우 이목구비와 턱 비율을 과장 없이 유지하도록 외관 원문을 갱신했다. 각 새 원문의 별도 생성 검증은 전이다.

## 2026-11-09 · 화풍 v1.3.0 개선 후보

- 사용자 지정 감정 컷인을 육안 분석해 따뜻한 색감, 섬세한 윤곽과 부드럽게 연결되는 음영을 반영했다. 이미지 참조 없이 얼굴 샘플을 생성했으며 사용자 검수 전이다. 기존 문서 기준은 유지한다.

## 2026-11-09 · 화풍 v1.2.0 변경

- 손으로 그린 2D 표현, 단순한 색면, 넓게 그린 그림자와 무광 형태를 추가했다. 조합된 실험 이미지는 확인했으나 새 원문 자체의 생성 검증은 전이다.

## 2026-11-09 · 화풍 v1.0.0 폐기

- 사용자 지시에 따라 `art-style-v1.yaml`을 폐기했다. 이전 생성 기록의 출처는 유지하며 신규 생성에는 사용하지 않는다.

## 2026-11-09 · 화풍 v1.1.0 변경

- 기본 캐릭터 컷인의 따뜻한 갈색 윤곽과 부드러운 회화식 명암을 반영했다. 44단어에서 42단어로 정리하고 고정 청록 회색 그림자와 좌상단 광원을 제외했다.
- 사용자 지시에 따라 현재 문서 기준으로 변경했다. 생성 검증 전이며 기존 v1.0.0과 생성기 연결은 유지한다.

## 2026-10-31 · 화풍 v1.0.0 한국어 관리 정보 보강

- `art-style-v1.yaml`에 `prompt_ko`와 한국어 번역 유지 정책을 추가했다.
- 영문 실행 원문·버전·단어 수·해시는 변경하지 않았다. 번역 동시 갱신과 실행 언어 분리 기준을 명시했다.

## 2026-10-31 · 최초 분리

- `slime_common_art_style` 1.0.0: 종합 화풍에서 형태·명암·광원·재질 역할을 분리했다. 카메라·배경·등신은 별도 조건으로 둔다.
- `slime_common_character_appearance` 1.0.0: 기본 캐릭터 참고 문구에서 얼굴 표현·외형 일관성 역할을 분리했다. 캐릭터별 색·복장·수치 비율은 별도 입력으로 둔다.
- 두 원문 모두 생성 검증 전이다. 기존 생성 기록과 생성기 연결은 변경하지 않았다.
- 여성 A v7~v9의 비율 이탈을 반영해 나이와 해부 비율의 구분, 과장 표현의 과보정 가능성, 실측 검수 조건을 문서화했다.

## 2026-10-31 · 체형 기준 유연화

- 사용자 정정에 따라 5등신을 절대 제한에서 체형 설계의 출발점으로 명시했다.
- 넓은 어깨 남성 관절형 마네킨을 추가했다. 과거 실행 프롬프트 원문은 유지한다.

## 2026-10-31 · 유사 마네킨 정리

- 기본형과 차이가 작은 청소년·노년 남녀형 및 역할이 겹치는 남녀 탄탄형 6종의 이미지·YAML을 제거했다.
- 신체 8종과 얼굴 2종으로 색인을 정리했다. 성인 평균 5등신 및 체형별 조절 기준은 유지한다.

## 2026-10-31 · 기준 얼굴 v3 채택

- 남녀 얼굴 비율 정리 v3를 기준으로 채택하고 v1·v2 얼굴 이미지와 YAML 8파일을 폐기했다.
- 과거 생성에 사용한 참조는 폐기된 출처로 명시하며, 기존 캐릭터 결과를 v3 생성으로 소급 변경하지 않는다.
