# 공통 프롬프트 변경 이력

## 2026-10-31 · 화풍 v1.0.0 한국어 관리 정보 보강

- `art-style-v1.yaml`에 `prompt_ko`와 한국어 번역 유지 정책을 추가했다.
- 영문 실행 원문·버전·단어 수·해시는 변경하지 않았다. 번역 동시 갱신과 실행 언어 분리 기준을 명시했다.

## 2026-10-31 · 최초 분리

- `slime_common_art_style` 1.0.0: 종합 화풍에서 형태·명암·광원·재질 역할을 분리했다. 카메라·배경·등신은 별도 조건으로 둔다.
- `slime_common_character_appearance` 1.0.0: 기본 캐릭터 참고 문구에서 얼굴 표현·외형 일관성 역할을 분리했다. 캐릭터별 색·복장·수치 비율은 별도 입력으로 둔다.
- 두 원문 모두 생성 검증 전이다. 기존 생성 기록과 생성기 연결은 변경하지 않았다.
- 여성 A v7~v9의 비율 이탈을 반영해 나이와 해부 비율의 구분, 과장 표현의 과보정 가능성, 실측 검수 조건을 문서화했다.

## 2026-10-31 · 체형 기준 유연화

- 사용자 정정에 따라 5등신을 절대 제한에서 체형 설계의 출발점으로 명시했다.
- 넓은 어깨 남성 관절형 마네킨을 추가했다. 과거 실행 프롬프트 원문은 유지한다.

## 2026-10-31 · 유사 마네킨 정리

- 기본형과 차이가 작은 청소년·노년 남녀형 및 역할이 겹치는 남녀 탄탄형 6종의 이미지·YAML을 제거했다.
- 신체 8종과 얼굴 2종으로 색인을 정리했다. 성인 평균 5등신 및 체형별 조절 기준은 유지한다.

## 2026-10-31 · 기준 얼굴 v3 채택

- 남녀 얼굴 비율 정리 v3를 기준으로 채택하고 v1·v2 얼굴 이미지와 YAML 8파일을 폐기했다.
- 과거 생성에 사용한 참조는 폐기된 출처로 명시하며, 기존 캐릭터 결과를 v3 생성으로 소급 변경하지 않는다.
