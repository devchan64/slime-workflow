# 화풍 관리용 공통 프롬프트

관리 원문: [art-style-v1.yaml](art-style-v1.yaml), 버전 1.0.0. 원문은 YAML에만 두고 이 문서에는 기준을 설명한다.

## 한국어 번역 유지 기준

`art-style-v1.yaml`의 `prompt`는 영문 실행 원문, `prompt_ko`는 한국어 관리·검수용 번역이다. 두 필드를 같은 파일에서 함께 유지하며, 번역을 생략하거나 별도 문서의 사본으로만 관리하지 않는다.

영문 원문을 변경하면 새 버전에 번역도 함께 반영하고 의미의 추가·누락을 확인한다. 한국어 번역을 실행 원문으로 자동 대체하거나 두 언어를 결합하지 않는다. 실행 언어를 변경하는 실험은 별도 버전·실행 기록으로 구분한다. 단어 수와 해시는 기존 영문 원문 기준을 유지한다.

## 화풍 표현

- 미니어처 판타지 게임 일러스트레이션을 기준으로 한다.
- 작은 크기에서 읽히는 넓은 색면과 단순한 둥근 형태를 우선한다.
- 밝음·중간·어두움의 큰 명암을 부드럽게 연결한다.
- 좌상단 확산광, 청록 회색 그림자, 절제된 반사광을 유지한다.
- 머리카락과 재질은 묶음 형태와 큰 단서로 표현한다. 잔무늬보다 실루엣을 우선한다.
- 피부·천을 광택 플라스틱으로 해석하지 않는다. 젤·금속 등 필요한 재질은 대상별로 지정한다.

## 분리할 조건

성별·등신·복장·포즈·카메라·배경은 화풍 원문에 고정하지 않는다. 정면 참조와 게임용 3/4 시점, 흰 배경과 투명 배경은 출력 목적에 따라 선택한다. 이전 종합 기준의 카메라·출력 문구를 중복 추가하지 않는다.

## 검수

동일 대상·구도·출력 규격으로 비교하며 색면, 명암, 재질, 작은 크기의 판독성을 확인한다. 화풍 변경과 체형 변경을 별도로 기록한다. 같은 프롬프트도 동일한 결과를 보장하지 않으며 현재 v1.0.0은 분리 문서 작성 후 생성 검증 전이다.
