1. 적용할 프레임

편집 모드

원본을 불러오면 적용 대상 수가 표시됩니다.

좌표 입력은 변경한 항목만 적용합니다. 1px 이동·크기 조절은 각 프레임에 같은 변화량을 적용합니다. 캔버스 드래그·가이드 지정·원본 복원은 개별 작업입니다.

적용할 프레임 선택

일부 프레임을 체크하면 ‘선택한 프레임들’ 모드로 전환됩니다. 미리보기 프레임을 이동해도 체크한 대상은 유지됩니다.

2. 속성값
