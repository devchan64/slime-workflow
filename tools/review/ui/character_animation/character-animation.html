등록된 모션과 캐릭터 레퍼런스로 방향별 애니메이션을 만듭니다. 프레임 간격 선택 · 방향별 생성

생성 설정

프레임 간격: 생성할 원본 포즈를 몇 프레임마다 고를지 결정합니다.

생성 스텝: 이미지 한 장을 만드는 연산 횟수입니다. 30스텝은 시간이 더 걸립니다.

재생 FPS: 검수 화면에서 초당 보여주는 이미지 수입니다. 생성 장수는 바뀌지 않습니다.

30스텝은 Lightning을 사용하지 않으며 생성 시간이 더 걸립니다.

생성할 방향

ANNY 입력은 등록된 리그의 렌더 이미지를 사용합니다.
