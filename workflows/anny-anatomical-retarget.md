# ANNY 해부학적 리타기팅 적용 기준

## 출처와 적용 범위

- 관절 좌표계 기준: Wu 등(2005), ISB Part II, DOI `10.1016/j.jbiomech.2004.05.042`.
- 원문: https://media.isbweb.org/images/documents/standards/Wu%20et%20al%20J%20Biomech%2038%20(2005)%20981%E2%80%93992.pdf
- 이 문헌은 해부학적 기준점·좌표계·회전 보고 규약이다. 범용 가동 범위 제한값의 근거로 대체 사용하지 않는다.
- 회전 계약: 고정 HY-Motion upstream의 `hymotion/pipeline/body_model.py`와 `hymotion/utils/geometry.py::rot6d_to_rotation_matrix`. 6D 값을 `[3,2]`로 해석하는 열 우선 방식이다. 같은 파일의 행 우선 `rotation_6d_to_matrix`와 혼용하지 않는다.

## 적용 전 필수 조건

1. 원본 22개 로컬 회전과 부모 계층을 보존하고 FK로 저장 관절 위치와 일치하는지 검사한다. `generators/hy_motion/rotation_channels.py`를 사용한다. 손목 회전은 존재하지만 30개 손가락 관절은 공식 Wooden 경로에서 항등 회전으로 확장되므로 생성된 손가락 동작으로 해석하지 않는다.
2. 원본·대상 각각의 본 축과 해부학적 좌표계 사이 보정 행렬, 기준 자세, 좌우 부호 규약, 출처·자산 해시를 기록한다. ANNY 본 로컬 Y축이나 기준 자세만으로 해부학적 굽힘축이라고 단정하지 않는다.
3. 어깨의 몸통·쇄골·견갑·상완 대응, 팔꿈치의 상완 내외측 기준점, 전완·손목의 요측/척측 기준점 및 손바닥 방향을 확인한다. 대응이 없는 구조는 별도로 명시하고 완전한 해부학적 모델로 표시하지 않는다.
4. 가동 범위는 회전축·좌표계·능동/수동 조건 등 적용 조건과 출처가 있는 보정 프로필에서만 받는다. 보정 자료가 없으면 해부학적 제약 모드의 적용은 중단한다. 보편적 수치를 추정하여 채우지 않는다.

## 전달 규칙

- 어깨 방향·상완 축 회전, 팔꿈치 굽힘, 전완 회내·회외, 손목 굽힘·편위를 구분한다. 관절 위치만으로 미관측 축 회전을 복원했다고 보고하지 않는다.
- 원본 회전을 해부학적 좌표계로 변환하고 대상의 보정된 좌표계로 전달한다. 회전 정보를 보존하는 것과 손바닥 비틀림을 그대로 복사하는 것은 다르다.
- 대상 뼈 길이·기준 메시·체형을 보존한다. 도달 불가·관절 제한·접촉 요구가 충돌하면 잔여 오차와 이유를 기록한다. 손목 목표를 위해 팔꿈치 굽힘 방향을 뒤집지 않는다.
- 표면 충돌은 대상의 실제 메시로 별도 평가한다. 충돌 회피는 해부학적 가동 범위와 동작의 접촉 의도 안에서 최소한으로 자세를 변경해야 한다.
- 임의의 4cm/3cm 손목 이동, 15도 어깨 한도, 원본 벌림각 하한은 기존 실험 조건일 뿐이다. 해부학적 공통 규칙·기본값으로 승격하지 않는다.

## 현재 상태

회전 채널 복원·FK 검증은 구현했다. 기존 위치 기반 실험의 결과와 구분한다. ANNY의 해부학적 기준점 대응·축 보정 및 가동 범위 프로필은 아직 검증되지 않았으므로 해부학적 제약 솔버의 기본 적용은 미완료다. 기존 실험용 함수와 기본 생성 경로는 이를 우회하여 해부학적 검증 완료로 표시해서는 안 된다.

## 손 기준점 회전 전달 분리 실험

기준점 후보 검수 도구는 아래 별도 절을 따른다. 이 손 프레임 실험의 검증 수준을 자동 승격하지 않는다.

`generators/hy_motion/config/anny-hand-landmarks.yaml`은 HY-Motion의 이름 있는 손목·중지·검지·소지 기저 관절과 ANNY MPFB `rig.default.json`의 해당 본 머리를 대응시킨다. `hand_frame_transfer.py`는 손목→중지 기저를 길이 축, 소지→검지 기저의 직교 성분을 가로 축으로 삼는다. 외적은 오른손 기준계를 만드는 계산용 법선이며, 좌우의 해부학적 손바닥 바깥 법선이라고 자동 해석하지 않는다.

원본 회전과 원본 기준 손 좌표계로 현재 손 좌표계를 구한 뒤, 대상 기준 손 좌표계와 손목 본 기준 회전의 차이를 보정한다. 본 로컬 Y축을 손 길이 축으로 가정하거나 좌우 Euler 부호를 임의로 반전하지 않는다. 소스와 대상은 먼저 같은 좌표계로 변환해야 한다.

이 설정의 `anatomical_joint_limits_verified`는 `false`다. 손가락 기저 기반 손 좌표계 정렬은 가능하지만, 임상적 손목 관절축·요골/척골 축·팔꿈치 내외측 돌기·견갑골 기준점의 검증을 대신하지 않는다. 현재 손목만 전달하는 분리 실험이며, 위팔·전완 축 회전까지 완료한 것으로 보고하지 않는다. 기준점 순서·출처·설정 해시와 원본 모션 해시를 결과에 보존하고, 어깨·팔꿈치·손목 위치 및 비대상 로컬 자세 불변을 검증한다. 가동 범위 제한이나 임의의 손목 위치 이동은 적용하지 않는다. 설정은 `load_hand_calibration`으로 중복 키·필드·형식·좌우 대응을 검사한다.

## ANNY 기준점 후보 검수 도구

관리 메뉴의 **ANNY 해부학 기준점 검수**(`/management/frame/anny-landmarks/`)에서 `anny-neutral-v4` 원본에 양측 어깨 중심·팔꿈치 내외측·요골/척골 경상돌기 후보를 지정한다. Gradio 표준 입력과 기존 ANNY WebGL 메시 미리보기를 사용하며 모델 추론·리타기팅은 실행하지 않는다.

1. 메시를 회전·확대하고 표면을 클릭한다. 선택은 가시 삼각형의 가장 가까운 정점에 스냅한다. ‘선택 좌표 읽기’ 후 근거를 입력하고 ‘후보에 반영’을 누른다.
2. 어깨 중심처럼 피부 표면과 다른 위치는 `manual_xyz`로 수동 지정한다. 표면 클릭은 뼈 위치를 자동 추정하거나 정확성을 보장하지 않는다. 좌표는 미터, Z-up, +X 왼쪽, −Y 전방이다.
3. 한쪽 다섯 기준점이 모두 있으면 상완·전완의 기하학적 직교 축을 표시한다. 상완의 길이축은 팔꿈치 내외측 중점→어깨 후보, 가로축은 내측→외측의 직교 성분이다. 전완은 손목 두 후보 중점→팔꿈치 중점, 척측→요측의 직교 성분을 사용한다. 세 번째 축은 길이축×가로축이다. 좌우 모두 오른손 계산 좌표계이며 임상 부호 규약은 아직 없다. 중복·공선 기준점에서는 축을 만들지 않는다.
4. 저장은 매번 새 후보 ID를 만들고 기존 기록을 덮어쓰지 않는다. 이력 불러오기는 미저장 입력 교체 확인이 필요하다. 브라우저 재연결로 미저장 후보가 사라질 수 있으므로 명시적으로 저장한다.

후보는 `.tmp/test/anny-landmarks/<KST 시각>/<고유 ID>/candidate.json`에 원본 NPZ·검증 파일 SHA-256, 좌표 변환, 지정 방식·근거·좌표·경고와 함께 보관한다. 원본/좌표 변환이 바뀌면 불러오기를 거절한다. 모든 결과는 `candidate`, `anatomical_verified: false`다. 견갑·쇄골·흉곽·손바닥 기준계, HY-Motion 원본 대응, 가동 범위는 별도 검증 대상이다. **승인·자동 적용 명령은 없으며 이 도구만으로 해부학적 리타기팅 완성을 주장하지 않는다.**

GUI·CLI는 `anny-landmarks` 게이트웨이 서비스를 공유한다. 명령은 `landmark-source`, `landmark-preview`, `landmark-save`, `landmark-load`, `landmark-history`이며 `--payload-file`로 JSON 객체를 받는다. 원본/이력 조회는 `{}`, 불러오기는 `{"id":"시각/고유 ID"}`, 검수/저장은 `{"source": 원본 응답의 source, "points": {기준점 ID: {"position": [X,Y,Z], "method": "manual_xyz 또는 surface_pick", "evidence": "지정 근거"}}}`다. 알 수 없는 필드·기준점, 비유한 좌표·범위 이탈, 근거 누락, 원본 불일치를 거절한다.

```bash
.venv-management/bin/python tools/manager.py help anny-landmarks
.venv-management/bin/python tools/manager.py command anny-landmarks landmark-source --payload-file /absolute/path/empty-object.json
```
