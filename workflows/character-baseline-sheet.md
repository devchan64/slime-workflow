# 캐릭터 4방향 기준 시트 제작 절차

Codex 내장 image_gen으로 원형 이미지에서 2×2 기준 시트를 제작하는 실행 절차다. 모션·리그 기반 애니메이션 제작과 구분한다.

## 입력과 프롬프트 준비

1. 프론트엔드의 승인된 원형 베이스라인 한 장을 참조로 선택한다. 직전 생성 시트를 연쇄 참조하지 않는다.
2. 한국 시간의 `.tmp/YYYY-MM-DD_HH-mm-ss/`를 새로 만들고 원형 참조 사본, 실행 프롬프트, 생성 결과, 실행 로그와 출처를 함께 보관한다. 기존 실험을 덮어쓰지 않는다.
3. 정식 프롬프트 원본은 사용자 이전 지시에 따라 `prompts/character-baseline-four-directions-v1.yaml`에서 관리한다. 해당 YAML의 `prompt` 원문을 실행 폴더에 준비하고 `reference`에 지정된 승인 원형을 사용한다. 백엔드의 이전 사본은 삭제했다.
4. 현재 승인 계약은 외형·렌더링 스타일 유지와 전신 4방향 배치만 지정한다. 등신, 신체 부위별 비율·길이·폭, 체형 보정, 균등 배율, 별도 카메라 각도 지시를 추가하지 않는다. 문구 변경은 새 실험으로 검수한다.

## 생성

- 참조 이미지를 확인한 뒤 내장 image_gen에 준비된 프롬프트와 원형 참조 파일을 전달한다. 내장 도구가 실행 주체이며 이 문서는 별도 자동 실행기를 제공하지 않는다.
- 2160×2160 투명 PNG를 요청한다. 크기를 직접 강제하는 도구 인자가 없으므로 요청값을 실제 크기로 간주하지 않는다.
- 한 시트의 좌상/우상/좌하/우하 칸은 각각 화면의 좌상/우상/좌하/우하를 바라본다. 위 두 칸은 후면 쿼터뷰, 아래 두 칸은 전면 쿼터뷰다.
- 기본 출력 파일은 보존하고 해당 실행 폴더에 복사한다. 도구·모드·참조·프롬프트 버전·해시·요청 크기·실제 크기·원본 경로를 실행 기록에 남긴다. 내장 모델 이름은 추측하지 않는다.
- 크기 미달은 명시하고 임의 확대나 다른 모델/API로 전환하지 않는다. 2160×2160 필수 납품 조건이 있다면 미달 파일을 충족으로 처리하지 않는다. 사용자 승인 시 실제 크기를 기록해 등록할 수 있다.

## 비교와 승인

원형과 같은 방향인 좌하향을 중심으로 전신 높이를 맞춘 가이드라인을 만든다. 가로·세로 배율을 같게 유지하고 원본을 변형하지 않는다. 머리끝·턱·가랑이·발바닥 및 머리 폭을 표시한다. 좌표·수동 추정 오차·정규화 분모를 보관하고 원근·자세 차이를 명시한다. 후면과 반대 방향은 보조 비교로 사용한다.

측정 비율을 다음 생성 프롬프트의 체형 보정값으로 자동 주입하지 않는다. 단일 결과나 오차 범위 내 변화로 프롬프트 효과를 확정하지 않는다. 최종 채택은 사용자 지시로 결정한다.

## 전달과 등록

승인한 PNG 한 장만 프론트엔드 `src/assets/characters/baseline/`에 버전 있는 이름으로 복사한다. `image-assets.yaml`에 관리 ID·경로를 등록하고 sidecar YAML에 실제 크기·2×2 셀 좌표·참조·해시를 기록한다. 원형 단일 이미지와 함께 보관한다. 후보·가이드라인·프롬프트는 공개 에셋에 복제하지 않는다.

베이스라인 등록과 게임 런타임 채택은 별도다. 이미지 커밋 검사는 파일 존재·파일명·목적 경로로 제한하고 저장소별로 커밋한다. 정적 전달 구조·배포·AWS 비용에는 변경이 없다.

기존 스탠딩 v2의 제작 기록 이전 및 재실행은 [스탠딩 재실행 절차](character-standing-replay.md)를 따른다. 이 과거 보정 레시피는 기준 시트 생성의 기본값이 아니다.
