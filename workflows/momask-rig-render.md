# MoMask 리그 렌더 기준

기본 걷기는 **mannequin-walk/v8**이다. 선택 이력 `2026-09-24_22-04-47-42b7a56f`의 32프레임·4fps·4방향을 재사용한다. 기존 v1~v7 기본 선택은 폐기했다. ANNY 모델은 39eab167이며 모션 신규 추론 없이 재렌더한다.

```bash
.venv/bin/python generators/animation/render_momask_rig.py
```

CUDA가 필요한 실행은 샌드박스 밖에서 수행한다. 기본 리그 선택기는 default_walk_rig.yaml이며 등록 에셋의 해시를 검증한다. 고정 버전의 렌더 코드를 새 .tmp 폴더에 복사해 실행하므로 기존 에셋을 덮어쓰지 않는다. 완료 후 방향별 32프레임 ANNY 이미지가 생성된다. 기존 버전은 과거 이력과 재현 코드용으로만 보존한다. 구형 자체 리그 렌더 경로는 폐기했으며 현재 진입점은 render_momask_rig.py이다. AnyPose 기본 참조 선택은 별도 설정이다.


## 관리도구 신규 모션 생성

`generators/momask/run_managed_generation.py`는 대기·걷기·스트레칭 모두 원본 위치
채널을 공통 리타깃에 전달한다. 동작별 자세 보정·회전 제한·자동 손 자세는 폐기했다.
현재 동작 방식과 실행 기록 계약은 [위치 채널 공통 리타깃 사용](anny-mannequin-generation.md#위치-채널-공통-리타깃-사용)을 따른다.

고정 프롬프트와 원본 프레임 수는 `generators/momask/config/standing-loops-v1.json`에서,
기준 ANNY 모델은 `generators/animation/config/anny_model_baseline.yaml`이 선택하는
프로필에서 읽는다. 과거 모델 ID를 신규 생성의 고정 기준으로 사용하지 않는다.
GUI와 CLI는 같은 공용 작업 서비스를 사용한다.

## 과거 결과의 보존과 재개

과거 생성 이력에는 대기 팔 벌림·가슴 호흡, 스트레칭 비틀림 제한, 주먹 자세,
메시 스무딩·접지 등 당시 적용된 보정이 남아 있을 수 있다. 해당 모션·리그·설정·
실행 코드 사본은 결과의 출처로 보존하며 신규 생성 코드 폐기를 이유로 삭제하지 않는다.
기존 리그 재렌더·재개는 저장된 리그를 사용한다. 최신 리타깃으로 다시 계산하거나
과거 기록을 최신 방식으로 표시하지 않는다. 보정 기록 파일이 없는 신규 결과도 재개할 수 있다.

일반 관리 생성 기록은 기존 `.tmp/momask-generator/jobs/<생성 ID>/` 경로를 유지한다.
별도 실험은 `.tmp/test/<실험명>/<한국시간>/`에 보관한다.

## 등록 모션 재사용

등록 모션은 신규 생성과 구분한다. `default_standing_motion.yaml`,
`default_stretch_motion.yaml`, `default_walk_rig.yaml` 등 생성기별 선택 설정이 가리키는
버전·해시를 기준으로 사용한다. 보정이 포함된 과거 모션도 승인된 제작 자산이면 유지하며,
새 프롬프트 추론이나 공통 리타깃 결과로 자동 대체하지 않는다.

### 리타깃 전 좌표 변환 기록

새 실행은 애니메이션 본 회전·키프레임을 적용하기 전에 `result/anny/coordinate-transform.json`과 `coordinate-transform.npz`를 저장한다. JSON에는 좌표 변환 행렬, 원본 출처, 프로필, 대상 기준 본 위치, 루트 이동 배율, 모든 프레임의 구간 방향·길이·대상 기준 방향과의 각도를 기록한다. NPZ에는 변환 전·후 관절과 루트 이동을 보존한다. 실행 로그에도 구간별 대응과 각도 평균·최댓값을 출력한다.

이 각도는 동작과 골격 구조 차이가 함께 포함된 값이며 보정값이나 품질 합격 기준이 아니다. 원본 모션 첫 프레임을 원본 골격의 중립 자세로 간주하지 않는다. 기존 실행 기록에는 소급하여 파일을 추가하지 않으며, 사후 분석은 별도 실험 경로에 보관한다.
