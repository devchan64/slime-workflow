# MoMask 리그 재렌더 기능 폐기

2026-10-09 사용자 지시에 따라 MoMask 포즈 생성 도구에 이어 등록 리그 재렌더 기능도 폐기했다.

- 리그 렌더 진입점, 기본 걷기 리그 해석기·선택 설정, ANNY 프레임 렌더 실행기와 전용 `render_asset.py`를 삭제했다.
- 기존 MoMask 생성·재개 명령은 폐기 오류로 종료한다. 재렌더 경로로 우회 실행하지 않는다.
- HY-Motion이 사용하는 위치 리타기팅·스키닝·`retarget_loop.py`·`run_stage.py`는 유지한다. HY-Motion 포즈 출력은 별도 `vnccs_render.py`를 사용한다.
- 등록된 모션·피팅·리그 원본과 다른 생성기 결과는 이번 코드 정리로 삭제하지 않는다. MoMask 관리 생성 기록은 앞선 폐기 작업에서 삭제했다.

현재 모션 생성과 포즈 출력은 [HY-Motion 사용 안내](hy-motion.md)를 따른다.
