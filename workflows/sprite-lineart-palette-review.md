# 스프라이트 라인아트 복원과 팔레트 정렬 조사 기록

## 확정한 검증 범위

2026-10-10 세션에서 사용자가 다시 제시한 기존 조사 내용과 이후 합의를 정리한다. 아래 도구는 비교 후보이며 설치·성능 검증·정식 채택 완료를 의미하지 않는다.

1. **라인아트 복원**: 축소로 약해진 외곽선과 내부선을 목표 크기 128–512px에서 읽기 쉽게 만든다. 포즈·실루엣·프레임 배치는 변경하지 않는다. 잔선 제거와 선명화가 얼굴·손·의상 경계를 손상시키지 않는지 확인한다.
2. **팔레트 정렬**: 전체 방향·동작·프레임에 하나의 승인된 마스터 팔레트를 적용한다. 미세 색 변화·윤곽 색 흔들림·반투명 가장자리 색 번짐을 검증한다. 프레임마다 독립 팔레트를 추출하지 않는다.

AI는 라인 복원 후보 생성의 보조 수단이다. 최종 승인 기준은 형태 보존, 마스터 팔레트 준수와 프레임 간 일관성이다. VNCCS 포즈 생성 실험과 본 후처리 후보 검증은 구분한다.

## 기준 이미지와 입력

- 외형 기준: `assets/character-baselines/character-default/light-armor-baseline.png`.
- 세션 예시 시트: 사용자 제공 `sprite-v2-20261010T102021-ec59a321/sheet.png`.
- 사용자가 제시한 시트는 7열 1행이다. 실제 분할은 원본 크기와 메타데이터를 확인한 후 수행한다.
- 베이스라인은 색·선 표현의 기준이며 자세를 복사하는 대상이 아니다. 팔레트 색 수와 음영 단계는 아직 확정하지 않았다.

## 세션에서 조사한 후보

| 목적 | 후보 | 당시 검토한 역할 | 도입 전 확인 항목 |
| --- | --- | --- | --- |
| 라인 복원 우선 비교 | Anime4K Restore/DTD | 흐려진 선을 정돈하는 후보 | 정확한 필터·버전·배율·알파 처리, 최종 크기에서 형태 보존 여부 |
| 라인 복원 연구 비교 | APISR | 손상된 애니메이션 선화 복원 후보 | 코드와 가중치 각각의 라이선스·이용 범위, 임의 디테일 생성과 프레임 흔들림 |
| 팔레트 편집·수동 승인 | Aseprite Indexed Color | 공통 팔레트와 투명색·윤곽색 관리 | 반투명 경계 처리, 모든 프레임의 실제 팔레트 일치 |
| 팔레트 배치 처리 후보 | proper-pixel-art | 공유 격자·팔레트 처리 방식 검토 | 실제 공유 팔레트 API, 격자 처리가 기존 형태를 바꾸는지 여부 |
| 양자화 엔진 후보 | libimagequant/pngquant | 알파를 고려한 색 축소 | 고정 팔레트 강제 매핑 지원 경로, 신규 색 생성·디더링 제어 |

표의 역할은 세션에서 제시한 조사 요약이다. APISR의 라이선스 제약과 proper-pixel-art의 공유 처리 기능 등은 채택 전에 해당 버전의 원문·코드로 재확인한다. 양자화와 지정 팔레트로의 강제 매핑은 같은 기능으로 간주하지 않는다.

세션에서 제공한 출처:

- [Aseprite Indexed 색상](https://www.aseprite.com/docs/color-mode/)
- [proper-pixel-art 저장소](https://github.com/KennethJAllen/proper-pixel-art)

## 처리 순서와 검수

원본 프레임 또는 시트 → 라인아트 복원 후보 → 마스터 팔레트 강제 매핑 → 투명도·외곽선·프레임 간 변화 검증 → 승인 결과만 시트 출력.

- 원본·베이스라인·후보를 나란히 보고 실제 목표 크기에서도 비교한다.
- 복원 단계는 좌표·셀 크기·포즈·실루엣을 보존한다. 출력 시트 배치 변경은 별도 단계다.
- 팔레트 밖 색의 존재와 윤곽색 일관성을 검사한다. 디더링은 별도 제어·검수하며 프레임별 잡음이 생기지 않는지 확인한다.
- 알파와 색상을 구분하여 검사한다. 팔레트 준수만으로 가장자리 번짐이 해결됐다고 판정하지 않는다. 흰색·어두운색·투명 체크 배경에서 확인한다.
- 반복 재생으로 색상·선의 깜빡임을 확인한다. 다른 포즈의 단순 픽셀 차이를 보정 오류로 단정하지 않는다.
- 원본을 덮어쓰지 않으며 사용자가 승인한 결과만 출력·채택한다.

## 시트 재구성은 출력 옵션

행·열, 셀 크기, 간격·외곽 여백을 지정하고 남는 칸은 투명하게 둔다. 공간 배치를 바꾸어도 프레임 ID·재생 순서·시간 정보를 유지한다. 출력 PNG와 프레임 좌표 메타데이터가 일치해야 한다. 보정의 두 핵심 목표와 구분한다.

## 기록 확인 범위와 다음 검증

이번 정리는 현재 대화에 사용자가 복원해 준 후보 표와 합의를 근거로 한다. `workflows/`, `tools/`, `report/`, `assets/` 및 `.tmp/test/`의 관련 텍스트 검색에서는 해당 후보명의 별도 조사 파일을 찾지 못했다. 과거 실험 결과나 채택 기록을 발견한 것으로 표현하지 않는다.

다음 검증은 후보별 공식 구현·라이선스 확인, 동일 입력의 라인 복원 비교, 고정 팔레트 매핑과 알파 검증 순서로 진행한다. 아직 모델 설치·생성 실험·편집기 기능 변경은 수행하지 않았다. 실험을 시작할 때 입력·버전·설정·해시·후보와 검수 결과는 저장소의 실험 기록 규칙에 따라 보존한다.
