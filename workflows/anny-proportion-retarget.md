# ANNY 신체비율 리타기팅 실험 모듈

`generators/momask/body_proportion_retarget.py`는 기존 위치 리타기팅 이후 선택적으로 사용하는 실험용 계산 모듈이다. 기본 생성기·게이트웨이에는 자동 적용하지 않는다. ANNY 체형·루트·다리·손목 로컬 회전은 유지하고 위팔·아래팔 회전만 조정하는 용도다.

## 적용 순서

1. 원본 관절에 기존 좌표 변환과 모션 스케일을 적용한다. 모든 계산은 같은 리그 좌표계·단위를 사용한다.
2. 원본과 대상의 기준 자세에서 `[왼쪽 골반, 오른쪽 골반, 양쪽 어깨 중심]`을 구성한다. `calculate_body_ratios`로 골반 폭과 골반 중심→어깨 중심 길이 비율을 구한다. 깊이 비율은 근거 없이 추정하지 않고 1로 유지한다.
3. 매 프레임 기존 리타기팅 자세를 평가하고, 두 골격의 몸통 기준점과 원본 손목을 `map_proportional_wrist`에 전달한다. 기준 자세에서 구한 비율은 클립 동안 고정한다.
4. 대상 어깨·팔꿈치·손목과 목표 손목을 `solve_two_segment`에 전달한다. 팔 길이를 보존하고 기존 팔꿈치를 목표 축에 투영한 굽힘 방향을 사용한다. 도달 불가 목표는 도달 범위로 제한하고 반환한 목표 이동 거리를 기록한다.
5. `rotate_segment_toward`로 위팔→팔꿈치, 아래팔→손목 순서로 적용한다. ANNY 구간은 `upperarm01.L/R`→`lowerarm01.L/R`, `lowerarm01.L/R`→`wrist.L/R`이다. 원본 포즈로 매 프레임 초기화하여 보정을 누적하지 않는다.
6. 회전 부호 연속성을 유지하여 키를 기록한다. IK 목표 오차, 도달 범위 제한량, 손목 이동량, 루트·비대상 본의 불변 여부와 교차쌍 수를 전후 비교한다.

## 검증과 한계

Blender Python에서 `tools/review/tests/test_body_proportion_retarget.py`와 기존 `test_anny_position_retarget.py`를 실행한다. 상세 로그·종료 코드·JUnit을 저장하는 회귀 실행기를 사용한다.

`build_surface_partitions`와 `count_surface_intersections`는 지배 가중치로 분류한 팔·손과 몸통·다리 사이의 비인접 삼각형 교차를 검사한다. 교차쌍 수는 깊이·체적 지표가 아니다. 혼합 경계, 완전히 내부에 들어간 표면, 팔끼리 교차는 검사하지 않는다. 정점 수를 유지하면서 토폴로지를 바꾸는 modifier도 지원 대상으로 간주하지 않는다.

몸 표면 두께·손바닥 비틀림·충돌 회피·프레임 간 IK 연속성 최적화는 포함하지 않는다. 한 모션의 시각적 개선은 모든 모션의 무관통을 보장하지 않는다. 실험 결과와 프롬프트·로그는 기존 `.tmp/test/<실험명>/<한국시간>/` 정책을 따른다. 제자리·발 고정·루프 보정은 추가하지 않는다.
