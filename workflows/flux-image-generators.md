# FLUX 이미지 생성기

일반 이미지·캐릭터·마네킨·빌보드 가이드·소품·식생·건물·심리스 타일과 별도 표정 생성기를 제공한다. 이미지 용도별 페이지는 FLUX 3 Image Klein 공용 실행기와 공용 화풍 v1.5.0을 사용하고, 생성기별 입력·이력과 Qwen 아카이브는 분리한다. 이미지 참조는 최대 두 장이며 투명 참조는 흰 배경과 합성한다. 출력은 RGB다. 캐릭터 신체 참조는 기존 검색 카드 갤러리, 마네킨은 제작 단계별 기준과 프롬프트 예시, 빌보드와 건물은 등록된 가이드를 사용한다.

심리스 타일의 새 작업은 FLUX VAE 디코더 합성곱에 순환 패딩을 적용한다. 같은 잠재값의 일반 디코딩에 기존 대향 경계 선형 보간을 적용한 비교도 저장한다. 기존 보간을 별도로 선택할 수 있으며 처리 방식 정보가 없는 이전 이력은 보간으로 재개·복원한다. VAE 타일링은 사용하지 않으며 무늬 연결·반복 품질은 검수가 필요하다.

추론은 모델 단위 CPU 오프로드, 16단계, BF16과 VAE FP32를 사용한다. 프롬프트 확장기·마스크·VAE 타일 인코딩 및 디코딩을 사용하지 않는다. 생성기별 저장 입력과 참조 사본 해시를 기록하며 입력 복원은 새 생성을 실행하지 않는다. GPU 초기 예약은 57,344 MiB이며 해상도·스텝·참조 수별 실측을 분리한다. 참조 수와 해상도가 달라지면 메모리 사용량이 달라진다.

## 구현 후 대표 검증

마네킨 기준과 캐릭터 기준의 신체 비율·색상·화풍, 심리스 타일 반복 경계를 별도 결과로 검수한다. 이 검증은 전체 용도·모든 입력의 일관성을 보장하지 않는다. 다음 대기열 ID는 공용 생성 이력에서 상태를 확인할 수 있다.

- `flux-mannequin`: `2026-11-16_18-54-36-99fdda24`
- `flux-character`: `2026-11-16_18-54-49-099696a3`
- `flux-seamless`: `2026-11-16_18-54-49-49a54a00`

## 순환 VAE 적용 후 비교

- `2026-11-16_20-02-50-05586466`: `2026-11-16_18-54-49-49a54a00`의 사용자 프롬프트·시드 1770797539·512×512·16단계를 사용했다. 같은 잠재값에서 일반 VAE·순환 VAE·일반 VAE 출력의 기존 선형 보간을 비교했다.
- 끝 픽셀 평균 RGB 절대 차이 좌우/상하: 일반 14.09/16.05, 순환 2.68/3.38, 보간 0/0. 보간은 끝 픽셀을 인위적으로 같게 하므로 수치만으로 반복 품질을 결론내리지 않는다. 비교 이미지는 `.tmp/test/flux-seamless-generator/2026-11-16_20-02-50-05586466/comparison-3x3.png`다.
- 일반 VAE 출력 및 보간 결과의 SHA-256은 기존 이력과 일치한다. 한 시드·한 이미지의 결과이며 어텐션 자체는 순환 처리하지 않았다.
- 추가 시드 검증 `2026-11-16_20-18-45-24dbdec0`: 동일 프롬프트·512×512·16단계에서 시드 1770797540으로 실행했다. 끝 픽셀 평균 RGB 절대 차이 좌우/상하는 일반 17.76/27.89, 순환 4.30/4.78, 보간 0/0이다. 두 방식 모두 3×3에서 원본의 어두운 부분이 반복되어 격자처럼 보이며, 끝 픽셀 일치만으로 타일 품질을 보장하지 않는다. 비교 이미지는 `.tmp/test/flux-seamless-generator/2026-11-16_20-18-45-24dbdec0/comparison-3x3.png`다.
