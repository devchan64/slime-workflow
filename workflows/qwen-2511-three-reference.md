# Qwen 2511 3참조 이미지 생성

관리도구의 **이미지 생성 → Qwen 2511 3참조 생성**에서 이미지 3장과 편집 지시를 입력한다. 이미지 1·2·3 순서를 유지하므로 프롬프트에 각 참조의 역할을 설명한다. 파일 선택, 각 칸으로 드래그 앤 드롭, 선택한 칸에 Ctrl+V/⌘V 붙여넣기를 지원한다. 한 번에 한 장씩 입력하며 일반 텍스트 붙여넣기는 유지한다. 입력 미리보기와 생성 결과를 비교하고 결과 PNG를 다운로드할 수 있다.

- 참조: 불투명 RGB/RGBA PNG, 각 512×512, 3MB 이하, 정확히 3장. 자동 크기 변경이나 배경 합성은 하지 않는다.
- 모델: `Qwen/Qwen-Image-Edit-2511`, 기존 `qwen_pose` 런타임의 고정 revision·로컬 모델 경로를 재사용한다.
- 생성 모드: 4스텝 Lightning(CFG 1, 기본 선택) 또는 30스텝 표준(CFG 4). seed 10107, 출력은 화면의 유효 해상도 프리셋에서 선택하며 기본 512×512이다. 참조 입력과 VAE 참조 크기는 기존 512×512를 유지한다. AnyPose는 두 모드 모두 사용하지 않으며 4스텝에서만 고정 Lightning 어댑터를 로드한다. 선택한 스텝과 실제 어댑터·CFG를 실행 기록에 남긴다.
- 모델 파일이 준비된 환경에서 관리 서버를 샌드박스 밖에서 실행한다. CUDA 또는 필수 파일이 없으면 실패하며 CPU 추론으로 대체하지 않는다.
- Qwen 2512 관리 생성기와 GPU 잠금을 공유한다. 다른 이미지 생성 작업이 실행 중이면 5초 간격 로그를 남기며 완료를 기다린다. 모델 다운로드 잠금은 별도로 분리하여 2512 다운로드 중에도 2511을 생성할 수 있다. 별도로 실행한 CLI 작업까지 잠금으로 제어하지는 않는다.
- 상태·실패 원인·로그를 화면에서 확인한다. 같은 탭을 새로고침하면 실행 중인 작업 조회를 복구한다.

입력·프롬프트·실행 로그·파라미터·입출력 해시·결과는 `.tmp/test/qwen-image-2511-three-reference/<한국시간>-<식별자>/`에 저장한다. 자동 에셋 등록이나 커밋은 하지 않는다.

관리 API는 `tools/review/image_generation.py`, 입력 검증은 `tools/review/three_reference_generation.py`, 작업자는 `generators/image/run_qwen_2511_three_reference.py`이다. 페이지 경로는 `/image-generation-2511/`이며 관리 서버 코드 변경 후 서버 재시작이 필요하다.

출력 해상도 선택지의 최소 크기는 384×384이다. 256×256 프리셋은 제거했으며 기존 기본 해상도는 유지한다. 2511의 참조 이미지 입력 조건은 출력 크기와 별개로 512×512를 유지한다.

입력 방식에서 텍스트 전용(참조 0장)과 3참조를 선택한다. 텍스트 전용은 동일 2511 가중치를 QwenImagePipeline에 로드하며, 참조 모드는 QwenImageEditPlusPipeline을 사용한다. 4스텝 Lightning / 30스텝 표준 설정은 공통이다.
