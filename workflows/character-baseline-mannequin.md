# 마네킨 기반 캐릭터 기본형 제작·관리

신체 마네킨, 피부·기본 착장, 얼굴 마네킨, 얼굴 윤곽 정리를 분리하여 캐릭터 기본형을 만드는 수동 제작 절차다. 생성기 자동화나 비율의 기하학적 고정을 의미하지 않는다. 캐릭터 설정 문서가 아닌 이미지 입력 역할·검수·등록 방법을 다룬다.

## 기준 자료의 역할

| 자료 | 결정하는 요소 | 다음 단계에서 보존할 요소 |
| --- | --- | --- |
| 관절 분리형 신체 마네킨 | 머리 대비 키, 어깨·허리·골반 폭, 몸통·팔다리 길이 | 신체 비율, 자세, 머리 외곽 |
| 피부·기본 착장 전신 | 피부색, 표면, 짧고 밀착된 기본복 | 마네킨의 신체 비율과 자세 |
| 얼굴 마네킨 | 눈 크기·간격, 코 높이, 입 너비, 턱선 | 이목구비의 상대 비율 |
| 윤곽을 정리한 얼굴 | 얼굴선·표면·명암의 일관성 | 채택한 이목구비 크기와 배치 |
| 캐릭터 기본형 | 눈색, 헤어, 눈썹 등 고유 외형 | 승인된 신체·얼굴 기준 |

신체와 얼굴 참조의 역할을 프롬프트에 각각 명시한다. 얼굴 참조의 머리 크기를 전신에 그대로 붙이지 않고, 전신의 머리 영역 안에 이목구비를 적용한다. 복장 참조는 옷의 구조·색·재질만 전달한다.

## 제작 순서

1. **신체 마네킨을 선정한다.** 관절이 분리되어 보이는 4방향 시트로 어깨·허리·골반과 팔다리 비율을 확인한다. 현재 출발 기준은 성인 평균 5등신이며 체형별 조절을 허용한다. 숫자만 반복하기보다 채택한 이미지 비율을 주 기준으로 삼는다.
2. **마네킨에 피부와 기본 착장만 적용한다.** 최초 단계에서는 신체 마네킨만 참조하여 얼굴·헤어의 영향으로 머리 크기가 바뀌는 것을 줄인다. 관절 틈을 피부로 연결하고 착장 교체에 적합한 짧고 몸에 붙는 기본복을 입힌다. 이 단계에서 얼굴·머리카락을 추가하지 않는다.
3. **신체 비율을 검수한다.** 원본 마네킨과 같은 전신 높이로 정렬해 가이드라인을 비교한다. 머리가 커졌다면 얼굴 작업으로 넘어가지 않고 신체 단계에서 보정한다.
4. **얼굴 마네킨을 별도로 조정한다.** 눈 크기·간격, 코 높이, 입 너비, 눈썹 두께 등을 한 번에 한 항목씩 수정한다. 정면·쿼터·측면에서 입체적 일관성을 확인한다. 파일의 과거 성별 명칭만으로 현재 용도를 결정하지 않는다.
5. **이목구비 비율을 유지하며 얼굴 윤곽을 정리한다.** 턱선·볼·코와 입 주변의 연결, 좌우 균형, 과한 그림자와 표면을 정리한다. 윤곽 정리를 눈 확대나 입·코 위치 재설계로 처리하지 않는다. 사용자가 채택한 결과를 얼굴 기준으로 등록한다.
6. **피부·착장 전신에 얼굴을 적용한다.** 전신을 수정 대상으로, 얼굴 마네킨을 이목구비 참조로 입력한다. 눈색은 명시한다. 머리 외곽·목·몸통·팔다리와 착장은 유지하도록 지시하고 결과를 다시 비교한다.
7. **헤어와 세부 외형을 적용한다.** 머리카락 길이·색·가르마·볼륨을 지정하고, 필요하면 눈썹을 별도 수정한다. 한 번의 수정에서 신체 비율까지 바꾸지 않는다. 4방향에서 같은 입체 헤어스타일이 이어지는지 확인한다.
8. **기본형 등록 후 파생물을 만든다.** 채택한 시트로 8방향, 얼굴 정면, 전신 정면을 각각 생성하고 별도로 검수한다. 재생성은 크롭과 다르므로 원본과 동일한 얼굴·비율이 보장되지 않는다. 파생물이 원본 기준을 자동 교체하지 않는다.

## 가이드라인 비교

전신은 두개골 정수리부터 발바닥까지 높이를 맞추고 턱·어깨·가랑이·무릎·발바닥의 수평선을 비교한다. 어깨·허리·골반 폭도 전신 높이에 대한 비율로 비교한다. 머리카락의 부피나 신발 높이를 해부학적 머리·신장에 포함하지 않는다. 가려진 정수리를 추정했다면 오차를 기록한다.

얼굴은 같은 머리 외곽 크기로 정렬해 눈 중심선·양눈 간격·코끝·입 중심·입 너비·턱끝을 비교한다. 전신에 적용한 얼굴도 확인하여 확대된 얼굴 이미지에서의 인상만으로 승인하지 않는다. 정면을 주 측정 대상으로 삼고, 측면·쿼터의 투영 길이를 정면의 실제 길이와 직접 비교하지 않는다.

프롬프트의 “50% 두껍게”, “비율 유지”는 지시 목표다. 실측 결과가 아니므로 측정하지 않은 수치는 검증 완료로 기록하지 않는다. 정확한 얼굴·신체 채택은 사용자 검수로 확정한다.

## 저장과 버전 관리

| 경로 | 용도 |
| --- | --- |
| `prompts/references/mannequin/research/<버전>/` | 마네킨·피부·얼굴 조정 실험과 생성 기록 |
| `prompts/references/mannequin/latest/` | 사용자가 채택·반영하도록 지정한 현재 참조의 복사본 |
| `assets/character-baselines/<캐릭터>/baseline-v<번호>/` | 캐릭터별 시트, 얼굴·전신 파생 이미지와 등록 기록 |

새 마네킨 생성 결과는 `latest`에 직접 저장하지 않는다. 사용자 반영 지시 후 선택한 이미지를 복사하고 파일명·YAML·README를 함께 갱신한다. 기존 이미지 교체와 새 후보 추가를 구분하며 삭제한 파일을 임의로 복원하지 않는다. 캐릭터 결과도 기존 파일 교체 지시가 없으면 별도 이름이나 버전으로 저장한다.

이미지마다 같은 이름의 YAML에 실제 최종 프롬프트, 단어 수, 프롬프트 SHA-256, 이미지 SHA-256, 실제 참조 경로와 역할, 생성 도구, 후보·채택 상태를 기록한다. 참조 해시를 함께 남겨 같은 경로의 이미지 교체를 구분한다. 사용자 첨부 자료는 첨부 파일명과 해시를 기록하며 생성 프롬프트를 추측해 만들지 않는다. 공통 프롬프트의 영문 원문과 한국어 번역은 함께 유지한다.

참조 폐기 시 PNG·YAML과 활성 색인을 정리한다. 이미 생성한 결과의 출처는 삭제하지 않고 `historical_reference_images`와 폐기 상태로 남긴다. 과거 실행 프롬프트는 현재 기준에 맞춰 소급 수정하지 않는다. 등록은 생성기의 기본 입력 변경·애니메이션 대기열 접수·커밋을 뜻하지 않는다.
