# FLUX 생성 단계 주기 경계 실험

## 조건

2026-11-16에 같은 잔디 프롬프트, 공용 화풍 v1.5.0, 모델 revision `09561231f44e41381c461caf53d5452005a60ac9`, 512×512, 16단계, 참조 없음, BF16·VAE FP32 및 시드 1770797539·1770797540·1770797541로 비교했다. 각 조건의 저장된 최종 프롬프트 해시, 모델 revision 및 PyTorch 버전이 같음을 확인했다. 기준은 기존 순환 패딩 VAE 결과다. 7539·7540은 기존 결과를 재사용하고 7541은 같은 설정으로 새로 생성했다.

## 생성 단계 실험

FLUX의 32×32 생성 잠재 토큰 격자를 디노이저 모델 호출 직전에 `(0,0)`, `(16,0)`, `(0,16)`, `(16,16)`으로 순환 이동하고, 모델 예측을 반대 방향으로 되돌린 다음 스케줄러에 전달한다. 각 네 단계 주기를 16단계에 반복하며 위치 ID는 고정 격자의 좌표를 사용한다. 이 방법은 프레임 이동을 통한 실험적 주기 처리이며, attention 내부의 주기 거리나 경계 일치를 수학적으로 보장하지 않는다. 입력 참조는 지원하지 않고 실험 해상도 512×512만 검증했다.

기준과 실험 모두 디코더의 패딩이 있는 Conv2d 33개에 순환 패딩을 적용했다. 프롬프트 확장기·마스크·VAE 타일 인코딩과 디코딩은 사용하지 않았다. 결과와 실험 코드·작업 로그·프롬프트·해시는 `.tmp/test/flux3-periodic-study/2026-11-16/`에 기록했다. 생성 결과는 기준 에셋으로 등록하지 않았다.

끝 차이는 맞닿는 가장 바깥 1픽셀의 RGB 평균 절대 차이다. 밝기는 테두리 32px의 면적 가중 평균에서 중앙 `(64,64)-(448,448)` 평균을 뺀 8비트 명도다. 3×3 비교에서 세 실험 모두 기준의 어두운 격자가 현저히 줄었으며, 끝 픽셀 차이는 오히려 증가했다. 풀잎 배치·크기와 색감도 달라졌고 반복 무늬는 남는다. 수치는 특정 영역과 이미지 내용의 영향을 받으므로 시각 검수의 보조 지표다. 세 시드와 한 프롬프트의 비교여서 일반화할 수 없다. 실험 코드는 생성기에 적용하지 않았다.

## 큰 풀잎으로 경계 재검수

사용자 요청에 따라 앞서 생성한 큰 풀잎 조건 `2026-11-16_19-12-22-bf0e7920`의 프롬프트·시드 1860025141·512×512·16단계를 그대로 사용했다. 기존 순환 VAE 결과와 생성 단계 순환 이동 + 순환 VAE를 보정 없이 3×3으로 비교했다. 결과: `.tmp/test/flux3-periodic-study/2026-11-16/large-grass-1860025141/comparison-3x3.png`.

좌우/상하 끝 픽셀 평균 RGB 절대 차이는 기존 22.06/18.22, 주기 이동 17.81/16.02다. 테두리−중앙 밝기는 기존 -0.53, 주기 이동 +3.55다. 주기 이동 결과는 풀잎이 크고 식별 가능하지만, 반복 경계에서 풀잎 방향과 밀도가 바뀌며 가로줄이 여전히 보인다. 수치가 감소해도 무늬 연결이 해결됐다고 볼 수 없다. 이 결과는 큰 풀잎 프롬프트 하나와 시드 하나의 관찰이다.

## 큰 풀잎 주기 어텐션 실험

같은 큰 풀잎 최종 프롬프트·시드 1860025141·512×512·16단계와 순환 패딩 VAE를 사용하고, 순환 이동 대신 생성 잠재 격자의 반대편 경계 토큰을 주기 좌표로 어텐션에 추가했다. 이미지 전용 블록 5개와 이미지·텍스트 결합 블록 28개에서 경계 폭 4토큰 및 모서리를 처리했으며, 텍스트 쿼리는 추가 경계 토큰을 보지 않는다. 텍스트 전용 어텐션과 VAE 타일링은 변경하지 않았다. 원본 격자의 위치 인코딩은 유지하고 복제 경계 토큰에는 이동된 위치 인코딩을 적용했다. 생성된 모델 예측과 VAE 출력을 검사했고 16단계가 완료됐다. 참조 이미지 없는 한 가지 크기만 지원하는 실험 코드다.

| 방식 | 좌우 끝 차이 | 상하 끝 차이 | 테두리−중앙 밝기 |
|---|---:|---:|---:|
| 순환 이동 + 순환 VAE | 17.81 | 16.02 | +3.55 |
| 주기 어텐션 + 순환 VAE | 16.81 | 14.49 | -0.79 |

끝 차이와 밝기 계산은 앞 절과 같다. 3×3 반복에서 순환 이동의 가로 밝기 띠는 주기 어텐션에서 약해졌지만, 반복되는 동일 무늬와 개별 풀잎 연결의 부자연스러움은 남는다. 생성 내용도 달라져 수치 감소만으로 형태 연결의 개선을 보장할 수 없다. 프롬프트와 시드 하나의 실험이므로 다른 조건의 성능은 미확인이다. 결과, 3×3 비교, 실험 코드와 메타데이터는 `.tmp/test/flux3-periodic-study/2026-11-16/attention-large/`에 보관하며 생성기에 적용하지 않았다.

## 큰 풀잎 주기 어텐션 다중 시드 비교

큰 풀잎 최종 프롬프트와 모델 revision·512×512·16단계·순환 패딩 VAE를 고정하고 시드 1860025141·1860025142·1860025143에서 순환 이동과 주기 어텐션을 각각 비교했다. 5141은 직전 결과를 재사용했고 5142·5143은 두 방식 모두 새로 생성했다. 모든 결과의 프롬프트 SHA-256과 모델 revision·크기·단계·VAE 타일링 비활성을 대조했다. 생성 모델 예측과 스케줄러 잠재값 및 VAE 출력을 검사했다. 주기 어텐션 설정은 앞 절과 동일하며 경계 폭은 4토큰이다.

| 시드 끝 | 좌우 끝 차이 이동→어텐션 | 상하 끝 차이 이동→어텐션 | 테두리−중앙 밝기 이동→어텐션 |
|---|---:|---:|---:|
| 5141 | 17.81→16.81 | 16.02→14.49 | +3.55→-0.79 |
| 5142 | 11.88→12.31 | 9.26→9.60 | +1.72→-1.06 |
| 5143 | 14.19→12.41 | 8.77→6.52 | -11.23→-27.19 |

5141은 가로 밝기 띠가 약해졌고 5142는 두 방식 모두 비교적 균일하지만 끝 차이는 조금 증가했다. 5143의 주기 어텐션은 끝 픽셀 차이가 감소했음에도 가장자리가 어두워진 탓에 3×3에서 격자형 밝기 변화가 더 두드러진다. 세 시드 모두 반복 무늬가 보이며, 특히 5143은 풀잎이 작고 조밀해 큰 풀잎 연결 판별에 불리하다. 픽셀 차이 감소는 풀잎 형태의 연결이나 균일한 밝기를 보장하지 않는다. 한 프롬프트와 세 시드의 비교로, 일반적 우위를 단정할 수 없다.

원본과 메타데이터·실험 코드, 시드별 무보정 반복 이미지 및 전체 비교표는 `.tmp/test/flux3-periodic-study/2026-11-16/attention-large-multiseed/`에 있다. 5141 원본은 이전 두 실험 디렉터리에 보존한다. 생성기에 실험 코드를 적용하지 않았다.

## 큰 풀잎 순환 이동과 주기 어텐션 결합

동일한 큰 풀잎 프롬프트와 시드 1860025141·1860025142·1860025143을 사용해 순환 이동과 주기 어텐션을 동시에 적용했다. 앞의 순환 이동과 동일한 네 이동값을 16단계에 반복하며 이동된 격자에 경계 폭 4토큰의 주기 어텐션을 적용하고 모델 예측을 되돌린다. 세 방식은 순환 패딩 VAE, 512×512, 16단계, 모델 revision 및 프롬프트 해시가 같다. 기존 단독 방식 결과는 재사용했고 결합 방식 세 이미지를 새로 생성했다. VAE 타일링은 사용하지 않았다.

| 시드 끝 | 좌우 끝 차이 이동 / 어텐션 / 결합 | 상하 끝 차이 이동 / 어텐션 / 결합 | 테두리−중앙 밝기 이동 / 어텐션 / 결합 |
|---|---:|---:|---:|
| 5141 | 17.81 / 16.81 / 16.54 | 16.02 / 14.49 / 15.41 | +3.55 / -0.79 / +1.36 |
| 5142 | 11.88 / 12.31 / 12.66 | 9.26 / 9.60 / 9.85 | +1.72 / -1.06 / +0.67 |
| 5143 | 14.19 / 12.41 / 14.43 | 8.77 / 6.52 / 8.31 | -11.23 / -27.19 / -9.60 |

5143에서 결합은 주기 어텐션 단독의 어두운 격자를 완화했으나 밝기 차이는 여전히 남고, 좌우 끝 차이는 단독 두 방식보다 커졌다. 5141·5142의 밝기는 비교적 균일하나 일부 가로줄과 반복 무늬가 보인다. 결과에 따라 풀잎 배치·크기가 달라지며, 큰 풀잎이 경계를 자연스럽게 관통하는지 확실히 판정하기 어렵다. 한 프롬프트·세 시드로 일반화하지 않는다. 출력, 실행 기록 및 세 방식의 3×3 비교는 `.tmp/test/flux3-periodic-study/2026-11-16/attention-shift-multiseed/`에 보관한다. 생성기에는 적용하지 않았다.

## 결합 방식의 어텐션 강도와 경계 폭 비교

순환 이동 + 주기 어텐션 + 순환 패딩 VAE를 유지하고 앞 절과 같은 큰 풀잎 프롬프트 및 시드 1860025141·1860025142·1860025143에서 비교했다. 기준은 폭 4토큰·강도 1이며, 강도 0.5·폭 4, 강도 1·폭 2, 강도 1·폭 8로 한 번에 한 변수만 바꾸어 각각 세 이미지를 새로 생성했다. 강도는 추가된 반대편 토큰의 softmax 정규화 전 가중치에 곱하는 값으로, 0.5는 해당 토큰의 attention logit에 ln(0.5)를 더한다. 기준 1은 기존 boolean 마스크이고 실험은 동등한 0/-무한대 가산 마스크를 사용했다. 경계 폭은 추가 토큰 영역과 허용 주기 거리 범위를 함께 조절한다. 512×512·16단계·모델 revision·프롬프트 해시·시드·33개 디코더 순환 패딩·VAE 타일링 비활성 및 이미지 SHA-256을 비교했다.

| 시드 끝 | 설정 | 좌우 끝 차이 | 상하 끝 차이 | 테두리−중앙 밝기 |
|---|---|---:|---:|---:|
| 5141 | 기준 / 강도 0.5 / 폭 2 / 폭 8 | 16.54 / 16.05 / 17.59 / 16.96 | 15.41 / 15.09 / 15.85 / 15.16 | +1.36 / +1.49 / +2.37 / +0.52 |
| 5142 | 기준 / 강도 0.5 / 폭 2 / 폭 8 | 12.66 / 12.72 / 12.82 / 12.62 | 9.85 / 10.05 / 9.84 / 9.51 | +0.67 / +0.79 / +0.90 / +0.47 |
| 5143 | 기준 / 강도 0.5 / 폭 2 / 폭 8 | 14.43 / 14.57 / 14.49 / 15.11 | 8.31 / 8.18 / 8.38 / 9.18 | -9.60 / -10.87 / -11.95 / -4.41 |

폭 8은 이 세 시드에서 테두리−중앙 밝기의 절댓값을 모두 줄였으며 특히 5143의 어두운 격자가 완화되었다. 하지만 5143의 양방향 끝 픽셀 차이는 증가했고 반복되는 풀잎과 일부 연결 불연속이 남는다. 강도 0.5나 폭 2는 밝기 편차를 일관되게 개선하지 않았다. 기준 이미지와 바뀐 실험 이미지의 생성 내용이 달라지므로 수치만으로 형태 연결 개선을 판단할 수 없고, 한 프롬프트·세 시드로 일반화할 수 없다. 실험 결과 및 3×3 비교는 `.tmp/test/flux3-periodic-study/2026-11-16/attention-tuning-multiseed/`에 보관하며 생성기에 적용하지 않았다.

## 폭 8 주기 어텐션의 초기·후기 적용 비교

폭 8토큰·강도 1의 주기 어텐션을 16단계 전체에 적용한 직전 결과를 기준으로 재사용하고, 같은 큰 풀잎 프롬프트와 시드 1860025141·1860025142·1860025143에서 초기 1–8단계 또는 후기 9–16단계에만 적용한 결과를 각각 새로 생성했다. 비활성 단계에는 원래 FLUX 어텐션을 사용했다. 세 조건 모두 동일한 네 단계 주기의 순환 이동과 순환 패딩 VAE를 유지하고 VAE 타일 인코딩·디코딩을 사용하지 않았다. 모델 revision·프롬프트 해시·해상도·단계·시드·이미지 SHA-256을 대조했다.

| 시드 끝 | 좌우 끝 차이 전체 / 초기 / 후기 | 상하 끝 차이 전체 / 초기 / 후기 | 테두리−중앙 밝기 전체 / 초기 / 후기 |
|---|---:|---:|---:|
| 5141 | 16.96 / 16.63 / 18.00 | 15.16 / 14.45 / 16.92 | +0.52 / +3.23 / +1.73 |
| 5142 | 12.62 / 12.20 / 12.41 | 9.51 / 8.78 / 9.70 | +0.47 / +1.95 / +0.50 |
| 5143 | 15.11 / 14.67 / 14.69 | 9.18 / 8.93 / 8.52 | -4.41 / -5.01 / -11.39 |

## 중단 지점과 다음 검토 방향

2026-11-16 현재 전역 최단 주기 거리·순환 패딩 VAE와 다양한 순환 이동을 실험 기준으로 유지한다. 잠재 곡률 조건과 단순 밝기 기울기 방향 유도는 큰 풀잎 윤곽의 경계 연결 개선을 세 시드에서 입증하지 못했다. 생성기에는 어떤 실험 방식도 적용하지 않았으며 기존 생성기 방식의 채택이나 품질 확보를 선언하지 않는다.

다음 작업을 재개할 때는 아래 순서로 검토한다.

1. **독립적인 형태 평가 기준 마련:** 3×3 반복과 경계 교차점 원본 해상도 확대에서 경계를 통과하는 잎의 윤곽·방향·굵기·끊김을 별도 표시해 검수한다. 유도에 사용한 방향 손실과 끝 픽셀 차이는 보조 지표로만 사용하고, 잎이 경계에 걸리지 않아 판정이 불가능한 경우를 구분한다. 조건별 후보 선택 기준을 사전에 정한다.
2. **순환 이동한 이미지의 특징 비교:** 동일 잠재값을 서로 다른 순환 위치에서 전체 디코딩하고 다시 정렬해, 경계가 내부에 놓였을 때와 원래 경계의 윤곽 차이를 분석한다. 먼저 분석용 비교를 실시하고, 차이가 관측되는 경우에만 생성 유도에 적용하는 방법과 비용을 검토한다. VAE 타일 인코딩·디코딩이나 이미지 마스크 보정은 사용하지 않는다.
3. **연결 구조를 명시한 생성 조건 검토:** 주기 경계를 가로지르는 잎의 윤곽 또는 방향이 명시된 구조를 먼저 준비하고 FLUX 3에서 참조하는 방식을 조사한다. 모델의 구조 조건 지원·참조로 인한 화풍과 구도 변화·상업적 사용 가능성을 확인하고, 구현 전 기준 이미지와 프롬프트의 출처를 기록한다.
4. **후보 선택 방식의 기준 실험:** 생성 과정의 조건을 늘리기 전에 여러 시드를 생성해 동일한 독립 형태 기준으로 평가하고 채택·제외 결과를 모두 기록한다. 선택 효과와 생성 방식의 개선을 혼동하지 않는다.

후속 비교는 같은 프롬프트·시드·모델 revision·해상도·이동 순서를 고정하고 변경 변수만 기록한다. 전역 어텐션은 기존 생성기에 미적용된 실험 코드이므로 운영 적용 전 별도의 성능·수치 안정성·이력 호환성 검증이 필요하다. 실험 원본과 코드의 `.tmp/` 경로는 임시 보관이므로 장기 보존이 필요하면 재개 시 워크플로우 보관 정책에 맞춰 별도로 정리한다.

## 심리스 생성기 적용

사용자가 지정한 이미지의 기준 방식은 전역 최단 주기 어텐션·16개 위치 순환 이동·순환 패딩 VAE의 조합이다. `global-periodic-v1`로 심리스 생성기의 새 작업에 적용했으며, 검증된 512×512·참조 없음·16단계만 허용한다. 과거 `edge-blend`, `circular-vae`, `circular-vae-v2` 이력은 저장된 방식대로 재개한다. 전역 방식은 결과·3×3 반복 검수와 적용된 이동값·블록 수·호출 수·해시를 기록한다. 전역 주기 좌표의 이미지 쌍별 최단 거리·동률 및 중복 선택을 CPU에서 검증했고, 생성기 경로의 실제 GPU 실행을 기존 5141 기준과 동일한 프롬프트·시드로 비교해 결과 이미지 SHA-256이 일치했다. 다른 크기와 참조 이미지 입력은 아직 검증되지 않았다.
