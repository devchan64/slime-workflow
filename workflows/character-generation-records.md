# 캐릭터 생성 기록과 워크플로우 개선

## 제작 경로

캐릭터 애니메이션은 **이미지젠과 Qwen을 조합하는 워크플로우**로 관리한다. 이미지젠은 승인 베이스라인·검수 통과 프레임의 최종 외형에만 사용하고, Qwen은 목표 포즈 적용을 담당한다. 이미지젠 호출의 목적·예산·재시도 기준은 [이미지젠 최소 사용 정책](imagegen-usage-policy.md)을 따른다. MoMask 리그 렌더가 Qwen의 기본 동작 참조다. OpenPose는 명시적 비교 실험용이며 리그와 동등한 기본 경로로 취급하지 않는다. 개별 단계 성공과 최종 에셋 채택을 구분한다.

1. 승인 2×2 베이스라인·MoMask/리그 버전·방향·프레임을 고정한다.
2. Qwen에 방향별 캐릭터 크롭과 해당 방향·프레임의 리그 렌더를 입력한다. `rig` 기준 프롬프트를 선택한다. 기준 포즈 문구와 옵션 문구를 분리하고 입력 순서에 맞춰 이미지 번호를 치환한다.
3. 포즈를 검수한다. 포즈가 틀리면 다음 단계로 넘기지 않는다. 리그 참조와 OpenPose 참조는 서로 다른 실험 조건이다.
4. 이미지젠에 Qwen 결과를 포즈 전용 참조, 승인 2×2 전체를 아이덴티티 참조로 전달한다. 기본적으로 검증된 단일 프레임 경로를 사용한다. 묶음 생성은 최대 4프레임이며 성공을 가정하지 않는다.
5. 최종 외형·방향·포즈 검수 후 셀 보정·앵커·루프 검수 및 최종 패킹을 진행한다. 걷기는 32프레임을 4×4 두 장으로 전달한다.

기존 이미지젠 직접 리그 참조 경로는 비교·기존 소스 활용 경로로 남긴다. 조합 경로와 직접 경로를 같은 조건에서 비교하기 전 호출 수·성공률만으로 우열을 단정하지 않는다. 스탠딩처럼 포즈 변경이 필요 없는 단계는 Qwen 생략 사유를 기록할 수 있다.

## 실행별 기록

실행 원본은 `.tmp/YYYY-MM-DD_HH-mm-ss/`에 보관한다. 도구의 result.json은 원형을 유지하고 공통 연결 기록 `generation-record.yaml`에서 참조한다. 이미지젠은 도구가 제공한 실제 정보만 기록한다.

| 기록 묶음 | 필수 내용 |
| --- | --- |
| 식별·연결 | managementId, 이력 버전, 실행 ID, 워크플로우 버전, 부모 실행 ID, 캐릭터·동작·방향·프레임 ID |
| 실험 의도 | 비교 대상 실행 ID, 가설, 이번 변경 변수, 고정 조건 |
| 입력 | 참조 역할·순서·경로·SHA-256, 크롭 rect, 원본 자산 ID·버전·해시 |
| 프롬프트 | 기준 ID·버전·해시, 옵션 사용 여부·해시, 실행 문구 해시; 실제 문구는 실행 폴더 또는 비공개 프로필 |
| 생성 | 도구, 확인된 모델/revision, 스텝·seed·CFG, 요청/실제 크기, 라이브러리 버전, 시작·종료·소요 시간 |
| 산출물 | 경로·SHA-256·크기, 후속 실행 ID, 보정 배율·이동·시트 파일·rect·anchor |
| 검수 | 포즈·발 연결·방향·아이덴티티·비율·알파·앵커·루프별 accepted/rejected/pending/not-applicable 및 사유, 검수자 |
| 채택 | 후보/단계 승인/최종 승인/시트 통합/런타임 채택 상태를 각각 기록 |
| 비용 | 선언한 이미지젠 호출 예산, 실제 호출 수·대상 프레임 수·채택/폐기/재시도 수, 확인 가능한 실행 시간·토큰·비용, 측정 범위; 미제공 값은 null과 사유 |

과거 실행을 소급 정리할 때 없는 값을 추정하지 않는다. 원본 기록을 덮어써 과거 정책을 수정하지 않고, 후속 기록이 어떤 상태를 갱신했는지 연결한다. 파일이 사라졌다면 missing으로 명시하며 해시만으로 재현 가능하다고 주장하지 않는다.

## 재사용 기록과 보관

재사용 근거가 있는 성공·실패 생성 관리기록은 `.tmp` 정리 전에 워크플로우 `assets/generation-records/`로 승격한다. 관리 원본은 워크플로우이며 프론트엔드 등록 시 동일 managementId를 사용한다. 비공개 프롬프트·기획 설계는 백엔드에 유지하고 관리기록에서 버전·해시로 연결한다. [관리번호·재현 보존 계약](../assets/generation-records/README.md)을 따른다. 정식 MoMask·리그·승인된 재사용 중간 이미지는 워크플로우 `assets/`에서 버전·출처·해시로 관리하고 최종 전달 에셋은 프론트엔드에 둔다.

실패 기록도 재발 방지 또는 비교 근거가 있으면 변경 변수·결과·이유를 남긴다. 근거 없는 중복 프롬프트는 남기지 않는다. 승격 기록이 참조하는 임시 이미지의 보존 필요성을 먼저 판정하며, 필요한 이미지까지 `.tmp` 경로에 있다는 이유만으로 삭제하지 않는다.

## 최적화 판정

한 번에 하나의 조건을 바꾸고 같은 캐릭터·방향·포즈·평가 기준으로 비교한다. 실제 검수한 프레임 수를 분모로 성공률을 계산하고 보류 수를 별도 표기한다. 최종 채택 프레임당 총 호출 수·총 시간·재생성 횟수를 집계하며 Qwen 포즈 단계 성공을 최종 성공으로 세지 않는다. 값이 없는 비용·토큰은 0으로 계산하지 않는다.

포즈·외형·루프 품질을 충족한 후보 사이에서 비용과 재시도를 줄인다. 개선안은 기존 기준과 비교 후 새 워크플로우 버전으로 채택하며 이전 버전·근거·되돌릴 경로를 보존한다. 단일 프레임 성공은 다른 방향 또는 전 프레임 검증을 대신하지 않는다. 이 문서는 기록·평가 절차이며 자동 수집·집계 도구가 구현되었다는 의미는 아니다.
