# FLUX 3 Image Klein 도입 검토

2026-11-16 조사와 ROCm 실험. 상세 결과는 아래에 기록한다.

## 라이선스

- [모델 카드](https://huggingface.co/black-forest-labs/flux-3-image-klein)의 가중치는 FLUX Kommunity License v1.0이며, [참조 구현](https://github.com/black-forest-labs/flux-3-image-klein)의 Apache 2.0 라이선스와 구별한다.
- [라이선스 1.e와 2.a](https://huggingface.co/black-forest-labs/flux-3-image-klein/blob/main/LICENSE.md)에 따라 사용자와 계열사의 연간 환산 총매출이 500만 달러 미만인 적격 사용자는 조항을 준수하여 상업적 결과물을 생성할 수 있다. 실제 사용자 또는 조직의 적격 여부는 확인되지 않았다. 그 밖의 상업적 사용은 별도 계약 범위를 확인한다.
- 모델 출력의 불법·침해 콘텐츠에 대한 필터링 또는 배포 전 검토 등 라이선스 2.e의 조건도 확인한다. 모델과 출력물의 권리·의무를 혼동하지 않는다.

## 시스템과 검증 계획

- 실제 호스트에서 Radeon 8060S `gfx1151`과 ROCm 장치를 확인했다. 2026-11-16 시스템 메모리는 약 30 GiB, 확인 시 사용 가능 약 24 GiB이며 공유 GPU 메모리 사용 중에는 더 줄어든다.
- 현행 `.venv`에서 PyTorch `2.13.0+rocm10.0.0`, HIP `7.15.26333`과 GPU 인식을 확인했다. 모델 가중치는 아직 설치되지 않았으며 기존 Hugging Face 인증 정보로 해당 모델 파일 메타데이터 접근 시 HTTP 403이 반환됐다. 모델 페이지의 접근 허용 여부 확인이 필요하다. 인증 정보 자체는 기록하지 않는다.
- [BFL 참조 구현](https://github.com/black-forest-labs/flux-3-image-klein#memory)은 NVIDIA B200에서 1024×1024의 BF16 모델을 프롬프트 확장기 없이 실행할 때 약 31 GB의 GPU 피크를 기록한다. 이는 AMD의 요구량 측정치가 아니다. 공식 설치와 FP8·NVFP4 조건은 NVIDIA 중심이므로 ROCm의 실행 가능성, 양자화 지원, 메모리, 정확성은 미확인이다.
- 참조 구현은 일반 체크포인트와 프롬프트 확장기 등 약 52 GB 저장 공간을 안내한다. 공식 모델 카드는 확장기를 권장하고 참조 이미지가 구조를 고정하지 않는다고 밝힌다. 확장 전후 프롬프트를 모두 기록해야 한다.
- 로컬 실행 전 라이선스 접근 조건, 실제 GPU 가용량, 기존 대기열과 호환 구현을 점검한다. 이후 얼굴 있는 4방향 기준 이미지를 입력으로 피부·기본복을 생성하고 입력, 확장 프롬프트, 모델 리비전, 시드, 해상도, 실제 정밀도, 실행 로그 및 관측 메모리를 보존한다. 마스크 국소 보정과 VAE 타일 인코딩·디코딩은 사용하지 않는다.
- 이미지의 머리 대 몸 비율과 어깨·골반 폭, 몸통·사지 길이, 허벅지와 종아리 두께 및 네 방향 배치를 원본과 비교한다. 생성 결과의 동일성이나 기준 교체는 사용자 검수 전까지 확정하지 않는다.

## 2026-11-16 ROCm 편집 시험

- 얼굴 있는 마네킨 원본 SHA-256 `1fa8c88ba68acc739ddd654e7c67b0215539e92ea4761f9253d0f358d7965464`를 사용했다. 모델 revision `09561231f44e41381c461caf53d5452005a60ac9`, 프롬프트 확장기 revision `a57899549f8f6f64c6c4d88db30827d496ff76d0`, 768×1152, 16스텝, 시드 589998267이다. 공용 화풍 v1.5.0 원문은 이번 FLUX 입력에 포함하지 않았다.
- ROCm PyTorch에서 확장기와 편집 모델을 별도 프로세스로 순차 실행하고 모델 단위 CPU 오프로드를 사용했다. VAE 타일 처리와 마스크는 사용하지 않았다. GPU 대기열에서 확장 약 49.5초, 이미지 편집 약 269.7초에 완료됐다. 편집의 프로세스 관측 GPU 메모리 피크는 32812 MiB(124개 표본), PyTorch 할당 피크는 32606065664바이트다. 공유 메모리 GPU의 수치는 시스템 전체 RAM과 단순 합산할 수 없으며 다른 해상도나 동시 부하에 대한 보장은 아니다.
- 네 방향과 인물 배치는 대체로 남았지만 팔·다리와 몸통의 두께와 윤곽이 달라졌고 반바지가 길어졌다. 그림체도 기준보다 입체적이고 사실적으로 바뀌었다. 확장문에 측면 방향을 원본과 다르게 서술한 부분이 있어 입력·확장문 검토가 필요하다. 단일 결과이므로 모델 전체의 일관성이나 Qwen 대비 우열을 일반화하지 않는다. 생성 결과와 기준은 교체하지 않았다.
- 실험 산출물은 `.tmp/test/flux3-mannequin-evaluation/2026-11-16_1147-image/`에 있으며, 기준·기존 Qwen 결과·FLUX 결과 비교 이미지와 실행 설정을 보관한다. Qwen과 FLUX는 프롬프트와 화풍 설정이 달라 통제된 모델 간 비교가 아니다.
