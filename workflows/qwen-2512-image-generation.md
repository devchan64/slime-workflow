# 관리도구 이미지 생성

공통 관리도구(`tools/review/serve.py`)의 **이미지 생성 → Qwen 2512 이미지 생성**에서 프롬프트와 생성 모드·너비·높이를 입력한다. 모델과 어댑터는 코드에 고정되며 사용자 입력으로 선택하지 않는다.

- Qwen/Qwen-Image-2512: 4스텝 Lightning(CFG 1, 기본 선택) / 30스텝 표준(CFG 4). seed 251204는 공통이다. 30스텝에서는 Lightning 어댑터를 검증하거나 로드하지 않는다.
- 출력 해상도: 검수용 512/768/1024 정사각형과 모델 카드 예시 1328×1328, 1664×928, 928×1664, 1472×1104, 1104×1472, 1584×1056, 1056×1584 프리셋. 기본 512×512. 가로·세로는 16의 배수이며 API는 256~1664 범위를 검증한다.
- 프리셋 근거: https://huggingface.co/Qwen/Qwen-Image-2512 . 유효 크기는 GPU 메모리나 품질 보장을 뜻하지 않는다.
- 최초 실행은 ‘모델 준비’로 고정 모델과 어댑터를 `.model/`에 다운로드한다. Lightning SHA-256·크기를 검증하고 로컬 파일로만 생성한다.
- CUDA 사용 불가·파일 누락·해시 오류는 즉시 실패한다. CPU 추론 대체 경로는 없다. 관리 서버는 샌드박스 밖에서 시작해야 준비·GPU 추론도 같은 환경에서 실행된다.
- 한 번에 한 작업을 실행한다. 작업 ID는 새로고침 후에도 같은 탭에서 복구된다. 실행 상태·실패 원인·로그와 이미지 다운로드를 제공한다.
- 생성 기록·입력 프롬프트·결과는 `.tmp/test/qwen-image-2512/<한국시간>-<식별자>/`에 저장한다. 자동 에셋 등록·Git 추적은 하지 않는다.

생성 코드는 `generators/image/qwen_2512.py`, 작업자는 `generators/image/run_qwen_2512.py`, 관리 API는 `tools/review/domains/image/image_generation.py`이다. 과거 애니메이션 폴더의 미사용 생성기를 복원하는 대신 현재 관리도구에 연결된 이미지 생성 경로로 관리한다. 모델 준비에는 큰 다운로드와 여유 디스크 공간이 필요하며, 준비 전에는 실제 생성 검증을 완료한 것으로 간주하지 않는다.

출력 해상도 선택지의 최소 크기는 384×384이다. 256×256 프리셋은 제거했으며 기존 기본 해상도는 유지한다. 2511의 참조 이미지 입력 조건은 출력 크기와 별개로 512×512를 유지한다.
