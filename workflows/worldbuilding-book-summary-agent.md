# 도서 편집 1단계 문서 요약 에이전트

## 목적

선택한 도서의 등록 경로에 있는 문서를 읽고, 문서별 내용·목적·주제 그룹을 만들어 다음 단계의 목차 구성에 전달한다. 원문을 수정하거나 문단을 재배치하지 않는다.

## 입력

- 선택한 도서 ID: `world` 또는 `system-design`
- 도서에 등록된 문서 루트 경로
- 사용자의 요약 지시
- 보호 문서와 원문 해시 정보

## 처리 규칙

1. 문서를 한 번에 모두 모델에 넣지 않고 문서별로 처리한다.
2. 각 문서에서 내용 요약, 문서 목적, 주제 그룹을 생성한다.
3. 원문에 없는 사실을 추가하지 않는다.
4. 원문 파일·문단·YAML을 수정하지 않는다.
5. 입력 토큰 한도를 초과하면 내용을 자르지 않고 해당 작업을 실패시킨다.
6. 결과의 문서 경로와 원문 해시를 보존해 검수 대상과 연결한다.

## 출력

각 문서에 대해 다음 값을 기록한다.

- `document_path`
- `summary_text`
- `purpose_text`
- `topic_group`

실행 상태와 결과는 실행별 `.tmp/YYYY-MM-DD_HH-mm-ss/` 아래에 저장한다. 결과 검수 후에만 2단계 목차 구성으로 넘긴다.

## 검수 기준

- 대상 문서 수와 요약 결과 수가 일치하는가
- 모든 문서 경로가 선택한 도서 루트 안에 있는가
- 요약·목적·주제 그룹이 비어 있지 않은가
- 원문 파일의 해시와 내용이 변하지 않았는가
- 실패 시 입력 초과, 스키마 오류, 모델 오류의 원인이 실행 로그에 남는가
