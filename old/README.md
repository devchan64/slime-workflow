# 이전 구현 아카이브

현재 MoMask·애니메이션 생성 경로에서 사용하지 않는 소스를 보관한다.

- `workflow/`: 기존 노드·음악·범용 파이프라인·아티팩트 계약과 테스트.
- `scripts/`: 해당 실행 스크립트, 이전 리그 외형 실험, SMPL 확인까지 포함했던 MoMask 실험.
- `requirements-*.txt`: 이전 테스트·아티팩트 환경.
- `README.previous.md`: 정리 전 저장소 안내.

파일 내부의 과거 경로는 역사 기록으로 유지한다. 이 디렉터리는 독립 실행·테스트 통과를 보장하지 않으며 현재 생성기에서 import하지 않는다. 복원하려면 필요한 구현과 의존성을 생성기 단위로 검토해 이동한다.
