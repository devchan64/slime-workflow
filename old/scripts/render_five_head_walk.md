# 자체 리그 Depth 렌더 실행

`render_five_head_walk.py`는 고정된 HumanML3D-22 NPZ 입력을 읽어 자체 제작 메시와 리그를 생성하고 CUDA Cycles로 네 카메라의 Depth·마스크·미리보기를 출력한다. SMPL 파일은 사용하지 않는다.

## 환경

전용 Python 3.11 환경에 `bpy==4.5.3`, `numpy==1.26.4`, `pillow==12.3.0`, `scipy==1.17.1`를 설치한다. 모델 준비·GPU 확인·렌더 명령은 샌드박스 밖에서 실행한다.

```bash
.local/blender-runtime/bin/python -u scripts/render_five_head_walk.py
```

입력은 `.result/workflow/reusable/motions/walk-travel/v1/motion.npz`와 `artifact.json`이다. 입력 해시·필드·형상·유한값을 검사한다. 코드의 출력 버전 경로는 불변이며 기존 디렉터리가 있으면 즉시 실패한다. 재실행하려면 새 버전을 명시하고 메타데이터 버전도 함께 변경한다.

## 출력

- `reusable/rigs/five-head-walk/v9/`: 리타기팅 모션, 수정 가능한 Blender 장면, 출처와 해시.
- `runs/five-head-walk-v9/`: 방향별 8장의 Depth·마스크·RGBA 제작 미리보기, 실행 로그, 파일 해시 manifest.
- 해상도 256×256, Depth 16비트 흑백. 카메라 거리 6m, 깊이 4~8m를 가까울수록 밝게 정규화한다. 배경은 0이며 별도 마스크로 구분한다.
- 샘플 간격 150ms, 8장 한 주기 1.2초. 소스는 20fps 관절 데이터다.

로그는 timestamp/area/stage 형식이며 실행 중 5초마다 heartbeat를 기록한다. 실행 표준출력의 Blender 상세 로그도 실행 디렉터리에 보관한다.

제작 미리보기는 최종 외형 에셋이 아니다. 접지 높이 보정만 적용되어 수평 발 미끄러짐·경계 속도 연속성 검수가 남는다. 단순 선형 경계 보정은 관절 간 거리에 작은 변동을 일으킬 수 있다. 품질 경고는 artifact에 기록하며 런타임 승인과 구분한다.

## v3 발 회전 수정

신발은 정강이 본 대신 발목–발끝 본에 연결한다. 본 회전은 중립 방향에 대한 최소 회전으로 계산하여 전역 up 추적으로 발생하던 roll 변화 가능성을 제거한다. 직선 걷기 프로필에서는 발의 yaw/roll을 고정하고 pitch를 -20~25도로 제한한 뒤 주기 평활한다. 회전·곡선 걷기에 그대로 재사용하지 않는다. `foot-validation.json`은 실제 Blender 평가 본의 회전축과 루프 포함 프레임 간 각도 변화를 검사한 기록이다. `preview.html`에서 재생·일시정지·프레임 선택을 지원한다.

## v4 외형 비율 참조

`reusable/references/default-standing/v2`의 참조 이미지와 해시를 검증하고 리그 출처에 기록한다. 중립 높이 2m·머리 높이 0.4m를 유지하며 머리 폭 0.42m, 어깨 폭 0.50m, 고관절 높이 0.92m, 손목 높이 0.91m와 제작 메시 두께를 참조에 맞춰 수동 조정했다. 2D 이미지의 시각적 추정이며 자동 3D 피팅이나 모든 시점의 실루엣 일치를 보장하지 않는다. v3의 발 본 연결·회전 제한은 유지한다.

## v5 다리 비율

v4와 같은 원본 모션·구간·샘플 시점·발 회전 보정을 사용한다. 전체 높이와 머리·어깨 위치를 유지하고, 허벅지와 종아리 길이를 각각 10% 늘렸다. 발목 높이 0.085m 기준 고관절은 0.92→1.0035m, 무릎은 0.49→0.5305m로 변경하고 몸통 관절 간격을 줄였다. 기존 동작에 대한 사용자 승인과 비율 조정 후 새 버전의 검수 상태를 분리하여 기록한다.

미리보기는 방향별 기본 스탠딩 첫 프레임과 걷기를 나란히 표시한다. 알파 128 이상 최대 연결 영역으로 캐릭터 경계를 계산하고 스탠딩 높이와 걷기 한 주기의 합집합 높이를 각각 220px에 맞춘다. 걷기 프레임마다 배율을 바꾸지 않는다. 발밑 기준선과 높이 1/5 간격 선, 일시정지·프레임 선택으로 비율을 비교한다. 원본 이미지는 수정하지 않는다.

## v6 목·어깨 수정

생략되었던 목 본(joint-12)의 메시를 생성한다. 머리 위치와 전체 높이는 유지하고 어깨 중심 높이를 1.48m에서 1.40m로 내렸다. 팔 길이를 유지하도록 팔꿈치·손목도 0.08m 내렸으며 가슴 관절을 조정했다. 다리 길이와 v5의 모션 구간·샘플·발 회전 보정은 동일하다.

## v7 비교 이미지 기반 실루엣 보정

머리 크기와 다리 관절 길이·모션은 유지한다. 첨부 비교 이미지에서 확인한 몸통의 둥근 돌출과 골반 생략을 보정하기 위해 몸통 구 3개를 연속 타원 단면 메시로 교체했다. 골반 하단을 0.86m까지 표현하고 앞뒤 두께를 0.115~0.145m 반경으로 줄였다. 상단은 목 반경으로 좁혀 v6의 목·낮춘 어깨가 구분되도록 한다. 제작용 몸통은 joint-03에 강체 가중치로 연결되며 원화의 의복·해부학을 정밀 복원한 메시가 아니다.

## v8 스키닝·관절 연결

연속 몸통을 세 척추 본(joint-03/06/09)에 높이별 정규화 가중치로 연결하고 체적 보존 변형을 적용한다. 어깨 연결 본 메시와 어깨·팔꿈치·무릎 접합 볼륨을 추가했다. 전체 정점의 가중치 합 1.0과 발 회전을 검증한다. 다리 관절 배열은 v7과 동일하다. 여러 메시가 겹치는 제작용 리그이며 단일 연속 표면 토폴로지나 최종 의복 메시가 아니다.

## v8 기준 보존 및 v9 쇄골 보정

v8 기준은 `.result/workflow/reusable/rig-baselines/five-head-walk/v8/baseline.json`에 리그·모션·렌더 manifest의 해시와 생성 코드 사본으로 기록했다. 최종 승인과는 별도 비교 기준이다. v9는 쇄골·어깨 본 방향의 수직 성분을 10%로 줄이고 중립 본 길이를 복원한다. 팔꿈치·손목은 어깨 변화량만큼 이동하여 팔 스윙을 유지하며 하체 관절은 변경하지 않는다. 직선 걷기 제작 프로필용 보정으로 다른 동작에 일반화하지 않는다.

## 기본 리그 선택

현재 기본값은 `workflow/config/default_walk_rig.yaml`의 `five-head-walk/v9`다. 새 제작 실행에서는 `.local/blender-runtime/bin/python scripts/resolve_default_walk_rig.py`로 manifest와 Blender·모션 파일 해시를 검증하여 기존 자산 경로를 얻는다. 누락·변조·잘못된 설정은 즉시 실패하며 이전 버전으로 자동 전환하지 않는다. 생성 스크립트 재실행은 기본값 조회와 별개이며 기존 v9를 덮어쓰지 않는다. 기본값 채택은 최종 이미지 에셋의 런타임 등록을 의미하지 않는다.

## 스탠딩 미리보기 자료

`workflow/config/default_standing_preview.yaml`은 기본 스탠딩 참조 미리보기를 지정한다. `.result/workflow/reusable/previews/default-standing/v1/preview.html`에서 네 방향의 4프레임 루프를 재생하고 일시정지·프레임 선택으로 검수한다. 원본 sidecar의 anchor와 400ms 간격을 사용하며 배율은 고정한다. 이 자료의 `animation.json`은 전달받은 계약 스냅샷이고 `artifact.json`은 파일·참조 이미지 해시와 출처를 보존한다. 이미지 자체는 `reusable/references/default-standing/v2/reference.png`를 재사용한다. 프론트엔드 원본 경로를 런타임에 읽지 않는다.

기본 리그 v9 비교 미리보기 링크도 포함한다. `.result`의 재사용 자료는 캐시 정리 대상이 아니며 Git 추적 제외 상태는 기존 정책을 유지한다. 최종 스탠딩 에셋의 관리 원본은 프론트엔드다.

## 외형 프레임 생성 실행 기록

v9 리그 참조 외형 생성 실행은 `.result/workflow/runs/character-walk-v9-style-v1/generation.json`에 기록했다. 내장 이미지 생성 도구의 참조 5장 제한으로 스탠딩과 시점 1·3·5·7의 Depth/제작 렌더를 입력했다. 중간 포즈는 이미지 모델이 생성하며 기하 제약을 강제하지 않는다. 입력·출력 경로와 해시, 생성 방식, 품질 경고를 실행 기록에 보관하고 비공개 프롬프트는 공개 저장소에 포함하지 않는다.

출력은 방향별 4×2 시트다. 발 교대·방향·외형 일관성 미달로 검수 후보 상태이며, 프론트엔드에 파일을 전달했지만 런타임에는 등록하지 않았다. 재생 메타데이터는 150ms×8프레임의 검수용 초기값이다.

## 생성 이미지 폐기 상태

캐릭터 걷기 외형 생성 결과(프론트엔드 walk-v2/v3·개별 프레임 실험·외형 적용 리그)는 사용자 요청으로 폐기했다. 위 출력 설명은 과거 실행 기록이며 현재 이미지가 존재한다는 뜻이 아니다. `.result/workflow/disposals/character-walk-2026-09-20.json`에 폐기 파일·해시를 기록했다. 승인된 기본 v9 리그·MoMask·Depth·스탠딩 참조는 보존한다.
