# 레퍼런스 체형 및 구체관절 개선 후보

기준은 기존 `report/mannequin-reference-preservation-20260923`에 보관한 리그 실험이다. 기존 5등신 레퍼런스의 형태를 기준으로 작업하되 정확한 등신 수를 새로 판정한 결과는 아니다. 추가로 제공된 고관절 스케치와 BJD 구조 설명 자료는 골반 안에 구체가 들어가는 형태와 가동부 관찰에 참고했다.

## 변경

- 정면 비교를 바탕으로 어깨와 팔의 벌어짐, 머리 폭, 허리와 종아리 두께를 국소 조정했다.
- 내부 구체, 구체를 드러내는 팔꿈치·무릎의 곡선 개구부, 손목·발목 연결을 만들었다. 무릎 중심을 기존 생성 조형에 맞춰 올리고 중복 요철을 평활화했다.
- 눈에는 얕은 입체 렌즈와 홍채·동공, 눈썹을 머리 메시의 일부로 추가했다. 눈꺼풀·입술·손발의 정교한 조형은 추가 개선 대상이다.
- 중간 수정안에서 너무 크게 보인 고관절 구체는 부피를 약 32% 줄였다. 이는 기존 공유 리포트의 숨겨진 작은 내부 구체와 비교한 수치가 아니다.
- 구체 중심을 깊이 방향으로 0.017 안쪽에 옮기고, 측면 단면을 둥글게 조정했다. 골반 외피는 매끈한 단면으로 다시 만들고 상단은 기존 몸통에 맞췄다. 소켓과 허벅지 상단은 축소한 구체 표면에 맞춰 연결했다.
- 자료의 셸 방식을 외형 구성에 참고했으나, 실물의 탄성 줄·걸림·이중 관절·당겨 빼는 기구는 구현하지 않았다.

## 산출물

- `preview.html`: 원본 / 이전 / 수정 비교, 겹쳐보기, 고관절 축소 전후, 확대 및 보행.
- `rigged-mannequin.blend`, `rigged-mannequin.glb`: 편집 원본과 보행 리그.
- `validation.json`, `export-validation.json`: 25프레임 검사 및 GLB 계약 검사.
- `reference-silhouette-comparison.json`: 원본 레퍼런스 마스크와 비교한 2D 투영 외곽 IoU. 포즈·크롭 차이를 포함하며 전체 디자인 유사도 점수가 아니다.
- `hip-abduction.png`, `hip-flexion.png`: 약 35도 벌림, 약 70도 굽힘 수동 자세 관찰. 충돌 없는 가동 범위를 보증하는 수치 검증은 아니다.
- `inputs/`: 기준 모델·모션과 사용자가 제공한 참조 사본.

## 재실행

Python 3.11 / bpy 4.5.3 / numpy 1.26.4 / Pillow 12.3.0 환경을 사용한다. 현재 폴더를 새 `.tmp/mannequin-reference-refinement/<한국시간>/`에 복사하고, 복사본에서 아래 순서로 실행한다. GPU 렌더 단계는 샌드박스 밖 CUDA 환경에서 실행한다. 원래 실험 폴더를 덮어쓰지 않는다.

1. `run_stage.py sculpt_source.py`: 채택 모델에서 체형과 관절 주변 표면 정리.
2. `run_stage.py build_rig.py`: 소켓·구체·얼굴 생성, 가중치, 보행 리타게팅, Blender/GLB export, 정지·보행 렌더.
3. `run_stage.py validate_rig.py`, `validate_export.py`: 25프레임 및 GLB 검사.
4. `run_stage.py render_details.py`, `run_stage.py render_comparison.py`: 확대·수동 자세·동일 카메라 비교 렌더.
5. `create_review.py`: 비교 이미지 정렬, 외곽 지표와 미리보기 생성.

`run_stage.py`와 각 대상 스크립트는 위 버전 패키지가 설치된 Python으로 호출한다. 로그는 각 단계의 `*.log`로 보관한다. bpy 종료 정체 방지를 위한 실행 래퍼는 예외를 실패 코드로 전달한다.
