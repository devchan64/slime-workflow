# 기본 캐릭터 대기 포즈 ImageGen 변환

[16장 비교 화면](index.html) · [출처·해시·검증 기록](manifest.yaml)

기존 대기 샘플 16장의 자세를 기준으로 baseline-v2의 아이덴티티·복장·얼굴·헤어스타일·체형을 유지하도록 ImageGen 내장 도구로 변환한 검수 후보다. 사용자 요청에 따라 최종 결과와 비교 입력을 리포트 사본으로 보존했다.

## 결과와 한계

- 최종 PNG 16장: 4방향 × 프레임 1·5·9·13, 모두 1254×1254 RGBA.
- 16장 모두 알파 범위 0~255와 네 모서리 완전 투명을 확인했다. 전체 가장자리의 잔색·반투명 품질을 보증하는 검사는 아니다.
- 복장과 헤어스타일의 주요 특징은 반영됐으나 얼굴·체형·위치·높이의 완전 일치는 달성하지 못했다.
- 인물 높이는 512px 환산 약 479.74~498.53px이다. 모션에 따른 자세 변화와 생성 편차를 분리한 측정은 아니다.
- 후방 좌측 1·13번은 ImageGen으로 흰 배경을 추가 제거했다.
- GIF는 포함하지 않는다. 정식 에셋 채택·런타임 등록·커밋은 수행하지 않았다.

## 제작 및 출처

- 실행 경로: `.tmp/test/standing-baseline-imagegen/2026-09-27_21-49-33`
- 방향별 베이스라인을 외형 기준으로, 기존 리포트 프레임을 자세 기준으로 사용했다.
- 비공개 프롬프트 원문은 복사하지 않았다. 프롬프트·실행 기록 해시는 manifest에 기록했다.
- 내장 도구의 세부 모델·seed가 제공되지 않아 동일 결과의 결정적 재생성은 보장하지 않는다.
- 검수 시 원본 PNG와 베이스라인을 같은 캔버스 크기로 비교하며 추가 위치·비율 보정은 적용하지 않았다.
