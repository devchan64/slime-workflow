# 실험 리포트

`report/`는 **외부 공유용 특정 실험의 이력과 결과 사본**을 보관하는 경로다. 실험별 폴더에 실행 과정과 결과, 입력·파라미터·출처, 검증 기록, 필요한 재현 코드 및 산출물 사본을 함께 둔다. 공유받은 사람이 원래 실행 폴더에 접근하지 않아도 결과를 검토하고, 명시된 범위에서 재현성을 확인할 수 있게 한다.

- 원본 실행 로그와 수정 과정은 구분하여 기록하고, 실패·미검증 항목도 남긴다.
- 파일 사본의 무결성 확인 방법과 재현 명령, 필요한 환경 및 검증 범위를 제공한다.
- 재실행은 새 `.tmp/<executor-kind>/<한국시간>/`에 출력하여 보관 사본을 덮어쓰지 않는다.
- 원본 제작 자산의 관리 경로나 정식 에셋 등록·게임 런타임 채택을 대체하지 않는다.
- 비공개 기획·설계·내부 프롬프트, 인증 정보와 모델 가중치는 공유본에 넣지 않는다. PDF는 필수 산출물이 아니다.
