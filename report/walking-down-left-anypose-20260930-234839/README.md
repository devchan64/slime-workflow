## 보존 자료와 검증

각 `down_left/frame-NNNN/`에는 생성 PNG, 실제 캐릭터·포즈 입력, 프롬프트, 프레임 결과 및 로그를 원본 그대로 보존했다. 최상위 실행 기록도 원본 사본이며, 내부의 원래 실행 경로는 출처 정보다. 파일별 사본 경로·원본 경로·SHA-256은 manifest.yaml을 따른다.

복사한 모든 파일의 SHA-256이 원본과 일치하는지 확인했다. GIF는 12프레임·총 1500ms·무한 반복이다. GIF의 시간 단위가 10ms이므로 120/130ms를 배분해 평균 8 FPS를 유지한다. PNG의 색상·크기·배경은 수정하지 않았다.

시작·중간·마지막 이미지에서는 외형과 의상이 대체로 유지되지만 얼굴 방향과 몸 위치 변화가 관찰됐다. 전체 반복 재생의 자연스러움과 마지막→첫 프레임 연결은 사용자 검수 대상이다. 투명화·정식 스프라이트 등록·게임 적용은 이 리포트의 범위에 포함되지 않는다.

새 추론 없이 GIF를 재현하려면 result.json의 좌하 프레임 순서대로 결합하고 총 1500ms, 무한 반복으로 저장한다. 재현 출력은 새 `.tmp/test/<실험명>/<한국시간>/`에 저장한다. 모델 재추론에는 원본 요청, 등록 모션·캐릭터 및 프레임 result.json에 기록된 모델·어댑터 버전과 GPU 환경이 필요하다.
