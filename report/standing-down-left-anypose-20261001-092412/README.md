## 결과와 검수 범위

8프레임 모두 정상 완료됐다. 외형과 의상은 대체로 일관되지만 프레임별 자세 변화가 매우 작아 대기 동작의 움직임은 약한 편이다. 전체 프레임 비교에 근거한 관찰이며 자연스러운 호흡이나 완전한 루프 연결을 보증하지 않는다. 최종 품질 판단은 사용자 검수 대상이다.

원본 PNG와 실제 캐릭터·포즈 참조, 프레임별 프롬프트·결과·로그를 `down_left/frame-NNNN/`에 그대로 복사했다. 복사본 전체의 SHA-256 일치와 GIF 8프레임·총 1000ms·무한 반복을 검증했다. GIF는 10ms 시간 단위에 맞춰 120/130ms를 교대로 사용한다. 각 프레임의 위치·비율·배경은 추가 보정하지 않았다. `gif-review-result.json`에는 GIF 검증과 인접 프레임 차이 측정이 있다.

이 결과는 Qwen 생성 원본이며 ImageGen 보정본이나 정식 게임 에셋 교체본이 아니다. 기존 384px 걷기 에셋과 구분하며, 이번 대기 결과는 512px로 보존한다.

## 재현과 경로

GIF는 result.json의 좌하 프레임 순서대로 결합하고 프레임 시간을 120/130ms 교대로 설정하면 된다. 새 검수 산출물은 `.tmp/test/<실험명>/<한국시간>/`에 저장한다. 모델 재추론에는 요청에 기록된 등록 모션·캐릭터와 프레임 result.json의 모델·어댑터 버전 및 GPU 환경이 필요하며 완전히 같은 픽셀 결과를 보장하지 않는다.

사본의 상대 경로는 manifest.yaml을 따른다. 실행 기록 안의 원래 경로는 출처 정보이며, 원본 생성 이력과 다른 리포트·정식 에셋은 유지한다.
