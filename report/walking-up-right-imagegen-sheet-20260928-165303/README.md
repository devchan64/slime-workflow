# 우상 걷기 ImageGen 스프라이트 시트 리포트

## 보존 목적과 상태

사용자 요청에 따라 이번 이미지젠 후보 시트와 검수 자료를 리포트로 보존한다. 리포트 저장은 최종 에셋 채택이나 게임 런타임 등록을 의미하지 않는다. 커밋은 별도 지시 전까지 수행하지 않는다.

## 생성 출처

입력은 30스텝 ANNY 작업 `2026-09-28_15-06-32-ce084d85`의 결과 6장이다. 해당 작업은 AnyPose base/helper 0.7, Lightning 해제, 512px, 시드 10107을 사용했다.

내장 image_gen 도구로 생성했다. 참조 캐릭터의 머리·의상·체형을 유지하고, 여섯 원본 포즈의 시간 순서와 지지발 전환을 보존하면서 크기·카메라·지면 위치와 보행 연결을 자연스럽게 정렬하도록 지시했다. 프롬프트는 생성 지시이며, 포즈 정확도나 자연스러운 루프를 보증하는 검수 판정은 아니다.

## 규격 정리

이미지젠 생성 원본은 1881×836 RGBA이며 별도 보존했다. 각 열에서 주요 알파 연결 성분을 기준으로 여백을 정리한 후 동일 배율로 축소했다. 각 384px 셀의 가로 중앙과 하단 기준선 368px에 배치해 2304×384 PNG를 만들었다. 비균등 확대·축소는 하지 않았다. GIF는 확인 편의를 위해 흰 배경으로 합성했다.

## 검증 및 후속 검수

파일 크기·RGBA 모드와 GIF 6프레임·250ms 간격을 확인했다. 최종 채택 전 다음 사항은 사용자 검수가 필요하다.

- 원본 리그 대비 발 들림·무릎 굽힘·지지발 전환 재현
- 정지 자세처럼 보이는 구간과 마지막→첫 프레임의 루프 연결
- 프레임별 아이덴티티·크기·지면 앵커 일관성
- 투명 경계의 잔여 픽셀·색 번짐과 실사용 스프라이트 높이

원본 생성 이력과 실험 폴더는 유지한다. 이 리포트는 에셋 제작·검증 기록이며 비공개 기획 문서를 포함하지 않는다.
