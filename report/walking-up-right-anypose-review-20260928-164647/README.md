# 우상 걷기 AnyPose 검수 리포트

## 판정

**현재 6프레임 묶음은 채택 보류 권고다.** AnyPose 강도 0.7→0.85와 4스텝→30스텝 표준 생성 모두 정지 자세처럼 보이는 프레임을 해소하지 못했다. 세 조건의 픽셀이 동일하다는 뜻은 아니며, 이번 표본에서 보행 포즈 재현의 뚜렷한 개선을 확인하지 못했다는 판정이다. 최종 품질 승인은 사용자에게 있다.

## 대상과 검증 범위

- 등록 모션: walking-v13, 우상(up_right), 원본 1·5·9·13·17·21번.
- 캐릭터: 기본 흰 셔츠 v2. 512×512, 생성 배속 4, 결과 4 FPS, 6장·1.5초 반복.
- 같은 번호의 입력 이미지 해시와 최종 프롬프트 해시가 세 실행에서 일치함을 확인했다. 시드 10107, Qwen Image Edit 2511을 사용했다.
- 실제 프레임 이미지 18장과 대응 ANNY 리그 6장의 정적 비교를 수행했다. GIF는 같은 번호를 동시에 재생하도록 제공한다. 관절 좌표 오차·지면 접촉·실시간 재생 체감은 정량 측정하지 않았다.
- 사용자가 GIF 검수에서 정지 자세를 지적했고, 0.85 강도 변경에 효과가 없다고 판단했다. 아래 프레임 관찰은 이미지 비교에 기반한다.

| 조건 | AnyPose base/helper | 스텝 | Lightning | true CFG |
|---|---|---|---|---|
| 기준 | 0.7 / 0.7 | 4 | 사용, 강도 1.0 | 1.0 |
| 강도 비교 | 0.85 / 0.85 | 4 | 사용, 강도 1.0 | 1.0 |
| 표준 생성 | 0.7 / 0.7 | 30 | 해제 | 4.0 |

30스텝 비교는 스텝·Lightning·CFG가 함께 바뀐 실행 방식 비교다. 스텝 수만의 효과로 해석할 수 없다. 강도 비교도 두 어댑터를 동시에 바꾸었으므로 개별 기여를 구분할 수 없다.

## 프레임별 관찰

| 5 | 다리 교차와 뒤쪽 발의 들림은 전달된다. 발목·신발 방향과 다리 간격은 리그와 차이가 남는다. |

| 13 | 리그의 앞으로 들린 발과 보폭이 결과에서 약해진다. 세 조건 모두 포즈 차이가 남는다. |
| 17 | 뒤로 뻗는 다리는 표현되지만, 리그의 굽힌 무릎이 결과에서 더 펴져 보인다. 강도·스텝 변경으로 명확히 해결되지 않는다. |
| 21 | 리그의 다리 겹침과 무릎 굽힘이 결과에서 약해지고 서 있는 자세에 가까워진다. |

외형은 세 조건 모두 흰 셔츠·회색 반바지·갈색 머리를 유지한다. 다만 프레임별 몸 크기·머리 위치·신발 위치가 달라 보이며, 이는 리그 동작과 생성 오차가 섞인 관찰이다. 기준 관절·앵커로 정규화한 측정 없이 모두 흔들림으로 단정하지 않는다.

## 연속성과 루프

9번과 21번처럼 정지 실루엣에 가까운 장면은 4 FPS에서 각각 250ms 유지된다. 사용자가 지적한 멈춤 인상과 연결될 가능성이 있다. 단, 1~22번 범위를 4칸 간격으로 추출했다는 사실만으로 완전한 보행 주기라고 볼 수 없다. 21→1번 접합의 지지발·보행 위상은 별도 확인이 필요하다. GIF를 만들었다는 사실은 루프 품질 승인과 다르다.

## 다음 검수 제안

1. 원본 모션에서 지지발을 유지하면서 반대 발의 들림·무릎 굽힘이 명확한 프레임을 찾는다.
2. 양발 교대와 시간 순서를 유지하고, 완전한 보행 주기 및 마지막→첫 프레임 접합을 먼저 리그로 확인한다.
3. 후보 프레임 한 장으로 포즈 전달을 먼저 검증한 뒤 배치로 확대한다. 이번 결과만으로 모든 강도·스텝 설정이 무효라고 일반화하지 않는다.
