# Qwen 2.1 순환 VAE 변경 기록

## 2026-11-16 · Qwen 이미지 생성기 아카이브

- 신규 생성·재개·우선 실행을 중단하고 기존 이력·입력·결과·로그 조회를 유지한다. 진행 중 작업은 자동 취소하지 않는다.

## 2026-11-16 · VAE 타일 인코딩·디코딩 중단

- 공용 Qwen 2.1 VAE의 타일 인코딩과 디코딩을 끈다. 기존 생성 이력 재개에도 새 설정이 적용되므로 과거 출력과 동일하지 않을 수 있으며, 메모리 부족 시 자동 타일 대체 없이 실패한다.

## 2026-11-15 · 공용 화풍 기본 적용

- 새 Qwen 이미지 요청에 공용 화풍 v1.5.0 원문을 기본 적용하고 이전 짧은 화풍 옵션을 폐기했다. 기존 기록은 저장된 입력으로 재개한다.

## 2026-11-15

- 생성기 페이지에서 이 변경 기록을 확인할 수 있도록 연결했다.
- 생성기별 페이지 구성을 분리하고 공용 화면과 기존 주소·이력 연결을 유지한다.
- 공용 Qwen 2.1 비양자화 이미지 생성의 CPU 오프로드를 해제했다. (Git `3362c623`)

## 2026-10-07

## 2026-10-06

## 2026-10-05
