# MiniMax H3 FL2VA 변경 기록

## 2026-11-27 · 입력·이력 경계와 복원 확인

- 독립 입력폼에 남아 있던 내부 이력 전환을 제거하고 대화 내장 이력은 유지한다. 저장 입력 적용 전 생성 모드별 이미지 수와 마지막 프레임 확인 상태를 검사한다.

## 2026-11-27 · 기존 이력 주소 정리

- 기존 이력 보기 주소도 공통 영상 이력 페이지에서 열어 독립 입력폼과 이력의 역할을 분리한다.

## 2026-11-27 · 모델 계열 정의 정리

- 텍스트만, 첫 프레임, 마지막 프레임, 첫·마지막 프레임 입력과 124~345프레임 선택을 추가한다. 첫·마지막 프레임의 124·192프레임 생성은 완료됐고, 텍스트만·마지막 단독과 다른 길이는 GPU 검증이 필요하다. 기존 첫 프레임 요청과 저장 이력 형식은 유지한다.

## 2026-11-27 · 영상 생성 이력 구성 정리

- 영상 생성과 편집의 공통 이력 페이지를 추가하고, 서비스별 이력과 저장 입력 복원 방식을 유지한다. 입력 화면은 새 탭에서 이력을 열어 작성 중인 입력을 보존한다.

## 2026-11-26 · 입력과 이력 분리

- 독립 생성기의 입력폼과 생성이력을 페이지로 구분하고 작업 결과와 입력 복원을 연결했다.

## 2026-11-26 · 실행별 임시 경로

- 컴파일 임시 파일을 작업 시도 폴더에 두어 시스템 임시 디렉터리의 할당량과 분리한다. GPU 생성 검증은 실행 결과로 확인한다.

## 2026-11-24 · 헤르메스 자동 보고

- 대화 제안의 접수 기록과 결과 분석·보고 상태를 연결했습니다. 표본 분석과 생성 완료는 별도로 확인합니다.

## 2026-11-24 · 프롬프트 사용설명

- 공식 첫 이미지 기반 프롬프트 가이드와 동작·소리 작성 예시를 사용설명에 추가했습니다.
- 480p 한손검 생성 결과와 미검증 범위를 기록했습니다.

## 2026-11-24 · 480p 기본값

- 기존 한손검 기준 이미지와 맞추어 기본 출력 해상도를 832×480으로 변경했습니다. 실제 480p 생성 검증은 아직 진행하지 않았습니다.
- 기존 768×448 요청과 저장된 입력 복원을 유지합니다.

## 2026-11-24

- 첫 프레임 이미지와 동작 프롬프트를 사용하는 Diffusers 기반 I2V 생성기를 등록했습니다.
- Radeon 8060S에서 실험한 FP8 저장·BF16 GPU 연산, INT8 인코더와 8스텝 Turbo 설정을 사용합니다.
- 768×448, 124프레임, 24fps를 실험 기본값으로 고정하고 오디오가 포함된 영상과 프레임 ZIP을 저장합니다.
- 한 차례 검술 시험에서는 발 전진과 검 들기가 관찰됐지만 내려베기는 완성되지 않았습니다.

## 2026-11-24 · 보고 재분석

- 보고 실패 또는 시각 관찰 불가 시 생성 결과를 보존하며 대화에서 재분석을 요청할 수 있습니다.
