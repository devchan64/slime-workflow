# MiniMax H3 I2V 변경 기록

## 2026-11-24 · 480p 기본값

- 기존 한손검 기준 이미지와 맞추어 기본 출력 해상도를 832×480으로 변경했습니다. 실제 480p 생성 검증은 아직 진행하지 않았습니다.
- 기존 768×448 요청과 저장된 입력 복원을 유지합니다.

## 2026-11-24

- 첫 프레임 이미지와 동작 프롬프트를 사용하는 Diffusers 기반 I2V 생성기를 등록했습니다.
- Radeon 8060S에서 실험한 FP8 저장·BF16 GPU 연산, INT8 인코더와 8스텝 Turbo 설정을 사용합니다.
- 768×448, 124프레임, 24fps를 실험 기본값으로 고정하고 오디오가 포함된 영상과 프레임 ZIP을 저장합니다.
- 한 차례 검술 시험에서는 발 전진과 검 들기가 관찰됐지만 내려베기는 완성되지 않았습니다.
