# 프롬프트 번역 변경 기록

## 미출시

- 번역 이력 카드에서 불필요한 썸네일 영역을 숨긴다.

- 번역 이력을 공용 생성 이력으로 전환하고 결과·입력 복원·로그와 작업 중지·재개·우선 실행·선택 삭제·전체 초기화를 연결했다. 삭제는 실행·대기 작업을 보호한다.

- 작가 AI 모델을 이용한 부정 범위 의미 검토와 원문 근거 검증을 추가했다. 실제 GPU 품질 검증은 대기 중이다.

- 실제 프롬프트의 배경·프레임·접지·참조 조건과 일부 금지 표현을 점검하고 지원하지 않는 부정문을 수동 검토 대상으로 표시한다.

- 번역의 숫자 행·열 역전과 두 핵심 조건의 대응 표현을 점검하고 불확실한 경우 확인 필요로 표시한다.

- 실제 화풍·캐릭터·스탠딩 프롬프트의 영어·중국어 결과를 검토하고 공통 원문의 영어 용어 세 개를 비교 기준에 추가했다.

- 원문을 그대로 번역하고 승인 용어 및 사용자가 확인한 용어의 불일치를 표시한다. 작가 AI 색인의 문서 후보와 출처를 조회한다.
- 중국어 간체 요청을 공식 모델 템플릿의 `zh-Hans` 코드로 변환한다. ROCm 대기열에서 영어·중국어 각 2건을 실행하고 용어 번역의 한계를 확인했다.
- 모델 관리에 고정 리비전 다운로드·준비 상태와 파일 목록을 연결하고 번역 페이지에 모델 관리 이동을 추가했다.

- TranslateGemma 4B 번역 요청과 공용 GPU 대기열·게이트웨이·텍스트 기반 페이지를 연결했다.
- 실제 모델 파일 준비와 ROCm 추론 및 번역 품질 검증은 남아 있다.
