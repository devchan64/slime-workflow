# Wan2.2 Fun Control 변경 기록

- 대화 생성 패널에서 원본·현재 시드를 비교하고 결과 입력을 다시 사용할 수 있다.

- 대화의 시드 변경 제안에서 원본 입력과 새 시드를 검토할 수 있도록 했다.

- Hermes 대화에서 입력 폼을 저장·복원하고 확인 후 접수된 작업 결과를 다시 열 수 있다.

- 생성기와 Hermes 대화에서 json-render 기반 공용 입력 필드와 결과 뷰어를 사용하는 시제품을 추가했다.

- 시드 입력 범위와 랜덤 선택을 생성기가 허용하는 0~2,147,483,647로 맞추고 범위 밖 입력을 거부한다.

- 생성 이력 카드와 선택 요약에 1.3B 또는 A14B 모델을 표시한다. 이전 14B 이력은 기존 태그로 구분한다.

- 기존 준비 상태 기록을 확인할 수 없을 때 새 모델 준비를 보류한다.

- 임시 HTTP 경로에서 심볼릭 링크 작업의 선행 거부를 검증했다.

- 직접 재개가 심볼릭 링크 작업 디렉터리나 저장소 밖 경로를 거부한다.

- 기존 직접 재개도 공용 접수 잠금과 다른 준비 작업 충돌 검사를 적용한다.

- 준비 작업은 재개 예비 검토의 중단 상태 복구 전에 제외한다.

- 과거 `-prepare` 이력도 재개 전 모델 준비 충돌 검사에 포함했다.

- 임시 게이트웨이에서 공유 접수 잠금 경합 시 모델 준비 거부를 확인했다.

- Hermes 대화·운영 이력·MCP의 검토 기반 재개 접수에 연결했다.

- Wan Fun 생성·준비와 검토된 재개 접수에 프로세스 간 공용 잠금을 적용했다.

- 원 서비스에 검토 지문 기반 재개를 추가하고 같은 관리기의 준비 접수와 충돌을 검사한다.

- 원 서비스 재개 예비 검토에서 숨겨진 준비 이력과 확인 불가 기록을 포함해 대기·실행 충돌을 관측한다.

- 임시 MCP·게이트웨이에서 생성 작업의 예비 검토와 접수 차단을 검증했다.

- Hermes와 Codex MCP의 재개 예비 검토에 연결했다. 재개 접수는 지원하지 않는다.

- 생성 작업에 원 서비스 재개 예비 검토를 등록하고 준비 충돌 확인 상태를 미확인으로 표시한다.

- 생성 재개 검토 연결을 위해 모든 제어 입력을 포함하는 내부 지문 계산을 추가했다.
