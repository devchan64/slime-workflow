# Wan2.2 VACE-Fun 변경 기록

## 2026-11-27 · BF16 인코더와 토크나이저 분리

- VACE UMT5 BF16과 공식 토크나이저를 각각 독립 경로로 이관하고 기존 상위 Samba 스냅샷을 보존한다.

## 2026-11-27 · LoRA 모델별 경로 분리

- Fighting High와 Lightning T2V 고·저 쌍을 독립 경로로 이관했다. 기존 상위 백업을 보존하며, 이동 전후 고정 크기와 SHA-256을 확인했다.

## 2026-11-27 · 공용 모델 경로 정리

- 공용 UMT5와 VAE를 독립 모델 경로로 이관하고 이관 전후 경로를 확인하도록 연결했다. 이관 전 상위 Samba 스냅샷은 보존한다.

## 2026-11-27 · 백업 우선 모델 복원

- 공용 VAE가 없으면 코드에 고정된 크기와 SHA-256으로 Samba 백업을 먼저 확인하고, 없으면 기존 공급처 다운로드를 사용한다.

## 2026-11-24 · 영상 조건과 마스크 안내

- 영상 전체 조건과 마스크 편집의 공통 생성 방식·차이·보존 한계와 한손검 조건 강도 비교 관측을 사용설명에 추가했다.

## 2026-11-23 · 권장 용도 안내

- 첫 프레임 기반 한손검 실험의 제한을 기록하고, 기존 모션 영상 편집·가공을 우선 권장하도록 사용설명을 보완했다. 원본 동작 보존은 별도 검수가 필요하다.

## 2026-11-23 · Q8 파일 준비

- Q8_0 고·저노이즈 모델 파일의 고정 출처 및 모델 관리 다운로드·해시 검증을 추가했다. Q8 선택과 GPU 연산 경로를 추가했으며 49프레임·4스텝·CFG 1에서 Lightning 단독과 격투 강도 0.5 실제 생성 및 수치 검사를 각 1회 완료했다. 목표 동작 품질은 미달이다.

## 2026-11-23 · 격투와 Lightning CFG 실험

- 격투 + Lightning 조합에서도 CFG를 변경할 수 있게 했다. 4스텝·shift 5는 유지하며 CFG 1을 기본으로 한다.

## 2026-11-23 · 사용설명 통합

- 화면의 사용 안내를 생성기 README에 통합하고 해당 문서를 사용설명 카드에서 직접 읽도록 변경했다.

## 2026-11-23 · CFG 설명 근거 구분

- Lightning CFG에 관한 모델 카드의 명시 내용, 로컬 기본값과 제한된 실험 관측을 구분하도록 사용설명을 정정했다.

- 격투 LoRA만 사용하는 선택지를 추가했다. Lightning 없이 High 전문가에 병합하며 일반 스텝과 CFG를 사용할 수 있다. 단독 GPU 품질은 미검증이다.

## 2026-11-22 · Lightning 단독 선택

- 격투 LoRA 없이 Lightning High/Low만 적용하는 선택지를 추가했다. 4스텝·CFG 1·shift 5를 적용하며 단독 GPU 실행은 별도 검증한다.

## 2026-11-22 · 격투와 Lightning 실험

- 격투 High와 Lightning T2V High/Low의 결합 옵션, 독립 모델 준비 및 파일 해시·병합 개수 기록을 추가했다. GPU 실행과 품질 검증은 별도다.

- ROCm 5프레임·4스텝 텍스트 시험 `2026-11-22_21-15-42-88b04484`에서 각 LoRA 400개 층 병합과 4스텝 수치 검사는 통과했다. 결과에는 격자형 번짐이 보여 품질은 미흡하며 원인은 미확인이다. 포즈 추종은 별도 검증한다.

- ROCm 37프레임 포즈 시험 `2026-11-22_21-24-31-ba25da8b`은 각 LoRA 400개 층과 4스텝·VAE 유한값 검사를 통과했다. 입력의 팔 동작 일부는 보이나 자세·방향 차이와 배경 경계 반복이 있어 정확한 추종과 품질을 보장하지 않는다. 출력 비교는 다섯 프레임의 육안 검수이며 기준 설정과 정량 비교는 하지 않았다.

## 2026-11-22 · 격투 LoRA 모델 준비

- 모델 관리에 Videogame Fighting High LoRA의 독립 다운로드와 SHA-256 검증을 추가했다. VACE 생성기 연결과 실제 추론은 아직 검증하지 않았다.

## 2026-11-22 · 공용 페이지 식별

- 작업 결과에 저장 입력을 자동 표시하고 `입력 적용` 한 번으로 첨부와 설정을 복원한다.

- 선택하거나 이력에서 복원한 포즈·원본·마스크 입력 영상을 생성 입력에서 직접 재생해 확인한다.

- 이력의 입력 확인을 결과 영상보다 먼저 표시하고, 입력 적용 시 접힌 생성 입력을 열어 복원 내용을 확인할 수 있게 했다.

- 선택한 작업 결과를 생성 이력의 해당 작업 아래에 표시하고, 진행 중 작업과 직접 주소에서도 이력에 연결한다.

- 사용 설명과 생성기 변경 기록을 같은 접이식 카드 서식으로 표시하고, 사용 순서와 입력 조건을 페이지에서 안내한다.

- 변경 기록뿐 아니라 생성기 이력·모델 파일 등 접기·펼치기 조작을 공용 크기와 경계로 표시한다.

- 생성기 변경 기록의 제목 글자 크기와 행간을 공용 컴포넌트에서 개선했다.

- 모델·진행·이력·결과 영역을 제목과 경계로 구분하고 주요 섹션 여백 및 행간을 UI 기준에 맞췄다.

- 실행·대기 중인 VACE 작업의 진행 상황을 모델 상태 아래에 표시하고 작업별 결과로 이동할 수 있게 했다.

- 생성 입력을 입력 자료·장면 지시·생성 설정으로 나누고 부정 프롬프트가 선택 사항임을 표시했다.

- 생성 입력·이력·선택 결과로 이동하는 공용 탐색을 추가하고 결과 영역을 구분했다.

- Kimodo 기준의 본문 폭·제목·일반 입력 여백과 글꼴을 공용 생성기 서식으로 통일했다.

- 페이지 제목과 변경 기록 연결을 공용 생성기 페이지 등록부로 관리한다. 기존 생성 입력과 이력 기능은 유지한다.

## 2026-11-22 · 텍스트·참조 입력

- 시드 입력·랜덤 선택 범위를 생성기 허용 범위인 0~2,147,483,647에 맞췄다.
