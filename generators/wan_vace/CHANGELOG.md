# Wan2.2 VACE-Fun 변경 기록

## 2026-11-22 · 공용 페이지 식별

- 변경 기록뿐 아니라 생성기 이력·모델 파일 등 접기·펼치기 조작을 공용 크기와 경계로 표시한다.

- 생성기 변경 기록의 제목 글자 크기와 행간을 공용 컴포넌트에서 개선했다.

- 모델·진행·이력·결과 영역을 제목과 경계로 구분하고 주요 섹션 여백 및 행간을 UI 기준에 맞췄다.

- 실행·대기 중인 VACE 작업의 진행 상황을 모델 상태 아래에 표시하고 작업별 결과로 이동할 수 있게 했다.

- 생성 입력을 입력 자료·장면 지시·생성 설정으로 나누고 부정 프롬프트가 선택 사항임을 표시했다.

- 생성 입력·이력·선택 결과로 이동하는 공용 탐색을 추가하고 결과 영역을 구분했다.

- Kimodo 기준의 본문 폭·제목·일반 입력 여백과 글꼴을 공용 생성기 서식으로 통일했다.

- 페이지 제목과 변경 기록 연결을 공용 생성기 페이지 등록부로 관리한다. 기존 생성 입력과 이력 기능은 유지한다.

## 2026-11-22 · 텍스트·참조 입력

- 공식 파이프라인의 텍스트·참조 전용 실행에도 공식 예제의 빈 영상과 전체 마스크를 전달한다. 텍스트 5프레임·2스텝 실제 GPU 작업 `2026-11-22_12-32-03-7770e198`이 완료됐으며 영상 품질은 사용자 검수 대기다. 참조 모드는 실제 GPU 재검증이 남아 있다.

- 시드 입력·랜덤 선택 범위를 생성기 허용 범위인 0~2,147,483,647에 맞췄다.

## 2026-11-19 · 원본 이력 검색

- 원본 이력 관측에서 작업 ID 일부를 검색하고 검색 조건에 페이지 확인값을 묶는다.

- 이력 페이지 변경 시 카드 이미지의 접근성 설명도 현재 작업에 맞춰 갱신한다.

## 2026-11-17

- 공식 영상 읽기의 PyAV 대체 디코더를 공유 실행 의존성에 포함하고 격리 영상 입력을 확인했다.

- 공유 이미지 실행 환경에 공식 VACE import 및 영상 출력 의존성을 추가하고 격리 환경에서 import와 시험 MP4 출력을 확인했다. 전체 생성은 별도 검증 대상이다.

- 수치 실패 텐서와 원래 배치를 보존하고 어텐션 실패 행 비교를 동등한 명시적 SDPA 조건으로 제한했다.

- VAE 내부의 실제 SDPA 입력을 선택적으로 보존하고 기본·수학 경로와 반복 출력을 비교하는 진단 경로를 추가했다. ROCm 실제 입력 비교는 미실시다.

- VAE 인코딩·디코딩과 조건 텐서의 비유한 값 실패 검사를 추가했다. 합성 CPU 테스트만 수행했으며 실제 ROCm 생성은 미검증이다.
