# 마네킨 생성기

관리도구 이미지 생성 메뉴에서 Qwen 2.1로 마네킨 기준 후보를 만든다. 관절 신체 조정, 피부·기본복 적용, 기본 얼굴 조정, 전신 얼굴 적용 단계에서 이미지와 파일명을 미리 확인하고 적용하면 프롬프트와 첫 두 참조가 교체된다. 전신 얼굴 적용은 관절 신체 마네킨을 첫 참조, 기본 얼굴을 두 번째 참조로 사용한다. 적용 후 구체적인 변경 조건을 프롬프트에 추가한다. 참조 3번 이후는 유지한다. 공용 화풍 v1.5.0은 다른 Qwen 생성기와 같이 최종 입력에 적용된다.

일반 Qwen 2.1 대기열·이력·삭제 기능을 공유한다. 생성 결과는 임시 후보이며 [마네킨 기준 원본](../../baseline/mannequin/README.md)을 자동 교체하지 않는다. 검수와 채택은 [제작 절차](../../workflows/character-baseline-mannequin.md)를 따른다.
