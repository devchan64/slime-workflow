# 마네킨 생성기

관리도구 이미지 생성 메뉴에서 Qwen 2.1로 마네킨 기준 후보를 만든다. 관절 신체 조정, 피부·기본복 적용, 기본 얼굴 조정, 전신 얼굴 적용 단계에서 이미지·파일명·프롬프트 예시를 미리 확인하고 적용하면 프롬프트와 첫 두 참조가 교체된다. 피부·기본복 적용은 얼굴이 있는 관절형 전신을 첫 참조로 사용하며 기존 이목구비와 표정을 유지하도록 요청한다. 전신 얼굴 적용은 얼굴 없는 관절 신체 마네킨을 첫 참조, 기본 얼굴을 두 번째 참조로 사용한다. 적용 후 구체적인 변경 조건을 프롬프트에 추가한다. 참조 3번 이후는 유지한다. 단계 적용 시 전신은 기준과 같은 2:3 비율의 768×1152, 얼굴은 1:1 비율의 1056×1056 출력을 설정한다. 신체 비율과 얼굴은 자동 고정되지 않으므로 원본과 결과를 비교한다. 공용 화풍 v1.5.0은 다른 Qwen 생성기와 같이 최종 입력에 적용된다.

GPU 대기열은 공유하고 마네킨 생성 이력과 삭제 범위는 독립한다. 이전에 일반 Qwen 이력으로 생성한 결과는 일반 Qwen 이력에서 확인한다. 생성 결과는 임시 후보이며 [마네킨 기준 원본](../../baseline/mannequin/README.md)을 자동 교체하지 않는다. 검수와 채택은 [제작 절차](../../workflows/character-baseline-mannequin.md)를 따른다.

## 참조 이미지 편집 시 시드

참조 이미지를 만든 생성 이력의 시드와 같은 시드로 후속 편집하면 초기 노이즈가 재현되어 이미지 전체에 거친 무늬가 생길 수 있다. 현재 관절 전신 마네킨 기준의 생성 시드는 10107이며 CLI 기본값도 10107이다. 화면의 생성마다 무작위 시드가 기본으로 켜져 있으므로 사용 시드가 기준 시드와 다른지 확인한다. 고정 시드가 필요하면 자동 선택을 끄고 값을 지정한다. 생성 이력에서 입력을 불러오면 저장 시드를 복원하고 자동 선택을 끈다. 생성 이력에서 실제 시드를 확인하고 기록하면 같은 조건으로 재시도할 수 있다. 다른 시드도 품질과 신체 비율이 자동 보장되지는 않으므로 전체 결과를 원본과 비교한다. 출처 시드를 알 수 없는 이미지에도 고정 기본 시드의 반복 사용을 피한다.

## 참조 처리 진단

통합 CLI의 `generate --reference-resolution 992|1024|1056`은 출력 크기가 아닌 모델 내부 참조 처리 면적을 선택하는 실험 옵션이다. 기본값은 1024이고 실제 가로·세로 크기는 참조 비율에 따라 계산한다. `--diagnostic-vae-roundtrip`을 함께 지정하면 참조 한 장의 전처리 결과 `vae-input.png`와 타일링 없는 VAE 인코딩·디코딩 결과 `vae-roundtrip.png`를 작업 폴더에 기록한다. 생성 결과와 별도로 비교하며 기준 원본을 변경하지 않는다. 두 옵션은 현재 진단용 CLI에서만 제공하고 생성 이력에 저장하여 재개한다.

전체 생성기 공통 사용법과 검증 범위는 [Qwen 이미지 생성 시드 안내](../../workflows/qwen-seed-guidance.md)를 따른다.
