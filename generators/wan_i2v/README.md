# Wan 2.2 I2V 실험

`wan22-i2v` 공용 GPU 대기열 서비스와 생성 화면은 832×480 첫 프레임과 프롬프트를 사용한다. I2V A14B FP16 체크포인트를 BF16으로 실행하고 Lightning 고·저노이즈 LoRA를 각 전문가에 적용할 수 있다. 모델 관리는 `wan22-i2v-assets`를 사용한다. 재개는 아직 미구현이다.

2026-11-23 Radeon 8060S에서 한손검 참조, Lightning 4스텝, 5프레임과 81프레임 각각 한 회 실행했다. 81프레임의 관측 스텝·최종 프레임 유한값 검사를 통과하고 MP4를 저장했으며 약 1,736초, 5초 표본의 작업 프로세스 GPU 메모리 피크는 60,533 MiB였다. 짧은 실행 뒤 전체 실행에서 예약 하한이 실측값으로 낮아지는 문제를 수정했다. 표본은 순간 피크나 다른 입력의 요구량을 보장하지 않는다. 영상의 손·검 접촉과 베기 품질은 사용자 검수 대상이다.

실행은 GPU 초기화 전 `expandable_segments:False`와 프로젝트 `.tmp` 임시 경로를 지정한다. VAE는 FP32 기본 SDPA 경로이며 실제 선택된 커널과 동일 입력의 수학 SDPA 대비 정확도는 확인하지 않았다. 이 실행을 TLB 문제의 근본 해결이나 모든 입력의 안전성으로 일반화하지 않는다.
