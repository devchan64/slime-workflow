# 변경 기록

## 2026-11-27 · Lightning 모델 경로 분리

- I2V Lightning 고·저 LoRA를 독립 경로로 이관하고 기존 상위 백업에서 복원할 수 있게 했다.
- 폐기된 KungFu LoRA 쌍도 별도 경로로 보존한다. 생성 옵션은 다시 활성화하지 않는다.

## 2026-11-27 · 공용 모델 경로 정리

- 공용 UMT5와 VAE를 독립 모델 경로로 이관하고 이관 전후 경로를 확인하도록 연결했다. 이관 전 상위 Samba 스냅샷은 보존한다.


## 2026-11-24
- KungFu 고·저노이즈 LoRA 선택과 실행을 폐기하고 한손검 비교 실험 결과는 사용 안내에 보존했다.
## 2026-11-23

- 생성 입력의 비활성 사유와 프레임 범위를 표시하고, Lightning 고정값과 KungFu 전용 강도를 구분했다. 요청 확인에 해상도·CFG·Shift 등 실제 설정을 표시하고 입력·이력·결과 이동을 추가했다.
- KungFu 선택 시 한손검 실험에서 관찰된 무술 동작·검 흐림을 생성 입력과 요청 확인에 안내한다. 선택과 생성 기능은 유지한다.
- 한손검 81프레임에서 Lightning 단독과 Lightning+KungFu를 각 한 회 비교했다. KungFu 쪽에는 트리거 단어를 추가했으며, 표본 프레임에서 넓은 보폭·회전과 마지막 검의 흐림을 관찰했다.
- 도구 탐색과 I2V 생성 화면을 연결하고 헤르메스 생성 요청 스킬에 첫 프레임 입력 안내를 추가했다.
- I2V 본체와 Lightning·KungFu 파일의 고정 출처 및 SHA-256 준비를 추가했다.
- I2V 실험 작업자를 공용 GPU 대기열과 CLI에 연결하고, Lightning 고·저노이즈 LoRA의 적용 수와 추론 경계의 비유한 값을 검사한다.
- LLVM 임시 파일을 프로젝트 `.tmp`에 두고 5프레임 및 81프레임 Lightning 실험을 실행했다. 화면·재개·SDPA 정확도 및 장기 안정성은 별도 검증 대상이다.
