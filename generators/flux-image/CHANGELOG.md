# 일반 이미지 생성기 변경 기록

## 2026-11-19 · 원본 이력 검색

- 원본 이력 관측에서 작업 ID 일부를 검색하고 검색 조건에 페이지 확인값을 묶는다.

## 2026-11-19

- 운영 이력에서 전달된 작업 ID를 확인한 뒤 생성 이력에서 찾는 연결을 추가했다.
- 이력 페이지 변경 시 카드 이미지의 접근성 설명도 현재 작업에 맞춰 갱신한다.

- 비양자화 FLUX 구성요소를 ROCm GPU에 순차 적재하고 CPU 자동 오프로드 없이 상주 실행한다. 기존 오프로드 이력과 메모리 예약을 분리한다.

- GPU 실행 중 호스트 메모리 압박 보호를 적용하고 보호 중지 시 실패 사유를 기록한다.

## 2026-11-17 · 한국어 프롬프트 번역 연결

- 한국어 설명을 공용 번역 대기열에서 영어로 변환한 후 기존 준비 문구와 결합해 이미지 생성을 자동 등록한다. 번역 실패·취소 시 생성하지 않는다.
- 한국어 원문·번역문·검토 항목과 최종 입력을 이력에 보존하고 기존 영어 이력의 입력 복원·재개를 지원한다.

## 2026-11-16 · FLUX 생성기 도입

- FLUX 3 Image Klein 공용 실행기와 공용 화풍 v1.5.0을 사용한다. Qwen 이력과 새 이력은 분리한다.
- 결과는 검수용 후보이며 비율·색상·화풍의 정확한 유지와 투명 배경은 보장하지 않는다.
