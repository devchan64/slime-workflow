# MiniMax H3 건물 이미지 생성기

FLUX 건물 생성기의 배치 가이드를 첫 참조로 적용하고 건물의 용도와 재질을 프롬프트에 입력합니다. 직접 PNG 참조를 선택할 수도 있습니다. 최종 프롬프트와 GPU 대기열을 검토한 뒤 생성합니다. 입력한 프롬프트를 그대로 전달하며 별도의 번역 기능을 사용하지 않습니다. 헤르메스가 건물 요청을 준비할 때는 한국어로 작성해 전달합니다.

MiniMax H3 이미지 생성기의 모델, 설정, 대기열과 전체 이력을 공유합니다. 생성 결과의 건물 형태와 가이드 일치 여부는 사용자가 검수해야 합니다. 출력은 RGB이며 투명 배경을 보장하지 않습니다.

생성기 입력폼과 생성이력은 별도 페이지로 이동합니다. 진행 작업이나 이력의 입력 적용을 통해 작업 결과와 저장 입력을 확인할 수 있습니다. 일반 MiniMax 이미지의 전체 이력을 공유합니다.

일반 이미지와 건물 폼은 공통 이미지 이력 페이지를 사용합니다. 이력 이동 전 입력은 현재 브라우저 탭에 임시 보존되며, 저장된 입력은 이력에서 다시 적용할 수 있습니다.

완료 결과의 `검토로 보내기`는 원본 이미지의 사본을 임시 후보 저장소에 보관하고 건물 에셋 관리 화면으로 연결합니다. 후보는 콘텐츠 DB에 등록되지 않습니다. 검수 화면은 이미지를 표시하며 점유 범위 대조는 별도로 필요합니다.
