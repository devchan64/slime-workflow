# HeartMuLa 음악 변경 기록

## 2026-11-22 · 이력 입력 적용

- 작업 결과에서 저장 입력을 표시하고 이력의 입력 적용 한 번으로 설정을 불러온다.

## 2026-11-22 · 헤르메스 GPU 양도

- 세션의 Qwen 3.8 해제와 작업 후 재적재를 생성 검토에서 확인할 수 있다. 실제 음악 생성·MR 및 보컬 분리 작업 `2026-11-22_13-01-08-c0e24914`과 Qwen 재적재가 완료됐다. 음원 품질은 청취 검수 대기다.

## 2026-11-20 · 모델 준비 중복 확인

- 작업 저장소에 접근할 수 없으면 빈 이력으로 간주하지 않고 모델 준비 중복 검사를 중단한다. 저장소가 아직 없는 최초 실행은 유지한다.

## 2026-11-19 · 원본 이력 검색

- 원본 이력 관측에서 작업 ID 일부를 검색하고 검색 조건에 페이지 확인값을 묶는다.

## 2026-11-19

- 운영 이력에서 전달된 작업 ID를 확인한 뒤 생성 이력에서 찾는 연결을 추가했다.
- 이력 페이지 변경 시 카드 이미지의 접근성 설명도 현재 작업에 맞춰 갱신한다.

## 2026-11-17

- 빈 ROCm 음악 환경을 준비하는 공용 명령과 HeartLib 메타데이터 차이 검사를 추가했다.

## 2026-11-15

- 생성기 페이지에서 이 변경 기록을 확인할 수 있도록 연결했다.
- 생성기별 페이지 구성을 분리하고 공용 화면과 기존 주소·이력 연결을 유지한다.
- HeartMuLa 실행을 ROCm 비양자화 경로로 전환했다. (Git `3513aef5`)
