# HeartMuLa 음악 변경 기록

## 2026-11-19 · 원본 이력 검색

- 원본 이력 관측에서 작업 ID 일부를 검색하고 검색 조건에 페이지 확인값을 묶는다.

## 2026-11-19

- 운영 이력에서 전달된 작업 ID를 확인한 뒤 생성 이력에서 찾는 연결을 추가했다.
- 이력 페이지 변경 시 카드 이미지의 접근성 설명도 현재 작업에 맞춰 갱신한다.

## 2026-11-17

- 빈 ROCm 음악 환경을 준비하는 공용 명령과 HeartLib 메타데이터 차이 검사를 추가했다.

## 2026-11-15

- 생성기 페이지에서 이 변경 기록을 확인할 수 있도록 연결했다.
- 생성기별 페이지 구성을 분리하고 공용 화면과 기존 주소·이력 연결을 유지한다.
- HeartMuLa 실행을 ROCm 비양자화 경로로 전환했다. (Git `3513aef5`)

## 2026-10-25

- 맵별 음악 예제를 개선하고 예제 목록의 10개 단위 페이지 이동을 추가했다. (Git `7be7055c`)
- 320kbps MP3 자동 생성과 다운로드를 추가했다. (Git `77a63201`)
- 가사곡의 MR 분리와 결과 비교를 추가했다. (Git `1b62e558`)
- HeartMuLa 생성기를 도입하고 이전 음악 생성기를 폐기했다. (Git `68e39e33`)
