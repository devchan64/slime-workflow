# 건물 생성기 변경 기록

## 2026-11-17 · 카드 갤러리 페이지네이션 정렬

- 건물 가이드와 생성 이력이 같은 공용 패널과 페이지네이션을 사용한다. 가이드 목록을 새로고침할 수 있다.

## 2026-11-16 · 한국어 디자인 번역 후 생성

- 한국어 디자인을 공용 번역 대기열에 등록하고 완료된 번역을 건물 기본 문구 및 공용 화풍과 결합해 이미지 대기열로 연결한다.
- 원문·번역·번역 작업 정보·최종 입력을 이력에 보존하며 번역 오류 시 이미지 생성을 중단한다.

## 2026-11-16 · 건물 가이드 카드 검색

- 건물 가이드를 구조 이미지 카드로 검색·선택한 뒤 첫 참조에 적용한다. 중복된 별도 미리보기는 표시하지 않는다.
- 규격·층수·지붕·입구·ID 검색과 공용 카드 갤러리의 페이지 크기 선택·번호 이동을 지원한다.
- 생성에 자동 적용되는 공용 화풍 버전·단어 수와 최종 모델 입력을 명확하게 표시한다.

## 2026-11-16 · FLUX 생성기 도입

- FLUX 3 Image Klein 공용 실행기와 공용 화풍 v1.5.0을 사용한다. Qwen 이력과 새 이력은 분리한다.
- 결과는 검수용 후보이며 비율·색상·화풍의 정확한 유지와 투명 배경은 보장하지 않는다.
