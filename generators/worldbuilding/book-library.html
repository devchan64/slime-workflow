도서 편집 · 파일 구조 정리

세계관 문서의 문단을 재배치하고 파일 간 이동·새 파일 분리를 수행합니다. 원본 파일 반영은 변경 미리보기를 확인한 뒤 실행합니다. 웹 도서는 정리한 원문을 읽는 판본으로 만들 수 있습니다.

1. 원본 선택

연결된 문서 루트 안에서 선택합니다. 상위·하위 폴더를 함께 골라도 문서는 한 번만 포함됩니다.

2. 목차와 문단 배치

문서 제목·경로·상위 절의 키워드로 주제별 목차 초안을 구성합니다. 자동 분류 결과를 확인하세요. 장 이름을 바꾸면 같은 이름의 장으로 이동하며, 화살표로 문단 순서를 조정할 수 있습니다. 표·목록·코드 블록은 통째로 이동합니다. 문단 본문을 보존하고 파일마다 제목을 남깁니다. YAML은 원래 파일에 유지합니다. 파일 이동은 아래 원본 반영 버튼으로 실행합니다.

기존 대상 파일도 위 원본 선택 범위에 포함해야 합니다. 참조 링크의 의미가 달라지는 이동은 차단합니다.

3. 원본 파일 변경 확인

아래 변경을 반영하면 원본 Markdown 파일과 카탈로그가 갱신됩니다. 새 파일의 제목과 문단 사이 구분 줄 외에 문단 본문은 재작성하지 않습니다.
