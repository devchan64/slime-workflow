- 도시 맵 DB 저장과 에셋 원본·소비자 잠금의 별도 동기화 필요를 명시한다.

- 대화·이력의 맵과 에셋 저장 완료 접수 ID를 검증한다.

- 영상·음원 결과의 서비스·작업·시도·파일 경로 검증을 대화와 공용화한다.

- 작가 적용 완료 응답의 접수·작업·제안 해시 일치 여부를 검증한다.

- 작가 결과 상세·적용 검토의 접수 서비스와 작업 ID를 재검증한다.

- 번역·작가 대화 결과의 접수 서비스와 작업 ID를 확인한다.

- 텍스트 기반 이미지·영상·오디오 결과의 접수 서비스와 작업 ID를 재확인한다.

- 불일치한 첨부 영상 접수의 재접수 방지 안내를 대화에 표시한다.

- 첨부 영상·오디오 결과 링크의 접수 서비스와 작업 ID를 재확인한다.

- 대화 결과에서 실제 영상·이미지·오디오·Kimodo 작업의 원 도구 이력으로 연결한다.

- 브라우저 저장소 접근이 차단돼도 운영 대화 세션 선택을 유지한다.

- 새 도구 탭에서 운영 대화로 돌아올 때 최근 세션을 복원한다.

- 대화 접수와 생성기 이력의 독립 GPU 기록을 원 서비스 확인값으로 구분한다.

- 독립 생성기 대기·예약의 확인된 원 서비스를 표시하고 미확인 선택을 제한한다.

- 독립 생성기 대기 작업의 우선 실행에서 원 서비스 작업 경로를 검증한다.

- 맵·캐릭터 캡처의 미연결과 GPU·파일·중복 접수 제한을 서비스 검색에 표시한다.

- 격리된 운영 대화에 생성기 GPU 예약 신원 조회를 추가한다.

- FLUX 표정 GPU 예약의 원본 작업 경로와 서비스별 정리 기능 발견을 연결한다.

- 운영 이력에서 일반 생성기 예약 정리를 별도 검토·확인하고 접수 결과를 조회한다.

- 일반 생성기 GPU 예약의 검토 확인, 조건부 정리와 중복 방지 접수 명령을 추가한다.

- 독립 생성기 GPU 예약의 원 서비스 확인에 지정 작업 경로 검증을 추가한다.

- 작가 GPU 예약 정리에서 실행기 PID의 명확한 부재와 전체 예약의 작업 ID 유일성을 확인한다.

## 2026-11-19 · 원본 작업 연결

- 생성기 예약의 조건이 확인될 때만 비파괴 재검토 기준값을 생성한다.

- GPU 대기·예약의 비정상적으로 큰 PID를 프로세스 조회 전에 거부한다.

- 생성기 예약 신원 조회는 부팅·시작 식별 확인 실패와 PID 미관측을 구분한다.

- 생성기 GPU 예약의 유일성·실행기·작업자 리더를 화면과 MCP에서 비파괴 확인한다.

- 새 생성 작업도 예약에 그룹 리더 식별 정보를 보존해 정리 확인 시 비파괴적으로 관측한다.

- GPU 예약에서 확인된 원 서비스 이력으로 이동하는 조회 안내를 제공한다.

- 다른 생성기의 실행기가 사라져도 하위 작업 종료가 확인되지 않은 GPU 예약은 자동 회수하지 않는다.

- GPU 예약 실행기 신원 확인이나 정리의 OS 오류는 예약을 보존하고 다른 작업의 안전한 대기로 처리한다.

- 손상된 GPU 예약 및 예약 작업 명령을 보존하고 다른 작업은 안전하게 대기하도록 한다.

- 손상된 GPU 우선순위 기록은 보존하고 실행 중인 대기 작업이 실패하지 않고 확인을 기다리도록 한다.

- 손상된 GPU 대기 티켓은 보존하고 다른 작업을 실패시키지 않고 대기하며 취소 요청은 처리한다.

- 잘못된 GPU 대기 티켓 PID는 프로세스 확인 전에 거부하고 실행 대기열을 보존한다.

- 대기 티켓의 식별 필드가 명시적으로 손상되면 기존 티켓으로 간주하지 않고 검증을 거부한다.

- GPU 대기 티켓에 부팅 식별값도 추가해 재부팅 전 PID 시작값과 현재 프로세스가 우연히 일치하는 경우를 구분한다.

- 새 GPU 대기 티켓에 가능한 경우 PID 시작 식별값을 기록하고, 값이 있는 티켓은 조회·우선 실행·실행 대상 선택에서 확인한다. 기존 티켓은 미확인으로 호환한다.

- GPU 대기 티켓의 PID 존재가 원래 실행기 신원을 보증하지 않는다는 제한을 우선 실행 검토와 상태 조회에 표시한다.

- GPU 대기 티켓의 상태 값이 미확인이거나 알 수 없으면 대기열 조회 불가로 처리한다.

- 살아 있는 GPU 대기 티켓의 작업 파일이 누락되면 빈 대기열로 표시하지 않는다.

- 격리 운영 대화에 원본 작업 ID 검색과 페이지 확인값 사용법을 안내한다.

- 관리 서비스 검색에서 확인된 차단·조건부 제한 설명도 검색한다.

- 서비스 발견에서 건물·빌보드 편집과 미연결 등록·크롭·폐기를 구분한다.

- 생성기 원본 이력에서 작업 ID 검색을 화면·MCP·격리 조회로 연결했다.

- 모델 준비 응답이 유실되거나 불일치하면 확인 화면을 닫고 같은 접수 ID의 결과 확인을 안내한다.

- 모델 준비 접수의 원 서비스 응답 당시 상태를 보존하고 현재 상태와 구분해 표시한다.

- 관리 서비스 목록에 Kimodo MIGraphX 상태 조회의 GPU 검사와 빌드 중복 방지 제한을 표시한다.

- 대기열에 서로 다른 서비스의 동일 ID가 함께 있으면 우선 실행 대상 확인 불가를 표시한다.

- 전용 GPU 대기·예약에서도 다른 서비스의 동일 작업 ID를 구분해 표시한다.

- 원본 이력의 상태에 작업 ID가 있으면 이력 ID와 일치하는지 확인한다.

- 같은 작업 ID의 중복 원본 색인은 합치지 않고 제외하며 확인 불가 수에 반영한다.

- 원본 이력의 기록 상태를 한국어로 표시하고 알 수 없는 상태는 확인 불가로 표시한다.

- 생성기 원본 이력에서 같은 목록 확인값으로 이전 페이지로 돌아갈 수 있다.

- 키프레임 후속 페이지를 확인값 없이 조회하면 목록 변경을 확인하지 못한 사실을 알린다.

- 확인된 대화 접수도 원본 작업 찾기에 연결하고 중복·불확실한 ID는 전달하지 않는다.

- 운영 이력에서 지원 생성기의 작업 ID를 전달하고 도구에서 명시적으로 찾아 확인하도록 연결했다.

- 우선 실행 대상에 불투명 티켓 확인값을 추가하고 조회 중 교체를 거절한다.

- 운영 이력에서 GPU 대기 행의 우선 실행 대상을 읽기 전용으로 재확인한다.

- GPU 대기 작업의 우선 실행 대상 확인을 MCP와 게이트웨이에 추가한다.

- 작가·영상·오디오 제안 조회를 서비스 검색의 연결 목록에 표시한다.

- GPU 예약 기록의 원 서비스도 대기 티켓과 독립적으로 확인한다.

- 공유 GPU 대기 티켓의 검증된 원 서비스만 이력과 연결하며 경로를 노출하지 않는다.

- 공유 GPU 서비스의 이력을 대기 기록 없음으로 오인하지 않고 Wan Fun의 실제 대기열 이름을 사용한다.

- 작가 변경의 대화 내 적용 확인·취소와 제안 재검증을 연결한다.

- 작가 제안의 탐색 근거와 중복 비교 문단을 제한적으로 조회한다.

- 작가 결과를 한국어 설명과 파일별 변경으로 정리해 보여 준다.

- 작가 경고가 잘리거나 형식이 잘못되면 전체 검토로 간주하지 않고 적용을 차단한다.

- 대화에서 작가 결과와 제한된 변경을 조회하고 일부만 표시된 경우를 안내한다.

- 완료된 답변의 작가 요청을 검증하는 게이트웨이·MCP 제안 조회를 추가한다. 대화에서 요청 검토와 GPU 확인 후 접수·상태 조회를 연결한다. 전체 변경 검토와 적용은 기존 화면을 사용한다.

- 운영 이력에서 세션 제안의 결정적 접수 ID와 영수증을 읽기 전용으로 대조한다. 영상 상태 복구는 호출하지 않으며 일치한 서비스·작업 ID의 GPU 대기와 예약을 별도로 관측한다.

- 운영 이력 화면에 세션 지시·Hermes 작업 상세·GPU 대기·예약 관측을 구분해 표시하고 세션 대화 링크를 제공한다. 생성기 원본 이력을 서비스별 스냅샷 페이지로 조회하며 대화·접수의 전체 관계 연결은 아직 제공하지 않는다.

- Hermes 대화를 첫 화면에 배치하고 기존 연결 기능을 보조 영역으로 모았다. Kimodo·FLUX·번역·오디오·텍스트 영상과 빌보드·이펙트·야외 맵·스프라이트 제안을 대화에서 검토·확인·상태 조회한다. 첨부 영상은 대화에서 파일·설정을 검토하고 기존 접수 상태를 확인한다. 작가 작업은 기존 연결 기능을 사용한다.

- 이펙트 신규 등록과 웨이포인트 교체를 화면·MCP의 원본 검토, 중복 방지 접수 및 상태 확인에 연결한다.
- 정렬 텍스처·키 충돌과 빌보드 대상 리비전을 공용 편집 잠금 안에서 재확인한다.

- FLUX 상태 응답에 작업 ID가 있으면 접수된 ID와 비교하며 기존 ID 없는 생성기 응답도 처리한다.

- 영상 상태 응답에 작업 ID가 포함된 경우 접수 기록과 일치하는지 검증하고 기존 ID 없는 응답과의 호환을 유지한다.

- 공용 기능 목록에서 영상·음향 제안 조회에 없는 서비스 입력을 제거하고 모든 명령의 입력 필드 일치를 검증한다.

- DWPose·Wan 동작·영상 제안의 서비스와 모드를 검토 설정으로 가져오고 이전 첨부를 비운다.

- DWPose와 Wan Animate-2·Fun Control·VACE의 설정·첨부 검증, GPU 위임과 서비스별 결과·중지를 연결한다.

- Hermes의 음악·효과음 위임 제안을 기존 서비스 입력 계약으로 검증해 화면·MCP에서 불러온다.

- HeartMuLa 음악과 Dasheng 효과음 생성·서비스별 이력·결과·중지를 공용 GPU 대기열에 위임한다.

- 별도 FLUX 표정 생성기의 얼굴 참조·프리셋·번역 단계와 위임 이력·중지를 연결한다.

- FLUX 이미지 8개 프로필의 참조 입력, 확인 후 생성, 서비스별 접수·상태·중지를 지원한다.

- 전체 변경과 근거를 확인한 작가 제안을 해시 검증 후 원본에 적용하고 접수 이력으로 결과를 복구한다.

- 작가 AI 문서 색인·작성·중복 검토를 위임하고 크기 제한된 제안 diff와 접수 이력을 조회한다.

- Hermes 번역 위임 제안을 기존 용어 검증 후 화면 검토 입력과 Codex MCP에서 읽도록 한다.

- 프롬프트 번역 위임·결과 검토·이력·중지를 기존 번역 서비스와 GPU 대기열에 연결한다.

- 격리 Hermes의 야외 셀 변경 제안을 현재 리비전과 대조해 장식을 보존하는 검토 초안으로 불러온다.

- 격리 Hermes와 MCP가 야외 맵 영역·배치를 원본 리비전에 고정해 나누어 조회한다.
