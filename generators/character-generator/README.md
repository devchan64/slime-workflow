# 캐릭터 이미지 생성기

관리도구 이미지 생성 분류의 캐릭터 이미지 생성기에서 Qwen 2.1로 후보를 만든다. 기본 입력은 캐릭터 외관 기준 v1.2.0의 단일 이미지용 축약 예시와 공용 화풍 v1.5.0의 영문 원문을 결합한다. 생성 시 동일 원문은 한 번만 포함한다. 캐릭터 조건을 편집하고 최종 99단어 제한을 확인한다. 원문 전체 외관 기준의 검증을 뜻하지 않는다.

일반 Qwen 2.1 서비스·CLI·대기열·생성 이력을 공유한다. 이력 삭제와 초기화는 일반 Qwen 작업에도 영향을 준다. 결과는 후보이며 정식 에셋 등록과 별개다.

## 신체 비율 참조

[신체 참조 목록](../../baseline/mannequin/body-reference-catalog.yaml)을 카드로 표시한다. 이름·용도·출처·ID를 검색해 카드를 선택하고 미리 본 뒤 첫 참조에 적용한다. 검색을 바꾸면 미리보기 선택은 초기화되며 이미 적용한 참조는 유지된다. 기존 첫 참조를 교체하며, 비율만 참고하도록 역할 문구를 추가한다. 참조 적용은 선택 사항이다. 원본 해시를 확인하고 생성 기록에 참조 ID·버전·출처·원본 해시와 실제 입력 사본의 해시를 보존한다. 이미지 자체가 단일 방향 출력을 보장하지 않으므로 결과를 검수한다.
