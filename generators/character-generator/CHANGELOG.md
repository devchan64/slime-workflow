# 변경 기록

## 2026-11-16 · Qwen 이미지 생성기 아카이브

- 신규 생성·재개·우선 실행을 중단하고 기존 이력·입력·결과·로그 조회를 유지한다. 진행 중 작업은 자동 취소하지 않는다.

## 2026-11-16 · VAE 타일 인코딩·디코딩 중단

- 공용 Qwen 2.1 VAE의 타일 인코딩과 디코딩을 끈다. 기존 생성 이력 재개에도 새 설정이 적용되므로 과거 출력과 동일하지 않을 수 있으며, 메모리 부족 시 자동 타일 대체 없이 실패한다.

## 2026-11-15 · 신체 비율 기준 여백 정리

- 피부·기본복 신체 참조를 768×1152 여백 정리본 v14로 갱신하고 과거 이력은 저장된 참조로 검증한다.

## 2026-11-15 · 신체 참조 갤러리 높이 개선

- 검색 결과 수에 맞춰 카드 갤러리 높이가 늘어나도록 조정해 빈 영역과 불필요한 내부 스크롤을 줄였다.

## 2026-11-15 · 마네킨 기준 원본 이전

- 신체 비율 참조 원본과 목록을 `baseline/mannequin/`으로 이전하고 이전 경로를 기록한 생성 이력의 재개 호환성을 유지했다.

## 2026-11-15 · 신체 참조 카드 검색

- 신체 비율 기준을 검색 가능한 카드 갤러리로 표시하고 선택·미리보기·적용을 연결했다. 검색 결과 변경 시 선택을 초기화하며 이미 적용한 참조는 유지한다.
- 검색 결과가 바뀔 때 공용 카드의 썸네일이 이전 이미지로 남는 문제를 수정했다.

## 2026-11-15 · 신체 비율 참조 연결

- 현재 중성형 신체 기준 두 장을 목록·미리보기와 첫 참조 적용에 연결했다. 이미지 비율만 사용하도록 역할을 표시하고 원본 출처와 해시를 실행 기록에 남긴다.

## 2026-11-15 · 공용 화풍 기본 적용

- 새 Qwen 이미지 요청에 공용 화풍 v1.5.0 원문을 기본 적용하고 이전 짧은 화풍 옵션을 폐기했다. 기존 기록은 저장된 입력으로 재개한다.

## 2026-11-15

- Qwen 2.1 캐릭터 이미지 생성 화면을 추가했다. 공용 화풍 v1.5.0 원문과 축약된 캐릭터 외관 예시를 기본 입력으로 제공한다.
- 일반 Qwen 생성기와 대기열·이력을 공유한다. 캐릭터 전용 이력은 제공하지 않는다.
