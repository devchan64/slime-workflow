# 변경 기록

## 2026-11-15 · 신체 비율 참조 연결

- 현재 중성형 신체 기준 두 장을 목록·미리보기와 첫 참조 적용에 연결했다. 이미지 비율만 사용하도록 역할을 표시하고 원본 출처와 해시를 실행 기록에 남긴다.

## 2026-11-15 · 공용 화풍 기본 적용

- 새 Qwen 이미지 요청에 공용 화풍 v1.5.0 원문을 기본 적용하고 이전 짧은 화풍 옵션을 폐기했다. 기존 기록은 저장된 입력으로 재개한다.

## 2026-11-15

- Qwen 2.1 캐릭터 이미지 생성 화면을 추가했다. 공용 화풍 v1.5.0 원문과 축약된 캐릭터 외관 예시를 기본 입력으로 제공한다.
- 일반 Qwen 생성기와 대기열·이력을 공유한다. 캐릭터 전용 이력은 제공하지 않는다.
