# 작가 AI 변경 기록

- 작성 추론 모델을 헤르메스와 공유하는 Qwen 3.8 27B로 변경하고 Qwen 3.5 다운로드를 폐기했다. GPU 예약 기준은 32768 MiB로 조정했다. 실제 GPU 추론 검증은 대기 중이다.

## 2026-11-20 · 검색 결과 경로 조회

- 검색 기록에서 문서 루트와 제외 경로를 확인한 상대 경로와 누락 여부만 제공한다. 본문·제목·검색 질의는 응답에 포함하지 않는다. 조회에는 같은 설정 값을 사용하며 조회 중 설정 변경이 감지되면 오류를 반환한다. 이전 검색 당시의 문서 루트와 파일 내용이 현재와 같은지는 확인하지 못한다.
- 실패·중단된 작업도 저장된 검색 기록이 있으면 조회할 수 있으며, 검색 결과는 작업 성공을 뜻하지 않는다.

## 2026-11-19 · 원본 이력 검색

- 원본 이력 관측에서 작업 ID 일부를 검색하고 검색 조건에 페이지 확인값을 묶는다.

- 실제 문서와 색인의 일치 여부를 확인하는 상태 명령을 추가한다.

## 2026-11-15

- 이력 삭제 확인 위에 선택한 작업 ID와 상태를 표시하고 확인 안내에 대상 ID를 포함한다.
- 이력 선택 목록의 중복을 제거하고 표에서 행을 선택해 결과를 확인한다.
- 전체 실행 이력 검색과 선택 기록의 확인 후 휴지통 이동을 제공한다.
- 실행 이력 행을 선택하면 상세를 바로 불러오고, 선택 메뉴를 유지하면서 이력 표의 상태를 자동 갱신한다.
- 근거 검토에서 지적된 초안은 원문을 기준으로 한 번 수정하고 다시 검토한다.
- 작성 제안의 미결정 사항·요청 식별 기준을 근거와 다시 검토하고, 문제가 발견되면 적용을 보류한다.
- 문서 학습·작성·중복 검토와 환경 준비를 공용 GPU 대기열에 연결하고 대기 순서를 표시한다.
- 첫 학습과 작성·결과 검토 순서, 문서·색인·기록 경로 및 실행 중 상태를 명확히 표시한다.
- 생성기 페이지에서 이 변경 기록을 확인할 수 있도록 연결했다.
- 생성기별 페이지 구성을 분리하고 공용 화면과 기존 주소·이력 연결을 유지한다.
