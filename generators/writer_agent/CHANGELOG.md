## 2026-11-15

- 이력 삭제 확인 위에 선택한 작업 ID와 상태를 표시하고 확인 안내에 대상 ID를 포함한다.
- 이력 선택 목록의 중복을 제거하고 표에서 행을 선택해 결과를 확인한다.
- 전체 실행 이력 검색과 선택 기록의 확인 후 휴지통 이동을 제공한다.
- 실행 이력 행을 선택하면 상세를 바로 불러오고, 선택 메뉴를 유지하면서 이력 표의 상태를 자동 갱신한다.
- 근거 검토에서 지적된 초안은 원문을 기준으로 한 번 수정하고 다시 검토한다.
- 작성 제안의 미결정 사항·요청 식별 기준을 근거와 다시 검토하고, 문제가 발견되면 적용을 보류한다.
- 문서 학습·작성·중복 검토와 환경 준비를 공용 GPU 대기열에 연결하고 대기 순서를 표시한다.
- 첫 학습과 작성·결과 검토 순서, 문서·색인·기록 경로 및 실행 중 상태를 명확히 표시한다.
- 생성기 페이지에서 이 변경 기록을 확인할 수 있도록 연결했다.
- 생성기별 페이지 구성을 분리하고 공용 화면과 기존 주소·이력 연결을 유지한다.
- 작가 AI 모델 파일 준비 상태 확인을 추가했다. (Git `7ddd655c`)
