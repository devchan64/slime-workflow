# Wan Animate-2 변경 기록

## 2026-11-15

- 실제 VAE 비유한 출력 재현 후 expandable segments를 비활성화하고 이전 할당 환경변수 충돌을 제거한다. VAE 수학 SDPA 조합의 짧은 GPU 재검증은 통과했으며 내부 오류 원인과 긴 영상 안정성은 미확정이다.

- ROCm에서 관측된 VAE SDPA 출력 손상을 피하도록 VAE 인코딩·디코딩에만 수학 SDPA를 적용한다.

- ROCm 실행 안내를 실제 GPU 상주 경로와 일치시키고, VAE 인코딩·스케줄러·출력의 비유한 값을 실패로 처리한다.
- 생성기 페이지를 `page/`에서 관리하고 이 변경 기록을 페이지에 표시한다. 기존 페이지 주소와 import 경로는 유지한다.
- ROCm 비양자화 실행 경로로 전환했다. (Git `3513aef5`)
