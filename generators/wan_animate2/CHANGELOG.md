# Wan Animate-2 변경 기록

## 2026-11-23 · LightX2V 준비 작업

- 가속 LoRA의 별도 다운로드·SHA-256 검증과 차분 적용, 6스텝 LCM 설정 및 선택 UI를 추가했다. 생성 요청 검토와 GPU 대기열 접수를 다시 연결했다. 5·17프레임 GPU 생성을 완료했고 17프레임의 시작·중간·마지막 프레임을 확인했다.
- 현재 생성 작업과 공용 진행 상태를 표시하고 접수된 작업의 결과 이력을 연다.
- 시스템 RAM 일괄 적재를 줄이도록 구성요소를 GPU에 직접 적재하고 LoRA를 GPU에서 합친다. 5프레임 전체 생성과 일부 차분의 CPU 비교를 확인했으며 긴 입력 검증은 별도로 진행한다.
- LoRA 미사용 Base 경로도 GPU 직접 적재로 5프레임·2스텝 스모크 테스트를 완료했다.

## 2026-11-22 · 이력 입력 적용

- 작업 결과에서 저장 입력을 표시하고 이력의 입력 적용 한 번으로 설정을 불러온다.

- 시드 입력·랜덤 선택 범위를 생성기 허용 범위인 0~2,147,483,647에 맞췄다.

## 2026-11-20 · 16fps 동작 전사

- 동작 입력 샘플링·모델 fps·결과 저장을 16fps로 통일한다. 16fps 입력은 프레임을 반복하지 않는다. 공식 24fps 대비 품질은 검수가 필요하다.

## 2026-11-19 · 원본 이력 검색

- 원본 이력 관측에서 작업 ID 일부를 검색하고 검색 조건에 페이지 확인값을 묶는다.

## 2026-11-19

- 운영 이력에서 전달된 작업 ID를 확인한 뒤 생성 이력에서 찾는 연결을 추가했다.
- 이력 페이지 변경 시 카드 이미지의 접근성 설명도 현재 작업에 맞춰 갱신한다.

## 2026-11-16

- 긴 ROCm 참조 어텐션의 연속 배치와 확인된 헤드 독립 Flex 마스크의 4헤드 분할을 적용한다. 실제 GPU에서 65프레임·20스텝 생성과 기존 유한값 검사를 완료했다. 장기 안정성과 영상 품질은 추가 검수가 필요하다.

## 2026-11-15

- 실제 VAE 비유한 출력 재현 후 expandable segments를 비활성화하고 이전 할당 환경변수 충돌을 제거한다. VAE 수학 SDPA 조합의 짧은 GPU 재검증은 통과했으며 내부 오류 원인과 긴 영상 안정성은 미확정이다.

- ROCm에서 관측된 VAE SDPA 출력 손상을 피하도록 VAE 인코딩·디코딩에만 수학 SDPA를 적용한다.

- ROCm 실행 안내를 실제 GPU 상주 경로와 일치시키고, VAE 인코딩·스케줄러·출력의 비유한 값을 실패로 처리한다.
- 생성기 페이지를 `page/`에서 관리하고 이 변경 기록을 페이지에 표시한다. 기존 페이지 주소와 import 경로는 유지한다.
- ROCm 비양자화 실행 경로로 전환했다. (Git `3513aef5`)
