# 심리스 타일 생성기 변경 기록

## 2026-11-22 · 이력 입력 적용

- 작업 결과에서 저장 입력을 표시하고 이력의 입력 적용 한 번으로 설정을 불러온다.

## 2026-11-19 · 원본 이력 검색

- 원본 이력 관측에서 작업 ID 일부를 검색하고 검색 조건에 페이지 확인값을 묶는다.

## 2026-11-19

- 운영 이력에서 전달된 작업 ID를 확인한 뒤 생성 이력에서 찾는 연결을 추가했다.
- 이력 페이지 변경 시 카드 이미지의 접근성 설명도 현재 작업에 맞춰 갱신한다.

- 비양자화 FLUX 구성요소를 ROCm GPU에 순차 적재하고 CPU 자동 오프로드 없이 상주 실행한다. 기존 오프로드 이력과 메모리 예약을 분리한다.

- GPU 실행 중 호스트 메모리 압박 보호를 적용하고 보호 중지 시 실패 사유를 기록한다.

## 2026-11-17 · 한국어 프롬프트 번역 연결

- 한국어 설명을 공용 번역 대기열에서 영어로 변환한 후 기존 준비 문구와 결합해 이미지 생성을 자동 등록한다. 번역 실패·취소 시 생성하지 않는다.
- 한국어 원문·번역문·검토 항목과 최종 입력을 이력에 보존하고 기존 영어 이력의 입력 복원·재개를 지원한다.

## 2026-11-16 · 전역 주기 어텐션 적용

- 새 작업에 전역 최단 주기 어텐션과 16개 위치의 순환 이동, 순환 패딩 VAE를 적용한다.
- 검증된 512×512 무참조 작업을 지원하며 기존 이력은 저장된 방식으로 재개한다. 반복 경계 품질은 별도 검수가 필요하다.

## 2026-11-16 · 순환 VAE 단일 방식

- 새 작업은 순환 패딩 VAE만 사용하고 결과와 3×3 반복 이미지를 저장한다. 경계 보간 선택 및 비교 이미지 생성은 제거한다.
- 기존 작업의 저장 방식은 조회·재개할 때 유지하며 입력을 복원해 새로 생성할 때는 새 방식이 적용된다.

## 2026-11-16 · 반복 검수 이미지 표시 개선

- 생성 원본·경계 보간·반복 미리보기가 현재 접속 주소에서 표시되도록 경로를 수정한다.

## 2026-11-16 · FLUX 생성기 도입

- FLUX 3 이미지의 반대편 가장자리 색을 보간하고 3×3 반복 미리보기를 생성한다. Qwen 순환 VAE나 다단계 보정과는 다른 방식이다.
- 반대편 경계 픽셀을 맞추지만 무늬의 연결·흐림·반복 품질은 별도 시각 검수가 필요하다.

## 2026-11-16 · 순환 VAE 기본 적용

- 새 작업은 순환 패딩 VAE를 기본 사용하고 동일 잠재값의 일반 디코딩과 기존 경계 보간 반복을 함께 기록한다. 기존 보간 방식 선택도 지원한다.
- 이전 방식 정보가 없는 이력은 기존 경계 보간으로 복원·재개한다. VAE 타일 인코딩·디코딩은 사용하지 않는다.
