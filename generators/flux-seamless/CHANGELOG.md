# 심리스 타일 생성기 변경 기록

## 2026-11-16 · 반복 검수 이미지 표시 개선

- 생성 원본·경계 보간·반복 미리보기가 현재 접속 주소에서 표시되도록 경로를 수정한다.

## 2026-11-16 · FLUX 생성기 도입

- FLUX 3 이미지의 반대편 가장자리 색을 보간하고 3×3 반복 미리보기를 생성한다. Qwen 순환 VAE나 다단계 보정과는 다른 방식이다.
- 반대편 경계 픽셀을 맞추지만 무늬의 연결·흐림·반복 품질은 별도 시각 검수가 필요하다.

## 2026-11-16 · 순환 VAE 기본 적용

- 새 작업은 순환 패딩 VAE를 기본 사용하고 동일 잠재값의 일반 디코딩과 기존 경계 보간 반복을 함께 기록한다. 기존 보간 방식 선택도 지원한다.
- 이전 방식 정보가 없는 이력은 기존 경계 보간으로 복원·재개한다. VAE 타일 인코딩·디코딩은 사용하지 않는다.
