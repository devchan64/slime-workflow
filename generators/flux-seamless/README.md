# FLUX 심리스 타일 생성기

FLUX 3 이미지 생성에 전역 최단 주기 어텐션과 순환 이동, 순환 패딩 VAE를 적용하고 3×3 반복 미리보기를 생성한다. 반복 경계와 무늬의 연결은 사용자가 검수한다.

공용 화풍 v1.5.0 원문을 기본으로 조합한다. 새 작업은 검증된 512×512·16단계·참조 이미지 없음만 지원한다. FLUX 출력은 RGB이며 투명 배경을 보장하지 않는다. 프롬프트·시드·모델 리비전과 생성기별 별도 이력을 보관하고 입력 복원을 지원한다.

CLI 예시: `.venv/bin/python tools/manager.py command flux-seamless generate --prompt 'Top-down grass texture' --detach`.

새 작업은 16개 위치 순환 이동과 전역 최단 주기 어텐션, 순환 패딩 VAE를 함께 사용한다. VAE 타일링은 사용하지 않는다. 기존 이력의 조회·재개는 저장 당시 방식을 유지한다. 이전 이력의 입력을 새 작업에 쓰려면 512×512와 참조 없음으로 맞춰야 한다.
