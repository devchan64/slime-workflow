# Wan 2.1 I2V 변경 기록

## 2026-11-23

- 선택 이력의 `입력 적용`으로 저장 설정과 참조 이미지 사본을 검증해 생성 폼에 불러온다. 적용은 생성 작업을 접수하지 않는다.
- 필수 입력과 모델 상태 안내, 동작 LoRA 설정 관계, 예상 재생 길이와 선택 이력의 저장 입력·우선 실행 검토를 표시한다.
- 선택 이력의 같은 버튼으로 결과를 펼치고 접는다. 결과 안의 중복 작업 중지와 닫기 버튼을 제거한다.
- 14B 480p 본체, 이미지 인코더 및 LoRA의 고정 파일 준비와 별도 공용 대기열 경로를 추가했다.
- 720p에서 학습된 Fight LoRA의 480p 및 무기 동작과 GPU 실행은 검증 전이다.
- 480p 본체와 가속 LoRA 1,262개, Fight LoRA 480개 대상의 이름·텐서 크기를 파일 헤더에서 확인했다. GPU 적용과 결과는 별도 검증 대상이다.
- 창 공격 예시가 있는 2.2 Attack Sprite high/low를 2.1의 실험 선택지로 추가했다. 두 파일은 각각 400개 패치 등록만 확인했다.
