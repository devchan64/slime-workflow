# FLUX 표정 생성기 변경 기록

## 2026-11-17 · 한국어 프롬프트 번역 연결

- 한국어 설명을 공용 번역 대기열에서 영어로 변환한 후 기존 준비 문구와 결합해 이미지 생성을 자동 등록한다. 번역 실패·취소 시 생성하지 않는다.
- 한국어 원문·번역문·검토 항목과 최종 입력을 이력에 보존하고 기존 영어 이력의 입력 복원·재개를 지원한다.

## 2026-11-16 · 이력 입력 복원

- 저장된 표정·참조 이미지·출력 크기·시드·태그를 입력란에 불러온다. 사본 해시와 현재 프리셋의 프롬프트가 일치하는지 확인하며 생성은 자동 실행하지 않는다.

## 2026-11-16 · FLUX 표정 생성기

- FLUX 3 Image Klein에서 단일 얼굴 참조와 표정 프리셋으로 생성한다.
- Qwen 표정 이력은 기존 아카이브에서 조회하며 새 FLUX 이력은 별도로 저장한다.
- 색상 및 얼굴 특징이 정확히 유지되는지는 결과를 원본과 비교해야 한다.
