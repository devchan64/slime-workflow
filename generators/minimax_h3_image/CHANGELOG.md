# MiniMax H3 이미지 생성 변경 기록

## 2026-11-27 · 독립 이력 경계 정리

- 입력폼의 내부 페이지 전환 상태를 제거하고 기존 작업 주소의 이력 오류 안내를 유지한다. 이력 이동 전 초안 보존과 대화 내장 이력은 유지한다.

## 2026-11-27 · 이력 샘플러 요약

- 이력 목록에 저장된 샘플러를 표시하고, 요약을 확인할 수 없을 때 임의의 값을 표시하지 않는다.

## 2026-11-27 · 이력 이동 전 입력 보존

- 이력 이동 시 프롬프트와 참조를 함께 보존하고, 저장 중 입력이 변경되거나 보존에 실패하면 이동하지 않는다. 작업 결과로 이동할 때도 초안을 보존한다.

## 2026-11-27 · 검수 이동 표시

- 생성 이력에서 작업을 선택하면 결과를 펼치지 않아도 검수로 보내기 버튼을 표시한다.

## 2026-11-27 · 건물 검토 후보

- 완료된 이미지 결과를 임시 건물 후보로 보관하고 건물 검수 화면에서 확인하는 경로를 추가했다.

## 2026-11-27 · 이력 입력 보기

- 이력에서 저장 입력과 참조 썸네일을 먼저 확인하고 생성폼에 적용하도록 변경했다.

## 2026-11-26 · 공통 이미지 이력 분리

- 일반·건물 생성폼이 같은 독립 이미지 생성이력 페이지를 사용하고 저장 입력을 각 폼에 복원한다.

## 2026-11-26 · 입력과 이력 분리

- 독립 생성기의 입력폼과 생성이력을 페이지로 구분하고 작업 결과와 입력 복원을 연결했다.

## 2026-11-26 · LCM 기본값

- 새 이미지 요청의 기본 샘플러를 LCM으로 변경했다. 독립 화면과 CLI에서 Euler를 선택할 수 있으며, 기존 샘플러 미기록 이력은 Euler로 유지한다.
- 대화 접수폼에는 새 기본값 LCM이 적용되며, LCM 품질과 GPU 실행 경로는 추가 검증이 필요하다.

## 2026-11-26 · 실험용 LCM 샘플러

- 독립 화면과 통합 CLI에 Euler 기본값과 LCM 실험 선택을 제공하고, 이력 입력과 결과에 선택을 보존한다. 대화 접수폼은 Euler를 유지한다.
- LCM 품질과 ComfyUI 난수열 동등성은 미검증이다.

## 2026-11-26 · 작업별 임시 경로

- 추론과 컴파일의 임시 파일을 작업 폴더에 두어 시스템 임시 디렉터리 할당량과 분리한다. 실제 생성 성공 여부는 별도 확인한다.

## 2026-11-26 · CLI 참조 이미지 입력

- 통합 CLI에서 `--reference`를 최대 두 번 지정하여 PNG 참조를 순서대로 전달한다.

## 2026-11-24 · 512×512 직접 생성

- 512×512 직접 생성 요청과 대화 제안의 크기 전달을 추가했다. 실제 GPU 생성과 품질은 미검증이다.

## 2026-11-24 · 헤르메스 자동 보고

- 대화 제안의 접수 기록과 결과 분석·보고 상태를 연결했습니다. 표본 분석과 생성 완료는 별도로 확인합니다.

## 2026-11-24

- 공용 화풍 적용 1024×1024 실험을 완료하고 생성 결과·GPU 피크와 종료 후 장치 메모리 사용량을 확인했다. SDPA 정확도와 장기 안정성은 미검증이다.
- 공용 화풍 v1.5.0 조합, 최종 프롬프트 검토와 기록 무결성 확인을 추가했다.
- 모델은 작업 중에만 GPU에 적재하고 작업 종료 시 프로세스를 종료하는 방식으로 수정했다. 실제 메모리 반환과 생성 품질은 미검증이다.
- INT8 텍스트 이미지 생성과 공용 GPU 대기열 연결을 준비했다. 첫 시험은 메모리 계획 단계에서 실패했다. 이후 비상주 요청을 스트리밍으로 오해해 생성 접수를 차단했으며, 위 항목에서 작업 중 적재 후 종료하는 방식으로 바로잡았다.

## 2026-11-24 · 보고 재분석
