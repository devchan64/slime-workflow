# Kimodo 모션 생성기 변경 기록

## 2026-11-27 · 생성 입력과 이력 분리

- 손상된 참조 PNG는 저장 입력 조회 시 오류를 표시한다.
- 저장된 신체 비율 참조 이미지를 이력 입력 보기에서 썸네일로 표시한다.

- 현재 입력폼은 재이동 링크 대신 상태로 표시해 작성 중인 입력을 보호한다.

- 독립 이력 화면에서 저장 입력과 모션 결과를 확인하고 입력폼으로 복원한다. 입력폼에서 이력을 새 탭으로 열어 작성 중인 입력을 유지한다.
- 복원 주소의 작업 ID를 검증하고 한 번 사용한 복원 매개변수를 주소에서 제거한다.

## 2026-11-23 · 사용설명 통합

- 생성 화면의 사용 안내와 도메인 README를 사용설명으로 통합하고 화면에서 원본을 직접 읽도록 변경했다.

## 2026-11-22 · 이력 입력 적용

- 작업 결과에서 저장 입력을 표시하고 이력의 입력 적용 한 번으로 설정을 불러온다.

## 2026-11-22 · 공용 페이지 식별

- 변경 기록·안내·모델·이력 접기 조작을 공용 글꼴과 경계로 표시한다.

- 생성 입력·이력·선택 결과로 이동하는 공용 탐색을 추가하고 결과 영역을 구분했다.

- Kimodo 기준의 본문 폭·제목·일반 입력 여백과 글꼴을 공용 생성기 서식으로 통일했다.

- 페이지 제목과 변경 기록 연결을 공용 생성기 페이지 등록부로 관리한다. 기존 생성 입력과 이력 기능은 유지한다.

- 모션 생성 화면에 예제 적용부터 대기와 결과 검수까지의 사용 안내를 추가했다.
- 보존된 작업 기록을 검토하고 생성·대기·결과 검수 사용 안내를 정리했다.
- 바닥 휴식 예제를 시드 917859350과 64·64·64프레임 설정으로 교체했다.
- 공용 GPU 대기열에서 Kimodo 동시 실행을 최대 두 건으로 제한한다. 2026-11-22 시스템 메모리 부족에 대한 예방 조치이며 다른 작업과 시스템 전체의 메모리 안전은 별도로 확인한다.
- 바닥 휴식 예제의 순차 구간을 64·32·64프레임으로 변경했다.

- 일반 생성과 순차 생성을 구분하고 바닥 휴식 예제를 32·16·32프레임으로 변경했다.

- 생성 화면에 순차 동작의 구간별 프레임 입력을 복원했다.
