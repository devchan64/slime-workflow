# 마네킨 베이스라인

캐릭터 제작에 사용하는 현재 마네킨 기준 원본과 출처 기록을 이 경로에서 관리한다. 전체 유형과 연구 후보는 [마네킨 색인](../../prompts/references/mannequin/README.md)을 따른다.

- [중성형 피부·기본복 전신 4방향](neutral-body-skin-clothes-four-directions.png) · [출처 및 버전 기록](neutral-body-skin-clothes-four-directions.yaml)
- [중성형 관절 마네킨 4방향](neutral-body-four-directions.png) · [출처 기록](neutral-body-four-directions.yaml)
- [중성형 기본 얼굴 4방향](neutral-head-basic-four-directions.png) · [출처 및 버전 기록](neutral-head-basic-four-directions.yaml)
- [캐릭터 생성기 신체 비율 참조 목록](body-reference-catalog.yaml)

관절 마네킨은 보존된 기준 자료이며 생성기의 신체 비율 참조 목록에는 포함하지 않는다. 실험과 이전 버전은 [마네킨 연구 기록](../../prompts/references/mannequin/research/README.md)에 보관한다.

## 기준과 사용

- 이미지는 2×2 구성으로 좌상 정면, 우상 앞쪽 쿼터, 좌하 측면, 우하 후면이다. 연속 회전 프레임이 아니므로 방향별 좌우와 시점을 확인한다.
- 성인 평균 5등신을 출발 기준으로 하는 중성형이며 좁은 어깨, 가는 허리와 넓힌 골반을 적용했다. 정확한 등신 수치와 이미지 간 비율 일치는 실측하지 않았다.
- 관절 마네킨은 머리 대비 키, 몸통 폭, 팔다리 길이와 관절 위치의 기준이다. 관절형 재질과 기계식 관절은 캐릭터 외형에 복제하지 않는다. 피부·기본복 전신은 비율과 자세를 유지하는 참고 자료다.
- 기본 얼굴은 사용자가 채택한 연구 v10의 복사본으로 눈·코·입의 크기와 간격, 턱선의 기준이다. 얼굴과 머리카락을 별도 단계에서 추가할 때 머리 외곽과 전신 비율을 유지한다.
- 결과를 같은 전신 높이로 정렬해 턱·어깨·가랑이·무릎 위치와 몸통 폭을 비교한다. 등신 계산에서 머리카락 부피는 제외한다.
- 생성기에서 신체 비율 참조를 선택하면 첫 참조 이미지가 교체되고 용도 문구가 추가된다. 선택하지 않으면 이미지가 자동 전달되지 않는다. 화풍과 외관은 각각 [공통 화풍](../../prompts/common/art-style.md)과 [캐릭터 외관 기준](../../prompts/common/character-appearance.md)을 함께 따른다.

## 저장과 갱신

PNG와 같은 이름의 YAML에 출처·참조 이미지·채택 상태·이미지 해시를 함께 관리하고, 생성 자료에는 실제 프롬프트·단어 수·프롬프트 해시를 보존한다. `neutral-body-four-directions.png`는 사용자가 채택한 생성 결과다. 이전의 첨부 원본과 여백 정리본 출처 및 해시는 YAML에 보존한다. 전신 두 장은 768×1152, 얼굴은 1056×1056으로 배치했다. 기존 피부·기본복 기준과 새 관절 기준의 비율 일치는 실측하지 않았다.

새 생성·수정 결과는 이 폴더에 직접 저장하지 않고 연구 버전에 보존한다. 사용자가 반영을 지시한 경우에만 현재 기준을 갱신하고 색인과 참조 경로를 함께 수정한다. 상세 절차는 [마네킨 기반 기본형 관리](../../workflows/character-baseline-mannequin.md)를 따른다.
