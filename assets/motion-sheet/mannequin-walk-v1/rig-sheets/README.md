# 걷기 리그 8프레임 시트 v2

좌하·우하·좌상·우상 4방향의 셰이딩 보강 리그 참조다. 각 PNG는 2048×1024, 512×512 셀의 4열×2행이며 왼쪽 위부터 1~8프레임이다. 150ms 간격의 1.2초 주기이며 중복 마지막 프레임은 제외했다. 중립 리그는 5등신이다.

기존 GPU 렌더 실행의 파일을 픽셀 변경 없이 보관했다. 원천 모션은 `../motion-source/source-motion.npz`, 마네킹 변환 모션은 `../mannequin-motion.npz`다. 출처·모션·리그·셰이딩·해시는 manifest.yaml에 기록한다. 재생성에 필요한 Blender 자료도 이 폴더에서 함께 관리한다.

- 기준 마네킹 Blender: `../mannequin.blend`
- 사람형 참조 Blender: `../../humanlike-walk/v1/humanlike-walk.blend`
- OpenPose 비교 시트: `../pose-sheets-v1/`

이미지젠에는 생성할 방향의 시트를 1–4번·5–8번의 2×2 리그 참조로 나누어 전달하고, 각 호출에 승인된 2×2 캐릭터 베이스라인 전체를 함께 사용한다. 호출당 최대 4프레임을 생성한 뒤 최종 8프레임 시트로 통합한다. 최종 캐릭터 애니메이션이나 OpenPose 시트가 아니다.
