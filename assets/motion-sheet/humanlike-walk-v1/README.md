# humanlike-walk v1

`mannequin-walk/v1`의 본 구조와 걷기 키프레임을 유지하면서 사람형 외형을 추가한 재생성용 리그다.

- `humanlike-walk.blend`: 사람형 Blender 리그
- `retargeted-motion.npz`: 마네킹 기준과 동일한 retarget 모션
- `artifact.json`: 출처와 파일 해시

마네킹 기준 리그와 4방향 시트는 `assets/rigs/mannequin-walk/v1`에서 관리한다. 이 리그는 기본 리그를 대체하지 않으며, AnyPose 및 사람형 참조 생성 실험에서 명시적으로 선택한다.
