# HY-Motion 걷기 v1 · 원근투영

실행 `2026-10-09_21-13-20-1a356bbd`의 미리보기 7~13번(원본 31·36·41·46·51·56·61)을 채택한 4방향 제작 에셋이다. 7프레임·6FPS이며 별도 루프 보간은 없다.

원근투영 FOV 30°·고도 17°를 사용한다. 전방 좌측은 기존 원근투영 이미지, 다른 세 방향은 동일한 저장된 제약 적용 리그의 렌더다. ANNY와 투영 OpenPose는 같은 카메라를 사용하며 방향별 카메라·출처·파일 해시는 manifest.yaml에 기록한다.

정사영으로 잘못 등록한 hy-motion-walking-v14를 대체한다. source-motion.npz·source-rig.blend는 전체 원본 보존용이며 사용할 구간은 manifest.yaml의 source_frames를 따른다. 게임 최종 스프라이트가 아닌 워크플로우 제작 자산이다.
