# 도윤 제작 참조 상태

사용자가 승인한 정면 전신 v3는 `body-front-v3/`, 해당 전신에서 파생한 정면 얼굴 v4는 `face-front-v4/`에 등록했다. 얼굴은 머리와 목만 포함하며 어깨·가슴·의상은 제외한다.

전신은 ANNY v4 체형을 참조한 제작 기준이며 기하 제약이나 정확한 등신 비율의 측정 검증은 적용되지 않았다. 게임 런타임 채택과는 구분한다.

4방향은 새 전신에서 파생하여 별도 검수 후 등록한다. 기존 폐기 자산의 경로·해시는 `manifest.yaml`의 `retired_assets`에서 유지한다.
