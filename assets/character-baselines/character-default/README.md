# 새 기본 캐릭터 참조

짧은 갈색 머리와 갈색 눈을 가진 중성적인 기본형이다. 현재 얼굴은 남성 헤드 마네킨 v3의 비율을 적용한 v2를 사용한다.

## 현재 얼굴 기준

- [얼굴 정면 v2](baseline-v2/face-front-v2.png)
- [실제 생성 프롬프트·참조 기록](baseline-v2/face-front-v2.yaml)

## 마네킨 단독 참조 전신 후보

- [피부·기본복 정면 v5](baseline-v5/body-skin-clothes-front-v5.png)
- [생성 프롬프트·참조 기록](baseline-v5/body-skin-clothes-front-v5.yaml)

전신 마네킨 한 장만 참조했다. 얼굴 이목구비와 머리카락은 추가하지 않았다.

## 이전 전신 재조정 후보

- [전신 정면 v4](baseline-v4/body-front-v4.png)
- [생성 프롬프트·참조 기록](baseline-v4/body-front-v4.yaml)

v3의 커진 머리를 줄이고 귀와 목덜미 머리카락을 조금 길게 표현한 후보. 마네킨과의 정확한 비율 일치는 검수 대상이다.

## 이전 전신 비율 조정 후보

- [전신 정면 v3](baseline-v3/body-front-v3.png)
- [조정 프롬프트·참조 기록](baseline-v3/body-front-v3.yaml)

마네킨을 참조해 상대적인 머리 크기를 키우고 몸통·팔다리 길이를 줄인 검수 후보다.

## 이전 전신 정면 후보

- [전신 정면 v2](baseline-v2/body-front-v2.png)
- [생성 프롬프트·참조 기록](baseline-v2/body-front-v2.yaml)

전신 마네킨 비율과 현재 얼굴을 함께 참조했다. 정확한 등신과 중성적 인상은 검수 대상이다.

## 이전 제작 기록

`baseline-v1/`은 이전 얼굴·전신 후보와 생성 기록이다. 현재 얼굴 기준으로 사용하지 않는다. 전신 v2에 현재 얼굴을 참조했으며 8방향 시트는 미제작이다. 생성기 기본 참조는 자동 변경하지 않는다.

기존 캐릭터 자료는 `../old/`에 보존한다.

## 피부 마네킨에 얼굴 추가

- [얼굴 추가 전신 v6](baseline-v6/body-face-front-v6.png)

## 얼굴 마네킨 v3 비율 적용
