# 새 기본 캐릭터 참조

성인 평균 5등신의 중성적인 기본형 후보다. 짧은 갈색 머리, 갈색 눈, 회색 밀착 상의와 짧은 숏팬츠를 적용했다.

- [얼굴·전신 정면 기준 후보](baseline-v1/face-body-front-v1.png)
- [실제 생성·수정 프롬프트와 기록](baseline-v1/generation-prompts.yaml)

8방향 시트에 앞서 얼굴과 전신 정면을 먼저 제작했다. 아직 사용자 검수 전이며 생성기의 기본 참조로 자동 연결하지 않는다. 이전 자료는 `../old/`에 보존한다.
