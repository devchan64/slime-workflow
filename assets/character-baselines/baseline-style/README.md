# 베이스라인 기본 설명 프롬프트

캐릭터 에셋 베이스라인 제작 시 공통으로 사용하는 독립적인 화풍 설명은 `base-prompt.txt`에서 관리한다. 큰 눈, 단순화된 작은 코·입, 부드럽게 좁아지는 턱선, 머리카락 덩어리와 부드러운 회화적 명암을 정의한다.

`manifest.yaml`은 프롬프트 해시, 정면 얼굴 구도 지시와 검수 기준을 관리한다. 공통 설명에 캐릭터별 특징·구도를 작업에 맞게 추가한다.

이 자료는 워크플로우의 재사용 제작 에셋이다. 기존 생성기의 자동 로딩이나 모델 설정을 변경하지 않는다. 전신의 체형·방향은 승인된 리그 기준을 유지한다. 새 후보의 채택 또는 기존 베이스라인 이미지 교체를 의미하지 않는다.
