# 테사 제작 참조

`body-front-v2/`는 사용자 지시로 등록한 정면 전신 베이스라인이다. ANNY 중성형 v4의 체형·자세를 참조한 후보에 큰 눈을 적용한 최종 선택 이미지를 보관한다.

현재 전신의 경로·메타데이터·SHA-256은 루트 `manifest.yaml`의 `body_reference`에서 관리한다. 사용자 채택은 리그 기하 일치나 특정 등신 수의 정밀 실측 검증을 의미하지 않는다.

기존 v1 전신·얼굴과 v2 얼굴은 폐기했으며 경로·해시를 유지한다. `baseline-source-v2/`에 정면 전신에서 파생한 4방향을 등록했다. 상단은 후면 좌·우, 하단은 전면 좌·우다. `face-front-v3/`에는 같은 전신에서 파생한 머리와 목까지의 정면 얼굴을 등록했다. 제작 참조 등록이며 게임 런타임 채택은 별개다.

제작 과정과 파생 후보의 기록은 [테사 베이스라인 제작 기록](../../generation-records/tesa-baseline-20261004/README.md)에 보존한다.
