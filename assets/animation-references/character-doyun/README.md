# 도윤 베이스라인 참조 자산

사용자가 승인한 정면 체형과 교체 등록을 지시한 v2 베이스라인이다.

- `body-front-v2/`: ANNY 중성형 v4 정면 렌더를 참조한 승인 체형.
- `baseline-source-v2/`: 4방향 전신. 상단 후면 좌·우, 하단 전면 좌·우.
- `face-front-v2/`: 머리와 목만 포함하는 정면 얼굴.

루트 `manifest.yaml`에 현재 원본·메타데이터·SHA-256을 연결한다. 기존 v1 폐기 기록은 유지한다. 제작 참조 등록이며 게임 런타임 채택은 별개다. 사용자 채택을 리그 기하 강제 일치나 5등신 정밀 실측 검증으로 간주하지 않는다.
