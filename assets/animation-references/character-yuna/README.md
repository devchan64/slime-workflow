# 유나 베이스라인 참조 자산

- `baseline-source-v1/`: 투명 배경 1254×1254 PNG 원본과 방향별 영역·출처·SHA-256.
- 배치: 좌상은 후면 좌향, 우상은 후면 우향, 좌하는 전면 좌향, 우하는 전면 우향의 3/4 시점.
- 기존 베이스라인의 화풍·배치를 참고한 신규 외형 초안이다.
- 제작용 참조 원본이며 게임 런타임 채택 여부는 `runtime_adopted: false`다.
- 방향별 영역은 원본 YAML을 따른다. 별도 크롭·모션·포즈 맵은 생성하지 않았다.

## 정면 얼굴 베이스라인

`face-front-v1/`는 기존 4방향 원본을 참조해 생성한 투명 배경 정면 얼굴 이미지다. 얼굴·헤어·눈동자·피부색의 제작 기준으로 등록했으며, 루트 `manifest.yaml`의 `face_reference`에서 이미지와 해시를 확인한다. 파생 원본과 해시는 얼굴 폴더의 `manifest.yaml`에 기록한다. 전신·방향 기준은 기존 `baseline-source-v1/`를 따른다.
