# 유나 베이스라인 참조 자산

사용자가 교체 등록을 지시한 얼굴·4방향 전신 v3 베이스라인이다.

- `baseline-source-v3/`: 새 얼굴과 가죽 방어복을 적용한 4방향 전신. 상단 후면 좌·우, 하단 전면 좌·우.
- `face-front-v3/`: 머리와 목만 포함하는 정면 얼굴.

루트 `manifest.yaml`에 현재 원본·메타데이터·SHA-256을 연결한다. 이전 전신·얼굴 파일은 삭제하고 경로·해시는 `retired_assets`와 Git 이력에 남긴다. 제작 참조 등록이며 게임 런타임 채택은 별개다. 5등신을 목표로 생성했으며 사용자 채택을 정밀 실측 또는 리그 기하 일치 검증으로 간주하지 않는다.
