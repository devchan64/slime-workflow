# 유나 베이스라인 참조 자산

사용자 지시로 v2를 베이스라인에 적용했다.

- `baseline-source-v2/`: ANNY 중성형 v4 정면 렌더를 참조한 외형 후보에서 파생한 4방향 전신. 상단 후면 좌·우, 하단 전면 좌·우.
- `face-front-v2/`: 정면 머리와 목만 포함하는 얼굴 기준. 어깨·가슴·의상은 제외한다.
- 루트 `manifest.yaml`에 현재 원본과 SHA-256을 연결한다. 게임 런타임 채택과는 별개인 제작 참조 자산이다.

기존 v1 전신·얼굴은 폐기했으며 경로·해시는 `retired_assets`와 Git 이력에 남긴다. v2 채택은 사용자 선택을 기록한 것으로, 5등신 정밀 실측이나 리그 메시·관절의 강제 일치를 검증했다는 의미는 아니다.
