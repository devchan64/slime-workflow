# 캐릭터 베이스라인

- `character-default-white-shirt-four-directions-v2.png`: 현재 승인된 4방향 기준 시트. 참조 없이 한 번에 직접 생성했다. 한 PNG에 2×2로 배치한다.
- 같은 이름의 YAML: 실제 크기·셀 좌표·참조·파일 해시. 셀은 좌상부터 `up_left`, `up_right`, `down_left`, `down_right`이며 화면에서 바라보는 방향이다.

4방향 시트의 실제 크기는 1254×1254, 셀은 627×627이다. 요청 해상도와 구분하여 원본 그대로 보관한다. 동일 폴더의 `down_left.png`, `down_right.png`, `up_left.png`, `up_right.png`는 이 통합 시트에서 만든 512×512 방향별 분할 참조다. 워크플로우 제작 기준 자산으로 보관하며 상위 manifest.yaml이 원본 경로와 해시를 참조한다. 게임 런타임 에셋이 아니다.

단일 베이스라인은 폐기했다. 통합 시트와 분할 이미지는 하나의 베이스라인으로 관리하며 소비 목적에 따라 선택한다. 현재 애니메이션 신체 입력은 상위 캐릭터 설정의 신체 베이스 manifest를 따른다. 신규 캐릭터는 최대 지원 크기의 2×2 시트로 한 번에 생성한다.

기존 four-directions-v1 파일은 폐기했으며 과거 Git 이력으로만 확인한다. v2의 실제 크기는 1254×1254이며 최대 지원 크기 충족 여부는 미확인이다.
