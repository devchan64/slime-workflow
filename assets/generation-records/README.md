# 명시적으로 보존하는 생성 기록

일반 생성·후보·검수·재시도·패킹 기록의 기본 보관 위치는 `.tmp/test/<executor-kind>/<YYYY-MM-DD_HH-mm-ss>/`이다. 자동으로 이 경로에 승격하거나 Git에 추가하지 않는다.

이 디렉터리에는 **사용자가 저장소 추적을 명시적으로 지시했고, 리포트 또는 현재 생성기에 직접 연결된 기록**만 둔다. 리포트에서 결과·근거로 직접 참조하거나 생성기가 재현 입력·고정 검증 자료로 직접 사용하는 관계를 기록해야 한다. 생성기 이름·코드 사본이 들어 있거나 최종 에셋과 관리번호가 같다는 사실만으로는 보존 대상이 아니다.

등록 시 연결 대상·보존 목적·출처·버전·파일 해시를 기록하고 `index.yaml`을 갱신한다. 비공개 프롬프트·기획·인증 정보·모델 가중치는 넣지 않는다. 실제 커밋은 사용자의 명시적 지시가 있을 때 수행한다.

2026-09-23 정리에서 리포트·생성기의 직접 참조가 없는 과거 후보·패킹 이력을 추적 경로에서 폐기하고 `.tmp/test/generation-records-retirement/`로 이동했다. 현재 직접 연결되어 남긴 기록은 없다. 기존 리포트와 승인된 MoMask 모션·리그 등 재사용 제작 자산은 이 정리 대상이 아니다.
