# 테사 베이스라인 제작 기록

기록 ID: `tesa-baseline-20261004` · 버전: 1 · 기준: 2026-10-04 사용자 기록 요청.

이 기록은 [테사 정면 전신 v2](../../animation-references/character-tesa/body-front-v2/manifest.yaml)의 제작 경로와 파생 후보를 보존한다. [manifest.yaml](manifest.yaml)의 모든 파일 경로는 저장소 루트 기준이다. 프롬프트 원문·단어 수·SHA-256과 입력·출력의 해시를 포함한다. 이미지 중복은 해시가 같은 기존 자산으로 연결했다.

## 전환 배경

처음 만든 얼굴 v2는 한 차례 등록됐으나 사용자가 폐기를 지시했다. 이후 전신 우선 제작으로 전환했다. 앞선 전신 후보는 다른 캐릭터와 얼굴이 비슷했고, 눈꺼풀만 바꾼 수정으로는 구분이 충분하지 않았다. 얼굴 재설계 뒤에는 머리가 작아지고 성숙한 인상이 강해졌다.

5등신·5.5등신이라는 숫자 지시만으로 목표 비율을 얻지 못했다. 이후 ANNY 정면 렌더를 첫 번째 입력이자 주 편집 대상으로 두고, 얼굴과 복장 입력의 역할을 분리했다. 사용한 리그는 `anny-neutral-v4`이며 `generation.json`의 머리 비율 기록은 약 5.68이다. 이를 정확한 5등신 리그라고 기록하지 않는다.

## 보존한 실제 실행

| 단계 | 원본 실행 시각(KST) | 입력·변경 | 상태 |
|---|---|---|---|
| 01 ANNY 비율 적용 | 17:43:30 | ANNY 정면 렌더 → 얼굴 → 복장 이미지 순으로 입력. 리그 체형을 우선하도록 지정 | 중간 결과 |
| 02 큰 눈 보정 | 18:02:28 | 01 전신의 눈·홍채를 확대하고 다른 요소를 유지하도록 지시 | 사용자 채택, 정면 전신 v2 등록 |
| 03 얼굴 파생 | 18:07:16 | 등록 전신에서 머리 전체와 목까지만 정면 얼굴 생성 | 사용자 채택, 얼굴 v3 등록 |
| 04 4방향 파생 | 18:10:23 | 등록 전신에서 후면 좌·우 / 전면 좌·우 시트 생성 | 사용자 채택, 4방향 v2 등록 |

보존 프롬프트는 각 단계 폴더의 `prompt.txt`다. 초기 실패 변형 전체를 정식 자산으로 복제하지 않고 현재 채택 결과에 직접 연결되는 입력과 4개 실행을 보존했다. 얼굴 입력은 사용자 재첨부 이미지이며, 이전 얼굴 v2의 승인 복원을 의미하지 않는다.

## 결과와 한계

- 정면 전신 v2·4방향 v2·전신에서 파생한 얼굴 v3는 사용자 채택 상태다. 폐기된 얼굴 v2는 복원하지 않았다.
- 02 보정에서 눈은 커졌지만 의상 질감과 발 사이 그림자도 달라졌다. 현재 등록 이미지는 사용자가 선택한 그 출력 자체다.
- ANNY 기하 강제 일치와 5·5.5등신 정밀 실측은 검증하지 않았다. 머리 크기 지시나 사용자 채택으로 실측 검증을 대체하지 않는다.
- 03 얼굴과 04 시트는 사용자 채택을 기록한다. 얼굴 정체성 및 방향별 체형·스트랩·파우치 위치의 정밀 검증 완료를 의미하지 않는다.
- 내장 이미지 생성 도구를 사용했다. 모델 버전·시드는 노출되지 않았고 별도 추론 로그는 제공되지 않았다. 이 기록은 프롬프트·파일 출처 보존이며 동일 출력 재현의 보증이 아니다.

재사용 절차는 [전신 우선 제작 워크플로우](../../../workflows/character-baseline-body-first.md)를 따른다. 기존 보존 기록을 덮어쓰지 않고 새 실행 폴더에서 작업한다. 게임 런타임 채택은 별도다.
