# 워크플로우 UI 가이드 목차

UI를 신규 작성하거나 변경할 때 적용하는 공통 기준이다. 생성기마다 같은 역할의 요소를 구별하기 쉽고 같은 순서로 읽을 수 있도록 관리한다. 개별 생성기 사용법은 해당 생성기 페이지에서 제공한다.

1. [글자·행간과 레이아웃 여백](typography-spacing.md): 정보 레벨과 레이아웃별 수치 기준.
2. [공통 레이아웃과 컴포넌트](layout-components.md): 카드, 접기, 사용설명과 변경 기록.
3. [생성기 사용 흐름](generator-workflows.md): 입력·진행·이력·결과의 공통 계약.
4. [이미지 생성기 페이지 UI](image-generator-pages.md): 참조 입력·프롬프트 검토·이미지 결과와 이력 재사용.
5. [접근성과 검수](accessibility-review.md): 실제 화면의 검수 방법과 범위.
6. [적용 현황](adoption-status.md): 확인 시점과 미적용·미검증 범위.
7. [검수 기록](history/): 과거 확인 내용과 당시의 한계.
8. [화면 목록](screen-inventory.md): 독립·대화 내 연결과 후속 검수 범위.

기존 [워크플로우 UI 가이드](../management-ui.md)는 이전 링크 및 아직 분리하지 않은 공통 규칙의 기준 문서로 유지한다. 구체적인 글자·간격과 카드 규칙은 위 전문 문서를 기준으로 하며, 기존 문서의 같은 주제 요약은 이를 가리킨다. 과거 계획 및 검수 기록은 현행 구현이나 규칙의 근거로 자동 승격하지 않는다. 기능별 실행·저장 계약은 [클라이언트 가이드](../management-clients.md), 생성기 문서 관리는 [생성기 구성 가이드](../generator-structure.md)를 따른다.

수치와 사용 흐름은 목표 계약이다. 각 화면이 실제로 준수하는지는 적용 현황 및 검수 기록에서 확인한다. 문서 이동 시 기존 제목 앵커와 외부 참조를 유지하거나 함께 수정한다.
