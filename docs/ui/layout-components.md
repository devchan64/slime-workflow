# 공통 레이아웃과 컴포넌트

## 생성기 섹션 카드와 접기 계약

생성기 화면의 모델 준비·현재 생성 작업·생성 입력·생성 이력은 같은 카드 구조로 제공한다. 선택한 작업 결과는 별도 주요 카드가 아니라 생성 이력 안에서 해당 작업에 연결해 표시한다. 접을 수 있는 카드의 머리말 자체가 펼침 조작이며 하나의 제목·상태 요약·열림 표시로 구성한다. 같은 제목의 카드 안에 또 다른 동일 목적의 펼침 머리말을 중첩하지 않는다. 머리말에는 버튼·링크·입력 등 별도 조작을 중첩하지 않고, 작업 제어는 카드 본문에 둔다. 접힘 여부는 네이티브 `details`로 보조기기에 전달하며 키보드 초점을 표시한다.

- 접힌 모델·진행 카드에도 준비 상태, 실행·대기 수, 알 수 있는 단계와 오류 또는 조회 실패를 표시한다. 여러 작업의 단계는 한 작업의 수치로 전체를 대표하지 않는다. 관측이 오래되었거나 불완전하면 그렇게 표시한다.
- 접거나 펴도 입력·첨부·선택 작업과 확인 중인 내용을 유지한다. 생성·중지·재개·삭제는 카드 동작으로 실행하지 않는다. 진행 카드가 접혀도 머리말이 보이고 자동 갱신이 켜져 있으면 기존 갱신 규칙을 유지한다.
- 바로 가기는 접힌 대상 카드를 연 후 해당 영역에 초점을 옮긴다. 카드를 열 때 필요한 이력 읽기는 허용하되 작업 생성이나 결과 선택을 실행하지 않는다. 결과가 없으면 비활성 이유를 표시한다.
- 진행 중 작업이나 직접 주소에서 결과를 열면 이력을 펼쳐 해당 작업을 찾고 선택 결과를 표시한다. 검색·페이지 범위 밖이거나 조회에 실패한 경우 대상과 사유를 드러내며, 다른 작업을 임의로 선택하지 않는다. 결과를 닫으면 해당 이력 항목으로 초점을 복원한다.
- 진행 카드에는 마지막 조회 시각을 한 번 표시한다. 조회 시각과 서로 다른 추정·단계 관측 갱신 시각은 의미를 명시해 상세 정보에 모으며, 실제 시작 시각이 확인되지 않으면 경과 시간을 임의로 계산하지 않는다.
- 기본 펼침 여부는 작업 맥락에 맞게 정하되 상태 요약은 항상 남긴다. CSS의 카드 테두리·머리말·내부 여백과 접기 토큰을 공용으로 사용하고, 시각·DOM 순서를 맞춘다.
- 적용 화면에서는 열고 닫은 뒤 값과 초점, 진행 갱신, 오류·빈 상태, 이력 선택 및 결과 복귀를 확인한다. 데스크톱과 360px에서 가로 넘침을 확인하며 기존 사용자 GPU 작업을 중단하거나 검수용 생성을 접수하지 않는다. 문서 규칙 자체는 전체 생성기 전환 완료를 뜻하지 않는다.

## 생성기 사용설명과 변경 기록

생성기별 사용설명은 해당 생성기 페이지에서 직접 읽을 수 있어야 한다. 목적, 입력별 역할과 필수 여부, 사용 순서, 결과와 제한사항을 해당 기능 가까이 설명하고, 오류·비활성 사유와 즉시 필요한 안내는 접힌 설명 밖에 둔다. 공통 UI 가이드는 설명의 배치와 표현 규칙을 관리하며 생성기별 사용법의 원본을 대신하지 않는다.

사용설명과 변경 기록은 별도의 제목과 내용·역할을 유지하되 같은 공통 카드 및 펼치기 서식을 사용한다. 본문은 각 생성기의 명시적으로 등록된 문서 또는 해당 페이지의 관리되는 내용에서 제공하며 링크만으로 대체하지 않는다. 변경 기록은 기존 `CHANGELOG.md` 원본과 공용 표시 계약을 유지한다. 사용설명과 변경 기록의 혼합·복제나 자동 생성·접수를 일으키지 않는다. 사용설명은 필요한 내용을 찾을 수 있는 위치에 두고 기본 펼침 여부는 내용의 중요도와 화면 흐름에 따라 정한다.

이 규칙은 목표다. 공통 표시 구현의 존재, 각 페이지 연결 및 실제 화면 검증은 별도로 확인한다. 누락·읽기 실패 시 원인과 조치를 표시하고, 키보드 조작과 좁은 화면에서의 가독성을 확인한다.
