# 접근성과 실제 화면 검수

실제 워크플로우 화면에서 데스크톱과 360px을 확인한다. 제목 계층, 동일 레벨의 계산된 글자 크기·행간, 카드 경계, 패딩과 요소 간격, 긴 문장의 줄바꿈 및 가로 넘침을 대조한다. 200% 확대, 키보드 초점·조작과 색 대비도 확인하고 확인하지 못한 항목은 별도로 기록한다.

카드를 열고 닫은 뒤 입력·첨부·선택과 초점이 유지되는지, 접힌 진행 요약과 자동 갱신이 유효한지 확인한다. 설명과 변경 기록의 펼침·본문·오류 표시를 각각 확인한다. 이력 없음·실행·오류 등 실제로 안전하게 확인할 수 있는 상태를 구분한다.

이력 입력 복원은 결과가 펼쳐진 경우와 입력 카드가 접힌 경우를 포함한다. 결과를 열었을 때 저장 입력의 자동 표시, 한 번의 입력 적용, 적용 전 기존 입력 유지, 적용 후 원본·설정·첨부와 초점, 실패 시 기존 값 보존을 확인한다. 데스크톱과 360px에서 버튼과 표시 영역을 확인하고, 실제로 재현하지 못한 실패나 첨부 종류는 미검증으로 기록한다.

영상 입력은 파일 선택과 이력 복원 각각에서 미리보기의 대상·재생·교체·제거와 오류 안내를 확인한다. 결과 영상과 입력 미리보기의 이름과 소속을 구별하고 좁은 화면에서 재생 조작과 가로 넘침을 확인한다.

검수용 GPU 작업을 접수하거나 사용자의 실행 작업을 중단하지 않는다. 실제 화면에서 안전하게 확인할 수 없는 생성·중지·삭제 흐름은 미검증으로 보고한다. 별도 포트의 모의 UI를 운영 검수 경로로 만들지 않는다. 격리된 단위·계약 테스트는 실제 화면 검수와 구분한다.

상세 기준은 [접근성과 검증](../management-ui.md#9-접근성과-검증), [카드 계약](layout-components.md), [글자·여백](typography-spacing.md)을 따른다. 검수 결과에는 화면·날짜·뷰포트·실측 또는 관찰·확인하지 못한 범위를 기록한다.
