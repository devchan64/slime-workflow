# 생성기 변경과 검증 이력

### 개별 변경과 검증 이력

다음 기록은 최신 변경부터 정렬했다. 각 항목의 미검증·미구현 표시는 해당 변경을 검수한 시점의 범위다.

- Kimodo 이력 카드에도 검증된 저장 시도의 첫 결과 프레임을 연결했다. 실제 완료 이력 이미지 로딩·이미지 클릭 선택, 일부 저장 입력 조회 불가 안내와 중지 이력의 이미지 없음, 360px 가로 넘침 없음을 확인했다. 실행 중에는 현재 시도에 첫 프레임이 저장된 뒤 표시한다.
- Fun Control·VACE·Animate-2·DWPose 이력 카드에 저장된 결과 시도의 첫 프레임을 연결했다. 결과 기록의 시도 ID와 경로·심볼릭 링크를 검증한다. 실제 Fun Control 완료 결과 프레임·실패/중지의 이미지 없음·이미지 클릭 선택 및 360px 가로 넘침 없음을 확인했다. 격리 검사 22건과 빌드 통과. DWPose·VACE·Animate-2에서도 실제 결과 이미지 로딩, 이미지 클릭 선택, 360px에서 가로 넘침 없음을 확인했다. 실행 중 현재 시도 선택과 이전 시도 제외는 격리 테스트로 검증했다. Wan Fun Control 실제 화면 번들에 격리 응답을 연결한 Chrome 검사에서 1440px·360px 모두 첫 프레임 준비 중 → 일시적 이미지 조회 실패 → 이력 새로고침 후 이미지 표시를 확인했다.
- FLUX 9개 프로필의 공용 이력 카드에 해당 작업의 결과 PNG 미리보기를 연결했다. 결과 유무는 서버에서 확인하고 지연 로딩하며 카드 클릭은 선택만 수행한다. 표정 실제 완료 이력 두 이미지와 이미지 클릭 선택, 360px 가로 넘침 없음을 확인했다. 다른 프로필의 실제 결과 및 결과 없음·진행 중 화면과 영상·모션 카드 미리보기는 별도 검증·구현 대상이다. 현재 미리보기는 원본 PNG를 축소 표시한다.
- 8770 응답이 복구된 후 Fun Control·VACE·Animate-2·DWPose·Kimodo·HeartMuLa·Dasheng·번역·FLUX 일반·표정의 최근 이력 각 1건에 대한 요약 조회가 정상 응답함을 확인했다. 번역은 요약 대상 필드가 없어 빈 요약이다. HeartMuLa 실제 목록에서 이력 태그·시드와 360px 가로 넘침 없음을 확인했다. 조회 실패 화면은 재현하지 않았다.
- 이력 카드 요약의 조회 실패와 일부 입력 누락을 안내하고 기존 이력·직접 입력 조회는 유지한다. 1MiB 초과·잘못된 형식 거절을 포함한 격리 검사 31건과 빌드가 통과했다. 추가 서비스 실제 화면 검수 시 8770 연결이 거절됐고 정식 재시작은 8771 점유, 개별 GUI 실행은 8770 소유자를 확인할 수 없어 실패했다. 포트를 점유한 프로세스는 건드리지 않았고 실제 오류 화면 재검증은 남아 있다.
- 기존 ID·상태 관측 응답은 유지하면서 현재 페이지 최대 30개에 대해 제한된 저장 입력 요약을 별도 조회한다. 서버는 등록 저장소·ID·일반 파일·1MiB 크기와 허용 필드를 검사하며 프롬프트와 경로는 반환하지 않는다. FLUX 표정 실제 목록에서 태그·해상도·스텝·시드와 360px 가로 넘침 없음을 확인했다. 격리 관측·경로 검사 30건과 빌드가 통과했다. 다른 서비스와 누락·오류 화면별 검증은 별도다.
- 공용 이력에서 저장 입력을 명시적으로 조회한 뒤 태그·해상도·프레임·스텝·시드 중 실제 저장된 값을 요약한다. FLUX 표정 실제 이력의 태그·해상도·스텝·시드와 360px 가로 넘침 없음을 확인했고 요약 단위 검사도 통과했다. 목록 카드 자체의 요약은 아직 제공하지 않는다.
- 공용 이력 카드에서 상태와 ID를 분리하고 표준 작업 ID에 포함된 시각을 한국 시간의 `ID 시각`으로 표시한다. 실제 Fun Control 이력과 360px 가로 넘침 없음을 확인했다. 기록의 별도 생성 시각이나 설정·태그를 조회한 것은 아니다.
- 공용 이력에 페이지당 5·10·20·30건 선택을 추가했다. 크기를 바꾸면 첫 페이지부터 조회하며 실패 시 기존 페이지와 크기를 유지한다. 실제 Fun Control에서 5건 선택, 다음·이전 페이지와 360px 가로 넘침 없음을 확인했다. 목록 관측 응답은 현재 ID와 기록 상태만 제공하므로 태그·설정 요약은 표시하지 않는다.
- 기록 폴더 요청이 서비스 이름을 정식 등록 경로로 변환하도록 수정해 `/flux-expression`과 실제 `/flux-expression-generator`의 차이를 처리한다. 격리 경로 검사 10건 통과. FLUX 표정 실제 완료 이력에서 폴더 경로 조회와 360px 가로 넘침 없음을 확인했다. 폴더 열기·복사는 실행하지 않았다.
- 공용 결과에 등록된 저장소와 작업 ID를 검증하는 기록 폴더 조회·경로 복사·열기 UI를 연결했다. 조회는 파일 관리자를 실행하지 않으며 기존 열기 요청은 사용자 동작에서만 실행한다. 격리 검사 9건과 DWPose 실제 경로 조회·360px 가로 넘침 없음을 확인했다. 실제 폴더 열기·클립보드 변경 및 다른 서비스별 경로는 검증하지 않았다.
- 영상·이미지·오디오 공용 결과와 Kimodo·번역 결과에 공용 `JobIdentifier`를 연결했다. 실제 DWPose 결과에서 읽기 전용 ID·복사 버튼, 다른 작업 조회 시 ID 변경 및 360px 가로 넘침 없음을 확인했다. 사용자 클립보드는 변경하지 않아 복사 성공·실패의 실제 브라우저 확인은 포함하지 않는다.
- 공용 검토 버튼 전환 후 DWPose 실제 완료 입력을 복원해 검토의 파일명·손/얼굴 옵션과 입력 수정 복귀를 확인했다. 이력 선택과 832px 입력·결과 이미지가 유지됐고 360px 검토·복귀 상태의 문서·스크롤 너비는 345px로 같았다. 추출은 접수하지 않았다.
- 공용 검토 버튼 전환 후 Fun Control 실제 완료 이력을 복원해 필수 입력 안내 해소, 113프레임 영상 정보·입력 요약 검토와 입력 수정 복귀를 확인했다. 복귀 후 프롬프트가 유지되고 360px 검토·복귀 상태에서 문서·스크롤 너비가 345px로 같았다. 생성은 접수하지 않았다.
- 공용 이력·다운로드 기록의 브라우저 연결 실패를 한국어 연결 확인 안내로 표시하고 서비스의 구체적 오류는 유지한다. 연결 오류·서비스 오류 분기 단위 검사가 통과했다. 실제 Animate-2에서는 정상 이력 재조회 후 선택 유지와 360px 가로 넘침 없음을 확인했다. 변경 후 연결 실패 화면은 재현하지 않았다.
- 공용 참조 이미지 입력은 파일 오류 뒤 이력 복원 등으로 이미지가 교체되면 이전 오류를 지운다. 실제 DWPose에서 잘못된 시험 PNG 선택 오류 후 저장 입력을 적용하여 오류 해제·832px 미리보기·검토 버튼 활성 및 360px 가로 넘침 없음을 확인했다. 이 확인은 파일 선택 경로이며 드롭·클립보드 검증은 아니다.
- Animate-2 실제 완료 이력의 저장 동작 영상은 MPEG-4 Part 2로, 검수 브라우저가 재생하지 못했다. 원본 GET·범위 요청은 정상이며 결과 영상은 로드됐다. 입력 영상 재생 실패 안내와 원본 열기 링크를 추가하고 실제 복원 및 360px 가로 넘침 없음을 확인했다. 브라우저 내 원본 재생이 가능해진 것은 아니다.
- Fun Control·VACE·DWPose에서 확인 화면을 여는 버튼을 공용 `ActionButton`과 `생성 요청 검토` 문구로 통일하고 입력별 비활성 사유를 표시한다. 번역은 `번역 요청 검토`로 구분한다. 실제 네 화면의 버튼과 사유를 확인했으며 VACE·번역에서 검토 후 입력 수정 복귀, VACE의 360px 가로 넘침 없음을 확인했다. 생성·번역은 접수하지 않았다.
- FLUX 마네킨 실제 화면에서 관절 신체 조정 단계의 예시 프롬프트와 참조 이미지를 불러와 공용 검토의 화풍 적용 결과를 확인했다. 입력 수정 복귀 후 두 입력이 유지됐고 360px 검토·복귀 상태에서 문서·스크롤 너비는 345px로 같았다. 생성은 접수하지 않았다.
- FLUX 식생 실제 화면에서 한국어 설명을 추가하고 검토하여 공용 화풍 적용 프롬프트·번역 전 단어 수·번역할 설명을 확인했다. 360px에서 검토와 입력 수정 복귀 모두 문서·스크롤 너비가 345px로 같고 설명이 유지됐다. 생성은 접수하지 않았다.
- FLUX 캐릭터의 신체 비율 가이드를 선택·첫 참조에 적용하고 프롬프트 검토 후 입력 수정으로 복귀해 참조와 입력이 유지됨을 확인했다. 가이드 해시가 360px 화면을 넓히던 문제를 수정했고, 선택·검토·복귀 상태에서 문서와 스크롤 너비가 모두 345px임을 확인했다. 생성은 접수하지 않았다.
- VACE·Fun Control 등 영상 서비스의 일반 `status` 조회는 중단 작업 복구를 호출할 수 있어, 단순 결과 조회에 추가 호출하지 않는다. 현재 대기열 실행 시도·상태·갱신 시각과 경로가 일치하는 추정만 읽는 관측을 추가했다. 불일치·오래된 기록은 숨기며 Fun Control의 별도 추론 이벤트도 유지한다. 격리 관측 테스트에서 포인터·상태 변경, 잘못된 값·심볼릭 링크 거절과 VACE 읽기 전용 경로 연결을 확인했다. 별도 임시 게이트웨이를 거쳐 추정이 반환되고 상태 파일이 유지되는 검사와 기존 결과 경로·무복구 검사도 통과했다. 그러나 실행 중 실제 영상 추정 UI는 아직 검증하지 않았다.
- 기존 격리 모의 진행 검증 화면에 공용 예상 시간 표시 예시를 추가했다. 실제 브라우저에서 대기·표본 있음·지연·완료 전환, 미정 값과 근거·범위 표시, 완료 시 예상치 숨김 및 360px 가로 넘침 없음을 확인했다. 수치는 모의 값이며 서비스 추정·GPU 실행의 정확성을 검증하지 않는다.
- FLUX와 Kimodo의 결과 화면에도 원 서비스 추정이 유효하고 관측 상태와 일치하는 경우를 연결했다. 예상 정보가 없는 실행 중 작업은 확인 불가로 표시한다. 데이터 형식 단위 검사와 빌드는 통과했고 Kimodo와 FLUX 표정 완료 이력의 결과·360px 화면이 정상 표시되고 종료 작업에 진행 중 예상치가 나오지 않음을 확인했다. 실행 중 FLUX·Kimodo의 실제 추정 화면은 별도 검증이다.
- 음악·효과음 결과는 원 서비스의 작업 ID·상태가 결과 관측과 일치하고 추정 값 형식이 유효할 때 공용 추정의 총 시간·남은 시간·완료 시각·예상 진행률·근거·범위·표본·갱신 시각을 표시한다. 미정은 계산 중으로 표시하며 종료 작업에는 예상치를 표시하지 않는다. 유효성 단위 검사와 HeartMuLa 완료 결과의 정상 표시·360px을 확인했다. 실행 중 추정의 실제 화면과 다른 생성기 추정 연결은 별도다.
- FLUX 표정 실제 완료 이력의 선택 삭제 검토에서 대상 ID·범위·동의 전 비활성, 360px 버튼 간격과 취소 후 복귀를 확인했다. 실제 삭제는 하지 않았다.
- 공용 전체·선택 이력 삭제 확인의 동의 항목과 버튼 묶음을 분리하고 버튼 간 8px 간격을 적용했다. VACE 실제 전체 삭제 대상 조회에서 동의 전 삭제 비활성, 취소 및 360px 두 버튼의 간격·가로 넘침 없음을 확인했다. 실제 삭제는 하지 않았다.
- FLUX 빌보드 실제 화면에서 점유 가이드와 프롬프트 적용, 공용 검토의 최종 프롬프트·단어 수와 입력 수정 복귀를 확인했다. 참조와 입력이 유지되고 360px 가로 넘침이 없었다. 생성은 접수하지 않았다.
