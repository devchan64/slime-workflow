후속 검수: 실제 Hermes 도구 탐색에서 DWPose 폼을 열어 완료 이력 결과가 해당 항목 안에 표시되는 것을 확인했다. 데스크톱 우측 패널의 내부 폭과 스크롤 폭은 각각 464px이었다. 다른 임베디드 생성기의 결과 흐름은 별도 검증이 필요하다.

## VACE 이력 입력 복원 · 2026-11-22

후속 변경: VACE 작업 결과에서 저장 입력이 자동 표시되고 `입력 적용` 한 번으로 복원되도록 바꿨다. 실제 완료 이력에서 자동 표시가 현재 입력을 바꾸지 않는 것과 접힌 입력 카드의 자동 열림, 참조 이미지·포즈 영상·프롬프트·121프레임 복원을 확인했다. 360px에서 가로 넘침은 없었다. 첨부 누락·조회 실패의 실제 화면 및 다른 생성기는 검증하지 않았다.

로컬 VACE 실제 완료 이력에서 입력 확인을 결과 영상 앞에 표시하고 확인 영역에 초점을 이동했다. 접힌 생성 입력에 적용하면 카드를 열고 초점을 이동하며, 포즈 모드·참조 이미지·포즈 영상·프롬프트·121프레임·시드 복원을 확인했다. 360px에서 확인 영역과 가로 넘침 없음을 확인했고 GUI 빌드가 통과했다. 적용 전 현재 입력 보존과 조회 실패·첨부 누락의 실제 화면, 다른 생성기 및 임베디드 화면은 별도 검증이 필요하다. 후속 검증으로 대화의 VACE 폼에서 실제 이력 결과를 열어도 작성 중인 프롬프트가 유지되는 것을 확인했다. 이어서 입력 적용을 선택하면 저장된 프롬프트가 반영되는 것도 확인했다. 입력 적용 중 연결 실패 또는 참조 파일 누락을 모의했을 때는 기존 프롬프트와 오류 안내가 유지됐다. 저장 입력과 첨부 조회는 30초 시간 제한을 두며, 입력 본문·참조 파일·저장 영상 정보 확인이 각각 지연되는 경우 기존 입력을 유지하고 다시 시도할 수 있음을 확인했다. 영상 정보 지연 후에는 실제 저장 영상 복원도 확인했다. 여러 영상 정보 중 하나가 실패하면 나머지 조회가 중단되고 입력이 유지되는 것도 모의 검증했다. 생성 접수는 하지 않았다. 공용 이력 확인 영역의 위치는 다른 소비자에도 적용되지만 개별 화면의 검증 완료를 뜻하지 않는다.

VACE 입력 영상 미리보기는 실제 완료 이력의 복원 포즈 MP4에서 832×480·7.5625초의 로딩과 재생을 확인했다. 360px에서 재생기가 화면 안에 들어오고 가로 넘침이 없었다. 독립 화면과 대화 패널에서 복원 포즈 영상의 재생 오류를 모의해 안내를 확인했다. 대화 패널에서 H.264 파일로 교체하면 이전 오류가 사라지고 재생이 진행되는 것도 확인했다. 영상 편집 모드의 원본·마스크 미리보기에도 같은 시험 파일을 선택해 각각 재생했으며, 마스크 내용의 유효성이나 생성 접수는 검증하지 않았다. 별도의 MPEG-4 Part 2 이력 영상은 파일 디코딩이 가능했지만 검증용 브라우저에서 재생되지 않아 실패 안내가 표시됐다. 영상 미리보기 구현은 로컬 VACE에 한정하며 다른 생성기의 적용을 뜻하지 않는다.

## VACE 이력 내 선택 결과 · 2026-11-22

로컬 VACE 페이지에서 결과를 선택한 이력 항목 아래로 옮겼다. 실제 8770 화면에서 작업 ID가 포함된 직접 주소, 접힌 이력에서 진행 중 작업의 결과 열기, 완료 이력 선택과 결과 조회, 결과 닫기 후 이력 항목 초점 복귀, 결과 바로 가기를 확인했다. 360px에서 문서 가로 넘침이 없었다. 이력 조회 중복 제한에 따른 실패를 관찰해 자동 재시도와 실패 안내·수동 재시도를 추가했다. 생성·중지·삭제는 실행하지 않았다. 이력 조회의 모든 오류와 검색·페이지 범위 밖의 모든 조합, 임베디드 화면은 별도 검증이 필요하다. 이 기록은 로컬 구현이며 다른 생성기나 원격 코드의 전환을 뜻하지 않는다.

## VACE 사용 설명·변경 기록 · 2026-11-22

로컬 VACE 독립 페이지에서 사용 설명과 변경 기록을 동일한 공용 접이식 카드로 연결했다. 사용 설명은 페이지에 직접 표시하고 변경 기록은 기존 등록된 원본에서 조회한다. 실제 8770 화면에서 두 카드의 펼침과 본문, 변경 기록의 다음 페이지 이동 및 접은 뒤 다시 열 때 선택 페이지 유지, 사용 설명의 키보드 접기를 확인했다. 360px에서 두 카드 머리글의 계산된 글자 크기 16px, 안쪽 여백 12.8px, 테두리 1px이 같았고 양쪽 카드를 펼친 상태에서 문서 가로 넘침이 없었다. 데스크톱에서 두 카드의 배치를 확인했다.
