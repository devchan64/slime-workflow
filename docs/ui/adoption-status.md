# 생성기 UI 적용 현황

이 문서는 관측 당시의 기록이다. 규칙 작성, 로컬 구현, 원격 반영, 실제 화면 검증은 각각 구분한다. 아래 2026-11-22 내용은 당시 로컬 작업 트리 기준이며 관련 구현의 원격 반영을 뜻하지 않는다.

## 공용 이력 입력 적용 · 2026-11-22

공용 이력의 입력 복원을 한 번의 `입력 적용`으로 바꾸고, Kimodo·Fun Control·FLUX·DWPose·Animate-2·음악·효과음·번역의 작업 결과에 저장 입력 자동 표시를 연결했다. 실제 독립 화면의 완료 이력에서 Kimodo, Fun Control, FLUX 일반, DWPose, HeartMuLa, 번역 및 Animate-2의 입력 표시와 적용을 확인했다. 프롬프트·설정과 각 화면에서 표시되는 참조를 확인했으며 생성 작업은 접수하지 않았다. Animate-2의 복원 동작 영상은 브라우저에서 재생할 수 없다는 기존 안내가 표시됐다. Animate-2 360px에서 가로 넘침은 없었다.

Dasheng과 FLUX의 나머지 프로필은 같은 공용 화면을 사용하지만 개별 실측하지 않았다. 임베디드 화면, 실제 첨부 누락·조회 실패, 다른 뷰포트와 모든 과거 이력의 호환성도 별도 검증이 필요하다. 이 기록은 검수 당시의 로컬 상태다.

## VACE 이력 입력 복원 · 2026-11-22

후속 변경: VACE 작업 결과에서 저장 입력이 자동 표시되고 `입력 적용` 한 번으로 복원되도록 바꿨다. 실제 완료 이력에서 자동 표시가 현재 입력을 바꾸지 않는 것과 접힌 입력 카드의 자동 열림, 참조 이미지·포즈 영상·프롬프트·121프레임 복원을 확인했다. 360px에서 가로 넘침은 없었다. 첨부 누락·조회 실패의 실제 화면 및 다른 생성기는 검증하지 않았다.

로컬 VACE 실제 완료 이력에서 입력 확인을 결과 영상 앞에 표시하고 확인 영역에 초점을 이동했다. 접힌 생성 입력에 적용하면 카드를 열고 초점을 이동하며, 포즈 모드·참조 이미지·포즈 영상·프롬프트·121프레임·시드 복원을 확인했다. 360px에서 확인 영역과 가로 넘침 없음을 확인했고 GUI 빌드가 통과했다. 적용 전 현재 입력 보존과 조회 실패·첨부 누락의 실제 화면, 다른 생성기 및 임베디드 화면은 별도 검증이 필요하다. 생성 접수는 하지 않았다. 공용 이력 확인 영역의 위치는 다른 소비자에도 적용되지만 개별 화면의 검증 완료를 뜻하지 않는다.

VACE 입력 영상 미리보기는 실제 완료 이력의 복원 포즈 MP4에서 832×480·7.5625초의 로딩과 재생을 확인했다. 360px에서 재생기가 화면 안에 들어오고 가로 넘침이 없었다. 새 파일 선택·교체, 원본·마스크 영상과 재생 실패 화면은 별도 검증이 필요하다. 영상 미리보기 구현은 로컬 VACE에 한정하며 다른 생성기의 적용을 뜻하지 않는다.

## VACE 이력 내 선택 결과 · 2026-11-22

로컬 VACE 페이지에서 결과를 선택한 이력 항목 아래로 옮겼다. 실제 8770 화면에서 작업 ID가 포함된 직접 주소, 접힌 이력에서 진행 중 작업의 결과 열기, 완료 이력 선택과 결과 조회, 결과 닫기 후 이력 항목 초점 복귀, 결과 바로 가기를 확인했다. 360px에서 문서 가로 넘침이 없었다. 이력 조회 중복 제한에 따른 실패를 관찰해 자동 재시도와 실패 안내·수동 재시도를 추가했다. 생성·중지·삭제는 실행하지 않았다. 이력 조회의 모든 오류와 검색·페이지 범위 밖의 모든 조합, 임베디드 화면은 별도 검증이 필요하다. 이 기록은 로컬 구현이며 다른 생성기나 원격 코드의 전환을 뜻하지 않는다.

## VACE 사용 설명·변경 기록 · 2026-11-22

로컬 VACE 독립 페이지에서 사용 설명과 변경 기록을 동일한 공용 접이식 카드로 연결했다. 사용 설명은 페이지에 직접 표시하고 변경 기록은 기존 등록된 원본에서 조회한다. 실제 8770 화면에서 두 카드의 펼침과 본문, 변경 기록의 다음 페이지 이동 및 접은 뒤 다시 열 때 선택 페이지 유지, 사용 설명의 키보드 접기를 확인했다. 360px에서 두 카드 머리글의 계산된 글자 크기 16px, 안쪽 여백 12.8px, 테두리 1px이 같았고 양쪽 카드를 펼친 상태에서 문서 가로 넘침이 없었다. 데스크톱에서 두 카드의 배치를 확인했다.

임베디드 화면, 문서 조회 실패 화면, 200% 확대와 색 대비 수치는 이 검수 범위에 포함하지 않았다. 사용자 작업을 생성하거나 중단하지 않았다. 이 기록은 당시 로컬 구현과 검수에 한정되며 원격 반영이나 다른 생성기의 적용 완료를 뜻하지 않는다.

이 표의 간격과 행간은 **목표 계약**이다. 현재 VACE 주요 영역 간격은 `1.25rem`, 입력 그룹은 `.9rem`이다. Kimodo·DWPose의 주요 영역 간격은 `.8rem`이므로 다른 화면까지 모두 준수된 것은 아니다. 단계적으로 공용 CSS 변수와 컴포넌트에 반영하고 각 화면의 적용 여부를 기록한다. 생성기별로 같은 역할의 줄 높이·간격을 임의로 덮어쓰지 않으며, 예외는 목적·대상·이유와 검수 결과를 이 문서에 남긴다.

서식 변경 시 실제 8770 화면에서 데스크톱과 360px을 확인한다. 페이지·주요 섹션 제목의 순서, 카드 경계, 같은 수준의 간격과 계산된 행간, 긴 문장 줄바꿈, 가로 넘침, 200% 확대, 키보드 초점과 색 대비를 검수한다. 이력 없음·실행·오류 등 실제로 확인 가능한 상태를 구분하고, 검수용 GPU 작업을 생성하거나 실행 중 작업을 중단하지 않는다. 자동 검사·스타일 수치 확인만으로 사용성 검수를 완료했다고 기록하지 않는다.

VACE는 모델 상태 바로 아래에 현재 생성 작업을 표시한다. 읽기 전용 이력과 원본 상태를 사용해 실행·대기 작업별 ID, 단계 및 근거 있는 추정을 보여 주고 결과 화면으로 이동한다. 이력은 한 번에 최대 300건까지 조회하며 나머지 또는 상태를 확인할 수 없는 항목이 있으면 전체 이력 확인을 안내한다. 자동 갱신은 상단 영역이 보일 때 30초 간격이며 수동 갱신을 제공한다. 선택 결과에서는 중복된 진행 컴포넌트를 감추고 결과 조회는 별도로 갱신한다. 현재 VACE만 적용했으며 다른 생성기 적용을 뜻하지 않는다.

VACE 입력 화면은 입력 자료 → 장면 지시 → 생성 설정 순서의 제목과 구분선을 사용하고, 부정 프롬프트는 선택 사항임을 표시한다. 수치는 넓은 화면에서 세 열, 좁은 화면에서 두 열 또는 한 열로 배치한다. 2026-11-22 VACE의 모델·현재 작업·이력·결과에 제목과 경계를 적용하고 1280px 및 360px 실제 화면에서 영역 구분·가로 넘침·이력 접근을 확인했다. 200% 확대·색 대비 수치·다른 작업 상태는 별도 검증이 필요하다. 이는 VACE 화면 적용 사례이며 다른 생성기가 자동으로 전환되었다는 뜻은 아니다. 텍스트 모드의 검토·입력 수정과 포즈 모드의 필수 입력 안내는 실제 8770 화면에서 확인했으며 GPU 접수·첨부 복원은 별도다.

`GeneratorSectionNavigation`은 생성 입력·이력·선택 결과로 이동하는 공용 탐색이다. 결과 미선택 시 비활성 이유를 표시하며 작업을 접수하거나 결과를 선택하지 않는다. VACE에서는 접힌 대상 카드를 열고 이동하며 이력을 열 때 필요한 읽기 조회를 수행한다. Kimodo의 기존 이동 동작은 유지한다. 이동 대상과 키보드 초점을 함께 확인한다.

CSS의 `.generator-page-common` 변수와 `GeneratorPageIdentity`가 이 계약의 구현이다. 2026-11-22 기준 Kimodo·Wan VACE의 독립 페이지 본문·제목·일반 입력과 DWPose의 본문·제목·입력 영역에 적용했다. 임베디드·다른 생성기 전체가 전환 완료됐다는 뜻은 아니다. 신규 적용이나 수정 시 실제 8770 화면의 대표 생성기 두 개 이상에서 데스크톱과 360px의 본문 폭·제목·라벨·입력 여백·가로 넘침을 비교하고, 변경 기록 및 기존 입력·이력 접근을 확인한다. 실행 중 사용자 작업을 중단하거나 검수용 새 GPU 작업을 접수하지 않는다. 동일 요소의 계산 스타일을 측정하고, 미검증 범위는 기록한다.
