임베디드 화면, 문서 조회 실패 화면, 200% 확대와 색 대비 수치는 이 검수 범위에 포함하지 않았다. 후속 검증으로 대화의 VACE 폼에서 사용 설명과 변경 기록을 펼치고 가로 넘침이 없는 것을 확인했다. 변경 기록 조회는 30초 시간 초과 후 재시도할 수 있으며 대화 폼에서 지연·잘못된 응답과 복구를 모의했다. 실제 변경 기록의 다음 페이지 이동도 확인했다. 공용 컴포넌트를 사용하는 Kimodo 독립 화면의 실제 변경 기록과 변경 기록 자동 테스트 6개도 확인했다. 사용자 작업을 생성하거나 중단하지 않았다. 이 기록은 당시 로컬 구현과 검수에 한정되며 원격 반영이나 다른 생성기의 적용 완료를 뜻하지 않는다.

이 표의 간격과 행간은 **목표 계약**이다. 현재 VACE 주요 영역 간격은 `1.25rem`, 입력 그룹은 `.9rem`이다. Kimodo·DWPose의 주요 영역 간격은 `.8rem`이므로 다른 화면까지 모두 준수된 것은 아니다. 단계적으로 공용 CSS 변수와 컴포넌트에 반영하고 각 화면의 적용 여부를 기록한다. 생성기별로 같은 역할의 줄 높이·간격을 임의로 덮어쓰지 않으며, 예외는 목적·대상·이유와 검수 결과를 이 문서에 남긴다.

서식 변경 시 실제 8770 화면에서 데스크톱과 360px을 확인한다. 페이지·주요 섹션 제목의 순서, 카드 경계, 같은 수준의 간격과 계산된 행간, 긴 문장 줄바꿈, 가로 넘침, 200% 확대, 키보드 초점과 색 대비를 검수한다. 이력 없음·실행·오류 등 실제로 확인 가능한 상태를 구분하고, 검수용 GPU 작업을 생성하거나 실행 중 작업을 중단하지 않는다. 자동 검사·스타일 수치 확인만으로 사용성 검수를 완료했다고 기록하지 않는다.

VACE는 모델 상태 바로 아래에 현재 생성 작업을 표시한다. 읽기 전용 이력과 원본 상태를 사용해 실행·대기 작업별 ID, 단계 및 근거 있는 추정을 보여 주고 결과 화면으로 이동한다. 이력은 한 번에 최대 300건까지 조회하며 나머지 또는 상태를 확인할 수 없는 항목이 있으면 전체 이력 확인을 안내한다. 자동 갱신은 상단 영역이 보일 때 30초 간격이며 수동 갱신을 제공한다. 선택 결과에서는 중복된 진행 컴포넌트를 감추고 결과 조회는 별도로 갱신한다. 현재 VACE만 적용했으며 다른 생성기 적용을 뜻하지 않는다.

VACE 입력 화면은 입력 자료 → 장면 지시 → 생성 설정 순서의 제목과 구분선을 사용하고, 부정 프롬프트는 선택 사항임을 표시한다. 수치는 넓은 화면에서 세 열, 좁은 화면에서 두 열 또는 한 열로 배치한다. 2026-11-22 VACE의 모델·현재 작업·이력·결과에 제목과 경계를 적용하고 1280px 및 360px 실제 화면에서 영역 구분·가로 넘침·이력 접근을 확인했다. 200% 확대·색 대비 수치·다른 작업 상태는 별도 검증이 필요하다. 이는 VACE 화면 적용 사례이며 다른 생성기가 자동으로 전환되었다는 뜻은 아니다. 텍스트 모드의 검토·입력 수정과 포즈 모드의 필수 입력 안내는 실제 8770 화면에서 확인했으며 GPU 접수·첨부 복원은 별도다.

`GeneratorSectionNavigation`은 생성 입력·이력·선택 결과로 이동하는 공용 탐색이다. 결과 미선택 시 비활성 이유를 표시하며 작업을 접수하거나 결과를 선택하지 않는다. VACE에서는 접힌 대상 카드를 열고 이동하며 이력을 열 때 필요한 읽기 조회를 수행한다. Kimodo의 기존 이동 동작은 유지한다. 이동 대상과 키보드 초점을 함께 확인한다.

CSS의 `.generator-page-common` 변수와 `GeneratorPageIdentity`가 이 계약의 구현이다. 2026-11-22 기준 Kimodo·Wan VACE의 독립 페이지 본문·제목·일반 입력과 DWPose의 본문·제목·입력 영역에 적용했다. 임베디드·다른 생성기 전체가 전환 완료됐다는 뜻은 아니다. 신규 적용이나 수정 시 실제 8770 화면의 대표 생성기 두 개 이상에서 데스크톱과 360px의 본문 폭·제목·라벨·입력 여백·가로 넘침을 비교하고, 변경 기록 및 기존 입력·이력 접근을 확인한다. 실행 중 사용자 작업을 중단하거나 검수용 새 GPU 작업을 접수하지 않는다. 동일 요소의 계산 스타일을 측정하고, 미검증 범위는 기록한다.

공통 기록 폴더 열기 실패 시 기존 경로를 마지막 확인값으로 표시하고 작업별 상태를 분리했다. 화면이 사라진 뒤 늦게 완료된 복사 결과는 반영하지 않는다. 작업별 키·기록 폴더 서버 검사 11건과 공용 복사 검사 1건, 빌드가 통과했다. 실제 화면에서 폴더 열기 실패와 복사 초점은 미검증이다.
공통 작업 ID의 값·표시 방식·이름별 복사 안내 상태를 분리하고 선택 API가 없을 때도 대체 복사 안내를 유지한다. 키 분리 포함 상태 조회 검사 7건, 공용 복사 검사 1건과 빌드가 통과했다. 실제 좁은 화면과 보조기기의 선택·복사는 미검증이다.
공통 자동 갱신에서 IntersectionObserver를 사용할 수 없는 환경은 화면 위치와 탭 표시 상태로 대체 판정한다. 빌드와 기존 갱신 간격 검사 2건이 통과했다. 대체 판정의 실제 스크롤·탭 전환과 화면 판독기 동작은 브라우저에서 아직 검증하지 못했다.
대체 가시성 판정을 공통 함수로 분리하고 모의 이벤트로 화면 진입·이탈, 탭 숨김과 구독 해제를 검사했다. 새 검사 1건, 기존 검사 2건과 빌드가 통과했다. 실제 브라우저의 중첩 스크롤 영역과 보조기기 동작은 여전히 미검증이다.
대체 가시성 판정에서 상위 스크롤·잘림 영역을 반영하고 탭 표시가 바뀌면 위치를 다시 계산한다. 모의 중첩 스크롤 경계 검사 포함 2건과 빌드가 통과했다. 실제 브라우저의 중첩 영역과 보조기기 동작은 여전히 미검증이다.
프롬프트 번역에서 원문을 수정해도 열린 문서 검색 영역을 유지한다. 이전 원문의 검색 결과는 숨기고 진행 중 요청을 중단해 새 원문에 섞이지 않게 했다. 기존 번역 검사 16건과 빌드가 통과했으며 새 입력 변경·늦은 응답 경합과 실제 화면 초점은 미검증이다.
번역 문서 검색의 진행 상태를 알리고 검색 완료 또는 실패로 초점이 사라졌을 때 검색 버튼으로 복귀하도록 했다. 공통 동작 버튼이 버튼 참조를 받을 수 있게 했다. 기존 번역 검사 16건과 빌드가 통과했으나 실제 키보드·화면 판독기 동작은 미검증이다.
공통 결과 표에 가로 스크롤 영역을 적용하고 내용이 실제로 넘칠 때만 이름 있는 키보드 초점 영역을 제공한다. 빌드와 기존 번역·상태 조회 검사 23건이 통과했다. 이 검사들은 표 스크롤을 직접 검증하지 않으며 실제 편집·검수 화면의 360px·확대·키보드 및 중첩 스크롤은 미검증이다.
표 넘침 감지를 분리해 크기 변경·넘침 해소·관찰 종료를 모의 검사하고 키보드 초점 윤곽을 추가했다. 새 검사 1건과 빌드가 통과했다. 실제 브라우저의 키보드 스크롤 및 중첩 스크롤은 여전히 미검증이다.
빌보드 목록 재조회가 끝나도 열린 상세와 속성 편집을 유지하고, 상세 항목이 현재 결과에 없으면 안내한다. 명시적으로 에셋 폐기에 성공한 경우에는 상세를 닫는다. 빌드와 카탈로그 분할 검사 4건은 통과했다. 전체 카탈로그 검사 5건 중 3건은 작업공간에 `field-grove-broadleaf-tree-1-v1`, `orchard-apple-tree-v1` 에셋이 없어 실패했다. 새 편집 보존·폐기 후 동작은 실제 화면에서 검증하지 않았으며 에셋 변경은 실행하지 않았다.
빌보드 축소·폐기 조회와 검토 중에는 다른 에셋 전환·검색·속성 편집을 잠그고 이유를 표시한다. 상세를 닫을 때 이전 목록 버튼이 사라졌으면 검색 버튼으로 초점을 돌린다. 빌드와 기존 분할 검사 4건이 통과했다. 새 검토 잠금과 초점은 실제 화면에서 검증하지 않았다.
빌보드 축소·폐기 검토의 목록·영향·원본 조회에 공용 30초 중단 처리를 적용하고, 실제 변경 요청 실패 시 결과가 불확실할 수 있음을 안내한다. 빌드, 공용 중단 검사 2건과 기존 분할 검사 4건이 통과했다. 검토 지연·복구는 실제 화면에서 검증하지 않았고 에셋 변경 요청은 실행하지 않았다.
빌보드 폐기 영향의 대상·토큰·맵별 제거 수와 축소 원본 크기·경로 형식을 확인한 뒤 검토 화면을 표시한다. 손상된 폐기 응답 검사 및 격리된 폐기 서버 검사 4건과 빌드가 통과했다. 실제 화면 오류 복구와 운영 에셋 변경은 검증하지 않았다.
빌보드 축소 완료 안내 전에 파일·DB 저장 방식별로 응답의 대상과 크기를 확인한다. 두 응답 형식과 잘못된 결과 검사 및 폐기 서버 검사 5건, 빌드가 통과했다. 실제 저장과 화면 오류 복구는 검증하지 않았다.
대화 에셋 변경 접수 목록을 세션별로 분리하고 30초 시간 초과·화면 종료 시 조회를 중단한다. 시간 초과 후에는 같은 세션의 이전 결과를 유지하고 재조회할 수 있다. 빌드와 기존 제안·접수 계약 검사 18건, 공용 중단 검사 2건이 통과했다. 새 세션 전환·시간 초과와 초점은 실제 화면에서 미검증이다.
건물 속성 저장·등록·삭제의 완료 안내 전에 응답 대상과 DB 세대, 작업 종류 또는 저장 속성이 요청과 맞는지 확인한다. 불확실한 삭제는 목록 재확인을 안내한다. 손상 응답 검사 포함 건물 검사 12건(3건 건너뜀)과 빌드가 통과했다. 실제 화면 및 운영 건물 변경은 검증하지 않았다.
대화의 건물 변경 제안을 대화·작업·이력 페이지별로 분리하고 검토 조회에 30초 중단과 진행 안내를 적용했다. 관련 제안·건물 검사를 포함한 중간 점검 32건(3건 건너뜀)과 공용 동작 검사 6건이 통과했다. 실제 화면의 전환·시간 초과는 미검증이다.
