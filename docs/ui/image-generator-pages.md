# 이미지 생성기 페이지 UI 가이드

이 문서는 [워크플로우 UI 가이드](../management-ui.md)의 하위 기준으로, 현행 이미지 생성기와 새 이미지 생성기의 페이지에 적용한다. Qwen 이미지 생성기에서 사용한 참조 입력·프롬프트 검토·이력 재사용 흐름을 참고하되 폐기된 생성기를 다시 지원한다는 뜻은 아니다. 공통 화면 구성과 행동은 [생성기 사용 흐름](generator-workflows.md)을 따르고, 모델별 입력과 제약은 해당 서비스의 실제 계약을 따른다. 아래는 목표 기준이며 모든 화면의 구현 완료를 뜻하지 않는다.

## 입력과 참조 이미지

- 프롬프트, 시드, 출력 크기, 스텝, 후처리 등 지원하는 설정의 의미·제약과 오류를 입력 가까이에 표시한다. 고정 설정과 편집 가능한 설정을 구분하고, 생성이 불가능하면 사유와 해결 방법을 버튼 가까이에 표시한다.
- 참조 이미지의 필수 여부, 허용 형식·장수·크기를 표시한다. 순서가 의미를 가지면 슬롯 번호와 역할을 표시하고 실제 요청에도 같은 순서를 유지한다. 미리보기·교체·제거 및 파일 드롭·업로드·붙여넣기는 [공용 참조 이미지 첨부 컴포넌트](../management-ui.md#참조-이미지-첨부-컴포넌트)를 따른다.
- 파일 검증이 끝나기 전에 생성하거나 불완전한 참조를 적용하지 않는다. 서비스는 GUI와 CLI에서 전달된 입력을 동일하게 최종 검증한다.

## 생성 전 검토와 진행

- 사용자 프롬프트와 공용 화풍 등 실제 결합되는 내용을 구분하고, 최종 모델 입력과 단어 수를 확인할 수 있게 한다. [프롬프트 단어 수 표시 규칙](../management-ui.md#프롬프트-단어-수-표시-규칙)을 따른다.
- 요청 확인에는 생성 크기와 최종 출력 크기, 스텝, 시드, 참조 장수 등 실제 적용 설정을 표시한다. 검토 중 입력을 보존하고 중복 접수를 방지한다. 취소는 생성을 실행하지 않는다.
- 접수와 완료를 구분하고 진행·예상 시간·오류는 공용 서비스의 상태와 근거를 표시한다. 결과 이미지가 준비되기 전에는 입력 참조나 다른 작업의 결과를 결과 이미지로 대체하지 않는다.

## 이력과 결과

- 선택한 작업의 저장 입력과 결과를 함께 읽기 전용으로 표시한다. 사용자 프롬프트와 최종 프롬프트, 생성 설정, 참조 순서와 원본을 구별하고, 저장 사본의 경로·해시 검증 실패나 누락을 알린다. 결과 조회는 현재 입력을 변경하지 않는다.
- `입력 보기`에서 프롬프트·설정과 참조 썸네일을 확인한다. 이어지는 `이 입력으로 생성하기`는 사용자 프롬프트, 시드, 크기, 후처리와 순서가 있는 참조 사본을 확인해 함께 복원한다. 누락·손상·지원하지 않는 설정 또는 조회 중 현재 입력이나 선택이 변경되면 부분 적용하지 않고 사유와 재시도 방법을 표시한다. 적용만으로 생성하지 않으며, 성공 시 입력 영역을 열고 초점과 적용한 원본 작업을 안내한다.
- 새 입력으로 다시 생성하는 행동과 기존 작업의 재개는 구분한다. 이력 선택·결과·입력 적용·우선 실행·중지·삭제는 공용 행동과 서비스의 실제 지원 범위를 따른다. 선택 삭제와 전체 초기화는 공용 확인 및 파일 삭제 계약을 따른다.

## 검증과 적용 현황

참조의 빈 상태·선택·교체·제거·순서·오류와 좁은 화면을 확인한다. 실제 화면에서 입력 → 검토·취소 → 이력 조회 → 입력 보기 → 이 입력으로 생성하기의 흐름과 초점을 검증하고, 자동화에서는 누락·해시 불일치·지원하지 않는 설정·조회 중 입력 변경·GUI/CLI 계약 일치를 확인한다. 운영 중인 생성 작업을 검증 목적으로 접수하거나 중단하지 않는다. 실행 불가능한 흐름과 브라우저 미검증 범위는 별도로 기록한다.

MiniMax H3 이미지 화면의 이력 입력 적용은 저장 입력과 참조 사본 검증을 거쳐 복원한다. 지원하지 않는 크기는 적용하지 않으며, 검수 범위와 남은 확인은 [적용 현황](adoption-status.md)을 따른다.
