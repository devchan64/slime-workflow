# 글자·행간과 레이아웃 여백

## 섹션 구분·행간 관리 기준

생성기 화면은 단순히 같은 여백을 반복하기보다 **페이지 → 주요 섹션 → 입력 그룹 → 필드·안내**의 계층을 눈으로 구분할 수 있어야 한다. 실행 상태와 입력은 별도 주요 섹션으로, 관련 설정과 설명은 같은 입력 그룹으로 묶는다. 공용 카드·구분선을 우선 사용하며 색만으로 섹션이나 상태를 구분하지 않는다.

서식의 기준은 장식이 아니라 **정보의 레벨별 글자 크기와 행간**, 그리고 **레이아웃별 내부 여백과 요소 간 간격**이다. 같은 레벨과 역할은 페이지 및 임베디드 여부와 관계없이 같은 값을 사용한다. 아래 표의 `line-height`는 배수이며 `rem`은 브라우저 루트 글자 크기를 기준으로 한다. 가로·세로 간격은 `padding`(경계 안쪽), `margin` 또는 `gap`(요소 사이)을 구분해 적용한다. 인접 영역의 간격은 부모의 `gap` 하나로 관리하고 자식의 바깥 여백을 중복해서 더하지 않는다.

| 구분 | 기준 | 적용 범위 |
| --- | --- | --- |
| 페이지 제목 | `1.5rem`, 줄 높이 `1.25` | 페이지 제목 하나. 임베디드 화면의 제목 노출 여부는 상위 패널 제목과 접근성 관계를 유지한다. |
| 주요 섹션 | 제목 `1.125rem`, 줄 높이 `1.3`; 섹션 사이 간격 `1.25rem` | 모델·진행·입력·이력·결과. 배경 또는 테두리와 제목 중 둘 이상으로 경계를 드러낸다. |
| 입력 그룹 | 제목 `1rem`, 줄 높이 `1.35`; 그룹 안쪽 위아래 여백 `.9rem` | 입력 자료·장면 지시·생성 설정처럼 목적별로 나눈다. 같은 카드 안에서는 구분선을 사용할 수 있다. |
| 본문·안내 | 본문 `1rem`, 줄 높이 `1.5`; 보조 안내 `.85rem` 이상, 줄 높이 `1.5` | 설명이 두 줄 이상이어도 줄이 겹치지 않게 한다. 작업 ID·시간 등의 보조 정보는 의미와 구분을 유지한다. |
| 라벨·필드 | 라벨 `.9rem`, 줄 높이 `1.4`; 라벨과 필드 간격 `.3rem`, 필드 묶음 간격 `.65rem` | 오류·제약·단위·비활성 사유는 관련 입력 가까이에 둔다. 체크박스와 첨부는 공용 컴포넌트의 배치를 따른다. |
| 섹션 내부 | 카드 안쪽 여백 `.8rem` 이상; 제목과 본문 간격 `.5rem` | 콘텐츠를 테두리에 붙이지 않는다. 같은 목적의 이중 카드는 금지하며, 다른 대상을 구분하는 하위 경계는 [카드 경계 기준](layout-components.md#카드-경계와-공통-컴포넌트의-책임)을 따른다. |

체크박스와 라디오는 선택 표시와 라벨을 같은 행에 가깝게 배치하고, 라벨을 눌러도 선택할 수 있게 한다. 긴 라벨은 표시 옆에서 줄바꿈하며 좁은 화면에서도 둘이 떨어지지 않게 한다. 텍스트 입력을 전체 너비로 만드는 규칙은 체크박스와 라디오에 적용하지 않는다. 관련 설명과 비활성 사유는 선택 항목 가까이에 둔다. 키보드 초점과 선택 상태가 보이는지, 실제 화면의 데스크톱·좁은 화면·확대 상태에서 확인한다.

## 레이아웃별 여백 계약

| 레이아웃 | 내부 여백 `padding` | 요소 간 여백 `gap` / `margin` | 적용 방식 |
| --- | --- | --- | --- |
| 페이지 본문 | 좌우 `1rem` | 주요 영역 사이 `1.25rem` | 최대 너비 `56rem`의 단일 열. 임베디드는 상위 패널과 좌우 여백이 중복되지 않게 한다. |
| 주요 섹션 카드 | 머리말과 본문 각각 `.8rem` | 카드 사이는 페이지 영역 간격을 사용 | 열린 카드의 머리말과 본문은 구분선으로 나누고, 별도의 바깥 여백을 추가하지 않는다. |
| 카드 내 입력 그룹 | 위아래 `.9rem`, 좌우 `0` | 그룹 제목과 안내 `.5rem` | 입력 자료·장면 지시·설정을 구분하며 구분선은 그룹 경계에만 둔다. |
| 필드 묶음 | 별도 안쪽 여백 `0` | 필드 묶음 위아래 `.65rem`, 라벨과 필드 `.3rem` | 설명과 오류는 해당 필드에 연결한다. 동일 축에서 부모 `gap`과 자식 `margin`을 함께 더하지 않는다. |
| 버튼·조작 묶음 | 별도 안쪽 여백 `0` | 조작 사이 `.5rem` | 폭이 부족하면 같은 순서로 줄바꿈하고 가로와 세로에 같은 간격을 둔다. |
| 이력 항목 | `10px` | 항목 안의 정보 `4px`, 제목·도구 모음·목록 사이 `8px` | [생성 이력의 기존 상세 기준](../management-ui.md#생성-이력-전체-폭-배치)을 따른다. 이력 항목 안쪽 여백은 주요 섹션 카드와 구분한다. |

위 값은 새로운 공용 서식의 목표다. 기존 화면의 실제 계산값을 이 표와 대조해 적용 여부를 기록하며, 공용 입력·첨부·이력 컴포넌트의 별도 규칙과 충돌하면 해당 컴포넌트의 목적과 예외를 명시한다. 좁은 화면에서도 정보의 글자 레벨과 행간을 줄여 맞추지 않고, 열 수와 줄바꿈을 조정한다.

생성기별 적용 상태와 검수 범위는 [적용 현황](adoption-status.md), 검수 방법은 [접근성과 검수](accessibility-review.md)를 따른다.
