# Hermes 실행 중 지시

채팅 대기열에서 현재 세션의 실행 작업에 지시 추가 또는 방향 수정을 요청한다. 이 기능은 제어 소켓을 포함한 새 작업에서 사용할 수 있으며, 소켓 준비 전이나 이전 실행 방식으로 시작한 작업에는 사용할 수 없다. 모델 준비와 문맥 정리 시간에는 대기열을 이용한다.

- 지시 추가는 실행 중인 도구 묶음이 끝나는 경계에서 전달한다. 도구가 실행되지 않거나 작업이 먼저 종료되면 전달되지 않을 수 있다.
- 방향 수정은 모델 요청 중이면 해당 요청을 중단하고 수정 지시로 계속하며, 도구 실행 중에는 해당 도구 묶음이 끝나는 경계에서 전달한다.
- `전달 접수`는 에이전트가 지시를 받은 상태로, 반영을 보장하지 않는다. 에이전트의 대화 기록이나 작업 종료 시 티켓에서 반영이 확인된 경우에만 `반영 확인`으로 표시한다.
- 미전달이 확인된 경우 사용자가 후속 대기열로 복구할 수 있다. 복구 요청은 같은 접수 ID를 재사용해 중복을 막는다.
- 연결 단절이나 비정상 종료로 전달 결과가 불명인 경우 자동 재전송하지 않는다. 작업 결과를 확인하고 중복 반영 가능성을 판단해야 한다.

에이전트가 지시를 반영한 상태는 지시가 모델 문맥에 전달되었다는 뜻이며, 최종 답변이 지시를 올바르게 따랐다는 품질 보증은 아니다. 활성 작업 중에도 문맥 반영이 관측되면 상태가 갱신된다.
