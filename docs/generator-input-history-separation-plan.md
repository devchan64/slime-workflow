# 생성 입력과 이력 페이지 분리 준비

상태: 단계적 적용과 대표 검증 완료 · 2026-11-27. 아래 현황과 순서는 최초 준비 기준이며 실제 적용, 확인하지 못한 경로와 환경 제약은 이후 기록을 따른다.

## 현재 확인 범위와 남은 일

2026-11-27 재점검: 현행 메뉴의 FLUX·MiniMax·Wan 2.2·Kimodo·DWPose·오디오는 독립 이력 경로를 사용한다. Wan 2.1은 생성이 폐기된 이력 전용 화면이다. MiniMax 영상 입력폼의 내부 이력 전환과 Wan 2.2·모션·오디오 입력폼의 이전 작업 주소용 내부 이력 분기를 제거했다. 기존 작업 주소는 각 독립 이력에서 처리하고, 대화 내장 폼은 내부 이력을 유지한다. MiniMax 이미지의 잘못된 작업 주소도 이력 오류 안내로 연결한다.

이번 수정 후 실제 화면에서 FL2VA 입력폼과 이력, Wan I2V 및 Dasheng의 기존 완료 작업과 결과 링크를 확인했다. MiniMax 영상·탐색 Python 검사 9건, 이미지 주소·탐색 Python 검사 10건, Wan·오디오 탐색 Python 검사 8건, MiniMax 복원 Node 검사 26건, Wan·모션·오디오 Node 검사 28건과 GUI 빌드가 통과했다. 생성·작업 제어는 실행하지 않았다. 모든 생성기의 내장 폼과 모든 이력·입력 조합을 이번 수정 후 실제 화면에서 확인한 것은 아니다.

MiniMax 이미지 입력폼의 남은 내부 페이지 전환 상태를 제거한 뒤 실제 화면에서 임시 프롬프트를 작성해 이력으로 이동했다. 입력폼으로 돌아오자 임시 프롬프트가 복원됐다. 생성 요청은 하지 않았고 이 확인은 첨부가 없는 초안에 한정된다. 관련 Python 검사 10건, Node 검사 20건과 GUI 빌드가 통과했다.

FL2VA의 첫·마지막 프레임 완료 작업 `2026-11-27_19-56-27-fc3eab66`을 실제 독립 이력에서 열어 참조 썸네일 두 장을 확인하고 입력폼으로 복원했다. 두 프레임 이미지, 생성 모드, 192프레임, 프롬프트와 시드가 표시됐다. 생성 요청과 진행 중인 다른 작업의 제어는 하지 않았다.

MiniMax 영상 생성·편집의 독립 입력폼에서 이력 이동을 실제 이력 주소를 가진 새 탭 링크로 바꾸고 검토 중 잠금은 유지했다. FL2VA 실제 화면에서 링크 주소와 클릭 후 기존 탭의 임시 프롬프트 유지를 확인했다. 이 환경의 브라우저 탭 목록에는 클릭으로 열린 새 탭이 관찰되지 않아 해당 클릭의 새 탭 열림 자체는 확인하지 못했다. 두 서비스의 링크·세션 서버 렌더 검사와 관련 Python 검사 8건, Node 검사 18건 및 GUI 빌드는 통과했다.

## 목표

생성기마다 다른 입력폼과 공통적인 이력·결과 조회의 책임을 분리한다. 입력폼에서 이력과 해당 검수 화면으로 이동하고, 이력에서는 작업을 선택해 결과와 저장 입력을 확인한 다음 `이 입력으로 생성하기`를 선택한다. 입력 조회·복원은 생성 접수가 아니다. 대화에 내장된 폼은 기존 제안·접수 상태를 유지하며 독립 화면 전환과 별도로 검증한다.

## 공통 설계와 순서

1. 생성기별 현행 서비스 ID, 입력·이력·결과·복원·검수 URL, 이력 저장소와 지원 동작을 표로 확정한다. 실행 중인 작업과 화면을 변경하지 않고 읽기 전용으로 확인한다.
2. 서비스별 명령과 결과 유형을 주입받는 공통 이력 페이지와 탐색 계약을 정의한다. 이력의 검색·상태·썸네일·입력 보기·입력 복원·취소·우선 실행·삭제는 실제 지원 범위에 맞춰 표시하고 비활성 사유를 제공한다. 미디어 입력 미리보기는 종류와 누락·오류를 구분한다.
3. 첫 전환은 공통 폼 구조가 있는 FLUX로 제한한다. 프로필별 저장소는 유지하고 대상 서비스와 작업 ID를 함께 전달한다. 기존 `?job=` 링크와 대화에서 연 결과가 같은 작업을 열어야 한다.
4. 영상, 모션, 오디오 순으로 서비스별 어댑터를 추가한다. 이력 페이지 코드를 공유하되 결과·첨부와 복원 검증은 각 서비스의 실제 계약을 따른다. 검수 링크는 해당 서비스의 실제 지원 경로가 확인된 경우에만 제공한다.
5. 입력폼에서 이력으로 이동할 때 작성 중인 프롬프트·설정·첨부를 잃지 않도록 한다. 임시 보관에 실패하면 이동하지 않고 사유를 표시한다. 기존 작업 기록의 입력 복원과 미접수 초안의 복원은 구분한다.
