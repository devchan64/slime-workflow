# Qwen 이미지 생성 시드 안내

Qwen Image 2.1에서 참조 이미지의 생성과 후속 편집에 같은 시드·난수 생성 방식·출력 잠재 크기를 재사용하면 초기 노이즈가 다시 사용되어 배경 얼룩, 거친 선과 과도한 질감이 생길 수 있다. 같은 숫자만으로 같은 노이즈라고 단정할 수는 없고, 다른 시드를 사용해도 모든 열화가 없어지는 것은 아니다.

Qwen 생성기 페이지의 **생성마다 무작위 시드**는 기본으로 켜져 있다. 새 생성 요청마다 새 시드를 선택해 요청에 기록하고, 화면에 실제 사용한 값을 표시한다. 고정 시드가 필요하면 자동 선택을 끄고 값을 입력한다. 이력에서 입력을 불러오면 저장된 시드를 복원하고 자동 선택을 끈다. 이력의 생성 재개는 저장된 요청을 사용한다. CLI에서 시드를 명시한 경우 지정값을 사용하며, CLI 기본 시드 정책은 화면과 별개다.

가능하면 참조 이미지의 생성 기록을 확인하고 그 시드와 다른 값을 편집에 사용한다. 출처 시드를 알 수 없다면 무작위 값을 선택하고 결과를 확인한다. 재현할 때는 사용 시드와 모델·프롬프트·참조·해상도·스텝을 함께 보존한다. 자동 선택값도 우연히 참조 시드와 같을 수 있으므로 참조 시드를 알고 있다면 확인한다.

전신 마네킨 실험에서는 기준 생성 시드 10107을 재사용했을 때 거친 무늬가 생겼고 10108·10109로 바꾼 두 결과에서는 크게 줄었다. 10108 결과를 다음 참조로 사용한 실험에서도 10108 재사용 시 열화가 나타났고 10109에서는 줄었다. 두 번째 참조는 첫 번째에서 파생됐으며 실험 결과를 모든 이미지에 일반화할 수 없다. 이미지 생성은 신체 비율을 고정하지 않으므로 전체 실루엣과 세부 형태를 원본과 비교한다. 공용 화풍 v1.5.0과 VAE 타일링 정책은 이 안내로 변경하지 않는다.
