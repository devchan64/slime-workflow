# 캐릭터 애니메이션 제작·검수

현행 모션 생성은 [Kimodo](../generators/kimodo/README.md)를 사용한다. MoMask·HY-Motion 및 AnyPose 기반 캐릭터 애니메이션 생성과 ANNY 리그 리타깃·렌더는 폐기했다. 기존 스프라이트·앵커 편집 기능은 별도다.

모션의 관절·프레임 번호·FPS·좌표계·참조와 출처를 기록한다. 관절의 직접 투영과 이미지에서 검출한 포즈를 구분한다. Kimodo 얼굴 참조 앵커는 등록된 참조 이미지의 정면·측면을 이용한 근사이며 관측되지 않은 머리 회전을 복원하지 않는다.

승인된 캐릭터 스프라이트와 애니메이션·앵커 메타데이터의 관리 원본은 `slime-assets/assets/`다. 생성 후보와 검수 실험은 `.tmp/test/`에 둔다.
